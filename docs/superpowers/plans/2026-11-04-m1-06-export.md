# M1 Part 6: CSV Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** The `real` flavor exports the ledger as CSV. The normalized shape is a zip with one CSV per table and a manifest, always the full ledger, and Part 7 imports it. The report shape is one CSV row per entry, scoped to the ledger, a group or a person, with an optional date range. Text that a spreadsheet would run is escaped reversibly (AC M1-9, export half).

**Architecture:** A new Android-free package `io` has three pieces:
- `TextEscaping`: the spec's `quote-prefix-v1` rule.
- `NormalizedTables`: one `CsvTable` per entity, whose `Column`s say how a record becomes cells; Part 7 reads the same column names.
- `LedgerExport`: writes the normalized zip and the report with Apache Commons CSV.

`store.ExportRules` checks requests for both flavors. `data.RealImportExportApi` writes the live ledger to a picked document through Part 5's `DocumentStore`. Its import members still delegate to the fake's simulation until Part 7.

**Tech Stack:** Apache Commons CSV 1.14.1, `java.util.zip`, kotlinx.serialization (manifest), JUnit 5, Kotest (including a property test).

## Global Constraints

- **Scope:** the normalized shape is always the full ledger: every table, every row including soft-deleted ones and the me person, so a re-import never meets a dangling reference. The report shape can be scoped to the full ledger, one group or one person, each with an optional `occurredOn` date range. A person scope contains the entries where that person (canonically) is the payer, has a share or is a transfer party (spec §7.2).
- **Normalized shape:** a `.zip` with one CSV per table (`people` including `merged_into_id`, `payment_handles`, `groups`, `group_members`, `transfers`, `expenses`, `expense_shares`, `fx_snapshots`) plus `manifest.json` (app version, schema version, timestamp, scope, text escaping). Amounts are exported as `amount_minor` integers and as decimal strings (spec §7.2).
- **Report shape:** one row per entry: `date, type, description, group, paid_by, from, to, amount, currency, my_share, balance_effect_for_me, account, note`. Names are canonical, and the report is not re-importable (spec §7.2).
- **Format:** by default UTF-8 without BOM, `,` delimiter and RFC 4180 quoting. "Excel-friendly" mode is UTF-8 with a BOM and `;`. Dates are ISO 8601 (`2026-11-02`), instants UTC with `Z`, and the decimal separator is `.` (spec §7.2).
- **Formula-injection protection (reversible):** a text value starting with `=`, `+`, `-`, `@`, tab, CR or `'` gets one `'` prefixed. On import of own exports, exactly one leading `'` is removed. `manifest.json` records `"textEscaping": "quote-prefix-v1"`, and the report uses the same rule (spec §7.2).
- **XLSX export** is M2 (index, carried items: FastExcel moves to M2).
- **No floating point** in money paths; `io` is Android-free (`DomainPurityTest`).

## Decisions this part makes

- **Columns are snake_case versions of the entity fields.** Every entity table ends with the sync columns `version, created_at, updated_at, author_id, deleted_at`.
  - `import_batch_id` is not exported: batches are local.
  - Money is `<name>_minor`, `<name>` (decimal string) and the currency column (`currency`, `effect_currency`).
  - `expense_shares` has `expense_id, position, person_id, share_minor, share, input_value`; `share` is in the expense's effect currency.
  - Booleans are `true`/`false`, enums by name, and null is an empty cell.
- **Only free-text columns are escaped:** names, notes, labels, payment values, holder names, BICs, descriptions, account labels. IDs, numbers, dates and enums never start with a trigger character.
- **The zip lists the tables in dependency order:** people, payment handles, groups, members, FX snapshots, transfers, expenses, shares. Part 7 applies them in this order (spec §7.5). `manifest.json` comes last.
- **The manifest also records `delimiter`, `bom` and the data rows per table** (`tables`), so the import knows how to read the CSVs and can check it read them all. `format` is `iou-normalized-csv`, `schemaVersion` 1, `scope` `full-ledger`.
- **The report adds an `effect_currency` column** after `balance_effect_for_me`, because `my_share` and `balance_effect_for_me` are in the effect currency, which differs from the paid currency after a conversion.
  - `type` is `loan`, `repayment` or `expense`.
  - `balance_effect_for_me` is signed: positive means owed to me.
  - Deleted entries are left out, and rows are sorted by date, then ID.
- **Request rules both flavors share** (`ExportRules.check`): XLSX gives `InvalidField("format")` until M2. A scoped normalized export gives `InvalidField("scope")`, and a range that ends before it starts gives `InvalidField("to")`.
- **The real export checks the scope before it opens the target**, so a `NotFound` scope writes nothing. A target that can't be opened gives `FileAccessFailed`. Exports read the store's current snapshot, and the CSV records end with CRLF (RFC 4180).
- **The real import members stay simulated:** `RealImportExportApi` delegates them to `FakeImportExportApi` (Kotlin `by`) until Part 7 replaces them.

```kotlin
package io.github.codex07.iou.io

import io.kotest.matchers.shouldBe
import io.kotest.property.Arb
import io.kotest.property.arbitrary.string
import io.kotest.property.checkAll
import kotlinx.coroutines.test.runTest
import org.junit.jupiter.api.Test

class TextEscapingTest {

    @Test
    fun `values that a spreadsheet would run get one quote, and so does a leading quote`() {
        TextEscaping.escape("=SUM(1)") shouldBe "'=SUM(1)"
        TextEscaping.escape("=HYPERLINK(\"http://evil\",\"x\")") shouldBe "'=HYPERLINK(\"http://evil\",\"x\")"
        for (start in listOf("+", "-", "@", "\t", "\r")) TextEscaping.escape("${start}x") shouldBe "'${start}x"
        TextEscaping.escape("'quoted") shouldBe "''quoted"
        TextEscaping.escape("plain = text") shouldBe "plain = text"
        TextEscaping.escape("") shouldBe ""
    }

    @Test
    fun `unescaping removes exactly one leading quote`() {
        TextEscaping.unescape("'=SUM(1)") shouldBe "=SUM(1)"
        TextEscaping.unescape("''quoted") shouldBe "'quoted"
        TextEscaping.unescape("plain") shouldBe "plain"
    }

    @Test
    fun `escaping is lossless for every string`() = runTest {
        checkAll(Arb.string(0..12)) { text -> TextEscaping.unescape(TextEscaping.escape(text)) shouldBe text }
    }
}
```

```kotlin
package io.github.codex07.iou.io

/**
 * Reversible formula-injection protection for exported text (spec §7.2): a value starting with `=`, `+`,
 * `-`, `@`, tab, CR or `'` gets one `'` prefixed. Escaping a leading `'` too makes it lossless: [unescape]
 * removes exactly one leading `'`. Only own exports, whose manifest declares [NAME], are unescaped.
 */
object TextEscaping {
    const val NAME = "quote-prefix-v1"

    private val triggers = setOf('=', '+', '-', '@', '\t', '\r', '\'')

    fun escape(text: String): String = if (text.isNotEmpty() && text[0] in triggers) "'$text" else text

    fun unescape(text: String): String = if (text.startsWith('\'')) text.substring(1) else text
}
```

```kotlin
package io.github.codex07.iou.io

import io.github.codex07.iou.ledger.model.Expense
import io.github.codex07.iou.ledger.model.ExpenseShare
import io.github.codex07.iou.ledger.model.FxSnapshot
import io.github.codex07.iou.ledger.model.Group
import io.github.codex07.iou.ledger.model.GroupMember
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.PaymentHandle
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.Transfer
import io.github.codex07.iou.money.Money

/** One column: its header, whether it holds free text (escaped, spec §7.2), and its value for a record. */
class Column<in T>(val name: String, val text: Boolean = false, val value: (T) -> String?)

/** One CSV file of the normalized export: `<name>.csv` with [columns] as its header. */
class CsvTable<T>(val name: String, val columns: List<Column<T>>, val rows: (LedgerState) -> List<T>) {
    val fileName: String get() = "$name.csv"
    val header: List<String> get() = columns.map { it.name }

    /** The cells of [record]: null stays an empty cell; text is escaped. */
    fun cells(record: T): List<String?> = columns.map { column ->
        column.value(record)?.let { if (column.text) TextEscaping.escape(it) else it }
    }
}

/** An expense share with the expense it belongs to and its position in the expense's share list. */
data class ShareLine(val expense: Expense, val position: Int, val share: ExpenseShare)

/**
 * The normalized shape (spec §7.2): one table per entity, every row including deleted ones and the me person.
 * Amounts appear as `*_minor` integers next to decimal strings; instants are ISO-8601 UTC, dates `yyyy-MM-dd`,
 * enums by name, booleans `true`/`false`. The sync columns are the same for every entity table.
 */
object NormalizedTables {
    const val SCHEMA_VERSION = 1

    private fun <T : LedgerEntity> sync(): List<Column<T>> = listOf(
        Column("version") { it.meta.version.toString() },
        Column("created_at") { it.meta.createdAt.toString() },
        Column("updated_at") { it.meta.updatedAt.toString() },
        Column("author_id") { it.meta.authorId.value },
        Column("deleted_at") { it.meta.deletedAt?.toString() },
    )

    private fun <T> money(prefix: String, currencyColumn: String, amount: (T) -> Money): List<Column<T>> = listOf(
        Column("${prefix}_minor") { amount(it).amountMinor.toString() },
        Column(prefix) { amount(it).toPlainString() },
        Column(currencyColumn) { amount(it).currency.code },
    )

    val people = CsvTable(
        "people",
        listOf<Column<Person>>(
            Column("id") { it.id.value },
            Column("display_name", text = true) { it.displayName },
            Column("is_me") { it.isMe.toString() },
            Column("note", text = true) { it.note },
            Column("default_currency") { it.defaultCurrency?.code },
            Column("archived_at") { it.archivedAt?.toString() },
            Column("merged_into_id") { it.mergedIntoId?.value },
        ) + sync(),
    ) { it.people.values.toList() }

    val paymentHandles = CsvTable(
        "payment_handles",
        listOf<Column<PaymentHandle>>(
            Column("id") { it.id.value },
            Column("person_id") { it.personId.value },
            Column("type") { it.type.name },
            Column("value", text = true) { it.value },
```

```kotlin
import java.util.zip.ZipOutputStream
import kotlinx.serialization.Serializable

/** `manifest.json` of the normalized zip (spec §7.2); the import reads the delimiter and escaping from it. */
@Serializable
data class ExportManifest(
    val format: String,
    val schemaVersion: Int,
    val appVersion: String,
    val exportedAt: String,
    val scope: String,
    val textEscaping: String,
    val delimiter: String,
    val bom: Boolean,
    /** Data rows per table. */
    val tables: Map<String, Int>,
)

/**
 * CSV export (spec §7.2). UTF-8, RFC 4180 quoting, `,` and no BOM by default. Excel-friendly mode is UTF-8 with
 * a BOM and `;`. Text is escaped with [TextEscaping] in both shapes.
 */
class LedgerExport(private val appVersion: String) {

    /** The normalized zip: every table, every row, plus the manifest. Returns the number of data rows. */
    fun normalized(state: LedgerState, exportedAt: Instant, excelFriendly: Boolean, out: OutputStream): Int {
        val zip = ZipOutputStream(out)
        val counts = linkedMapOf<String, Int>()
        for (table in NormalizedTables.all) {
            zip.putNextEntry(ZipEntry(table.fileName))
            counts[table.name] = table.write(state, excelFriendly, zip)
            zip.closeEntry()
        }
        val manifest = ExportManifest(
            format = FORMAT, schemaVersion = NormalizedTables.SCHEMA_VERSION, appVersion = appVersion,
            exportedAt = exportedAt.toString(), scope = "full-ledger", textEscaping = TextEscaping.NAME,
            delimiter = delimiter(excelFriendly).toString(), bom = excelFriendly, tables = counts,
        )
        zip.putNextEntry(ZipEntry(MANIFEST))
        zip.write(json.encodeToString(ExportManifest.serializer(), manifest).toByteArray(Charsets.UTF_8))
        zip.closeEntry()
        zip.finish()
        return counts.values.sum()
    }

    /**
     * The report: one row per active entry in [scope] and the inclusive date range, by date. Names are canonical;
     * `my_share` and `balance_effect_for_me` (positive: owed to me) are in `effect_currency`. Not re-importable.
     * Errors: `NotFound` for a group or person that doesn't exist.
     */
    fun report(
        state: LedgerState,
        scope: ExportScope,
        from: LocalDate?,
        to: LocalDate?,
        excelFriendly: Boolean,
        out: OutputStream,
    ): LedgerResult<Int> {
        scopeError(state, scope)?.let { return LedgerResult.Err(it) }
        val resolver = IdentityResolver(state)
        val me = state.meOrNull?.id
        val entries = if (me == null) emptyList() else state.entries
            .filter { !it.isDeleted }
            .filter { (from == null || it.occurredOn >= from) && (to == null || it.occurredOn <= to) }
            .filter { it.inScope(scope, resolver) }
            .sortedWith(compareBy({ it.occurredOn }, { it.id.value }))
        csv(out, excelFriendly) { printer ->
            printer.printRecord(REPORT_HEADER)
            for (entry in entries) printer.printRecord(reportRow(entry, checkNotNull(me), state, resolver))
        }
        return LedgerResult.Ok(entries.size)
    }

    /** `NotFound` for a scope naming a group or person that doesn't exist; check before opening the target. */
    fun scopeError(state: LedgerState, scope: ExportScope): LedgerError? = when (scope) {
        ExportScope.FullLedger -> null
        is ExportScope.Group -> if (scope.id in state.groups) null else LedgerError.NotFound(scope.id.value)
        is ExportScope.Person -> if (scope.id in state.people) null else LedgerError.NotFound(scope.id.value)
    }

    private fun Entry.inScope(scope: ExportScope, resolver: IdentityResolver): Boolean = when (scope) {
        ExportScope.FullLedger -> true
        is ExportScope.Group -> groupId == scope.id
        is ExportScope.Person -> resolver.canonical(scope.id) in personIds.map(resolver::canonical)
    }

    private fun reportRow(entry: Entry, me: PersonId, state: LedgerState, resolver: IdentityResolver): List<String?> {
        fun name(id: PersonId) = state.people[resolver.canonical(id)]?.displayName
        val effectCurrency = entry.effect.currency
        val effectForMe = LedgerEngine.entryEffects(entry, resolver).sumOf { effect ->
            when (me) {
                effect.creditor -> effect.amount.amountMinor
                effect.debtor -> -effect.amount.amountMinor
                else -> 0L
            }
        }
        val transfer = entry as? Transfer
        val expense = entry as? Expense
        val myShare = expense?.shares?.filter { resolver.canonical(it.personId) == me }?.sumOf { it.shareMinor }
        return listOf(
            entry.occurredOn.toString(),
            transfer?.kind?.name?.lowercase() ?: "expense",
            expense?.description?.let(TextEscaping::escape),
            entry.groupId?.let { state.groups[it]?.name }?.let(TextEscaping::escape),
            expense?.let { name(it.payerPersonId) }?.let(TextEscaping::escape),
            transfer?.let { name(it.fromPersonId) }?.let(TextEscaping::escape),
            transfer?.let { name(it.toPersonId) }?.let(TextEscaping::escape),
            entry.paid.toPlainString(),
            entry.paid.currency.code,
            myShare?.let { Money(it, effectCurrency).toPlainString() },
            Money(effectForMe, effectCurrency).toPlainString(),
            effectCurrency.code,
            transfer?.accountLabel?.let(TextEscaping::escape),
            entry.note?.let(TextEscaping::escape),
        )
    }

    private fun <T> CsvTable<T>.write(state: LedgerState, excelFriendly: Boolean, out: OutputStream): Int {
        val records = rows(state)
        csv(out, excelFriendly) { printer ->
            printer.printRecord(header)
            for (record in records) printer.printRecord(cells(record))
        }
        return records.size
    }

    /** Writes one CSV document to [out] without closing it (a zip entry stays open for the next one). */
    private fun csv(out: OutputStream, excelFriendly: Boolean, block: (CSVPrinter) -> Unit) {
        val writer = OutputStreamWriter(out, Charsets.UTF_8)
        if (excelFriendly) writer.write(BOM)
        val printer = CSVPrinter(writer, CSVFormat.RFC4180.builder().setDelimiter(delimiter(excelFriendly)).get())
        block(printer)
        printer.flush()
    }

    private fun delimiter(excelFriendly: Boolean) = if (excelFriendly) ';' else ','

    companion object {
        const val FORMAT = "iou-normalized-csv"
        const val MANIFEST = "manifest.json"
        const val BOM = "\uFEFF"
        val REPORT_HEADER = listOf(
            "date", "type", "description", "group", "paid_by", "from", "to", "amount", "currency",
            "my_share", "balance_effect_for_me", "effect_currency", "account", "note",
        )
        private val json = Json { encodeDefaults = true }
    }
}
```

```kotlin
    /**

        request.from != null && request.to != null && request.from > request.to -> LedgerError.InvalidField("to")

    }
```

```kotlin
import kotlinx.coroutines.withContext

/**
 * The real flavor's import/export. Export writes the live ledger to the picked document (spec §7.2). Import
 * still comes from [simulation] until Part 7.
 */
class RealImportExportApi(
    private val store: LedgerStore,
    private val documents: DocumentStore,
    private val exporter: LedgerExport,
    simulation: ImportExportApi,
) : ImportExportApi by simulation {

    /** Errors: those of `ExportRules.check`, `NotFound` for the scope, `FileAccessFailed`. */
    override suspend fun export(request: ExportRequest, target: DocumentRef): LedgerResult<ExportInfo> {
        ExportRules.check(request)?.let { return LedgerResult.Err(it) }
        val state = store.loaded().state
        exporter.scopeError(state, request.scope)?.let { return LedgerResult.Err(it) }
        val now = store.now()
        return withContext(Dispatchers.IO) {
            try {
                documents.openWrite(target).use { out ->
                    when (request.shape) {
                        ExportShape.NORMALIZED -> LedgerResult.Ok(exporter.normalized(state, now, request.excelFriendly, out))
                        ExportShape.REPORT -> exporter.report(state, request.scope, request.from, request.to, request.excelFriendly, out)
                    }
                }.map(::ExportInfo)
            } catch (e: IOException) {
                LedgerResult.Err(LedgerError.FileAccessFailed("${target.uri}: ${e.message}"))
            } catch (e: SecurityException) {
                LedgerResult.Err(LedgerError.FileAccessFailed("${target.uri}: ${e.message}"))
            }
        }
    }
}
```

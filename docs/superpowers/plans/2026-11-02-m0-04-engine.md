> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-02-m0-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** Pure functions that turn a `LedgerState` into balances (pairwise, group nets, flows, overview totals), greedy settle plans, and field-level revision diffs.

**Architecture:** `LedgerEngine` maps every non-deleted entry, after canonical resolution, to `Effect`s and sums them with exact `Long` arithmetic into a `Balances` value. `SettlePlanner` works on nets only. `RevisionDiff` flattens an entity into named display fields and compares two snapshots. All in `ledger.engine`, no Android, no floating point.

**Tech Stack:** Kotlin, JUnit 5, Kotest assertions and property tests.

## Global Constraints

- Effects (spec §4.2): a transfer P→Q gives `Effect(P, Q, effectCurrency, effectAmountMinor, groupId)`; an expense paid by P gives, for each share of person X ≠ P with `shareMinor > 0`, `Effect(P, X, effectCurrency, shareMinor, groupId)`. Effects between two records of the same canonical person are dropped; shares of two such records add up (spec §4.1).
- Pairwise (spec §4.3): `net(me, X, cur)` = Σ non-group effects me→X − Σ non-group effects X→me. Group nets: `groupNet(M, cur)` = Σ group effects with M as creditor − Σ with M as debtor; nets sum to 0 per group and currency. Flows: gross per pair within a group, informational.
- Overview totals (spec §4.3): *owed to me* = Σ positive `net(me, X)` + Σ over groups of `max(groupNet(me), 0)`; *I owe* = Σ negative `net(me, X)` + Σ over groups of `min(groupNet(me), 0)` (reported here as positive magnitudes).
- Settle plan (spec §4.6): per group and currency, greedy largest creditor vs largest debtor, ties to the lowest person UUID; emit `min(credit, |debt|)` from debtor to creditor; amounts above `MAX_MINOR` split into several transfers of at most `MAX_MINOR` in the same direction; at most n−1 debtor–creditor pairs per currency.
- Person settle-up (spec §4.6): one transfer per non-zero currency of `net(me, X)`, in the direction that reduces the debt, split above `MAX_MINOR`.
- All `Long` money arithmetic is exact (`Math.addExact` etc.); an overflow throws `ArithmeticException` (index, locked decision 4).
- Revision diffs (spec §5.3): field-level diff to the previous snapshot; shares diffed per person; the deleted state shows as a field ("active → deleted", spec §7.4).

```kotlin
package io.github.codex07.iou.ledger.engine

import io.github.codex07.iou.ledger.model.Entry
import io.github.codex07.iou.ledger.model.Expense
import io.github.codex07.iou.ledger.model.GroupId
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.ledger.model.Transfer
import io.github.codex07.iou.money.CurrencyCode
import io.github.codex07.iou.money.Money

/** [debtor] owes [creditor] [amount] because of one entry (spec §4.2). Person IDs are canonical. */
data class Effect(
    val creditor: PersonId,
    val debtor: PersonId,
    val amount: Money,
    val groupId: GroupId?,
)

/** Every balance of one ledger state. Maps never contain zero amounts. Person keys are canonical. */
data class Balances(
    val me: PersonId,
    /** `net(me, X)` per canonical X: positive means X owes me. Non-group effects only. */
    val pairwise: Map<PersonId, Map<CurrencyCode, Long>>,
    /** `groupNet(M)` per group and member: positive means the group owes M. */
    val groupNets: Map<GroupId, Map<PersonId, Map<CurrencyCode, Long>>>,
    /** Gross amounts per group and (creditor, debtor) pair: "who paid for whom". */
    val flows: Map<GroupId, Map<Pair<PersonId, PersonId>, Map<CurrencyCode, Long>>>,
) {
    fun net(other: PersonId): Map<CurrencyCode, Long> = pairwise[other].orEmpty()

    fun groupNet(groupId: GroupId, person: PersonId): Map<CurrencyCode, Long> =
        groupNets[groupId]?.get(person).orEmpty()

    fun myGroupNet(groupId: GroupId): Map<CurrencyCode, Long> = groupNet(groupId, me)

    /** Σ positive `net(me, X)` + Σ over groups of `max(groupNet(me), 0)`, per currency. */
    val owedToMe: Map<CurrencyCode, Long> by lazy { totals(positive = true) }

    /** Σ |negative `net(me, X)`| + Σ over groups of |`min(groupNet(me), 0)`|, per currency, as magnitudes. */
    val iOwe: Map<CurrencyCode, Long> by lazy { totals(positive = false) }

    private fun totals(positive: Boolean): Map<CurrencyCode, Long> {
        val sums = Sums<Unit>()
        val myPositions = pairwise.values.asSequence() + groupNets.values.asSequence().map { it[me].orEmpty() }
        for (position in myPositions) {
            for ((currency, amount) in position) {
                if (positive && amount > 0) sums.add(Unit, currency, amount)
                if (!positive && amount < 0) sums.add(Unit, currency, Math.negateExact(amount))
            }
        }
        return sums.result()[Unit].orEmpty()
    }
}

/** Pure balance computation (spec §4.2, §4.3). Recomputed on every emission. */
object LedgerEngine {

    fun effects(state: LedgerState, resolver: IdentityResolver = IdentityResolver(state)): List<Effect> =
        state.entries.filter { !it.isDeleted }.flatMap { entryEffects(it, resolver) }

    fun entryEffects(entry: Entry, resolver: IdentityResolver): List<Effect> = when (entry) {
        is Transfer -> {
            val from = resolver.canonical(entry.fromPersonId)
            val to = resolver.canonical(entry.toPersonId)
            if (from == to) emptyList() else listOf(Effect(from, to, entry.effectAmount, entry.groupId))
        }
        is Expense -> {
            val payer = resolver.canonical(entry.payerPersonId)
            entry.shares
                .filter { it.shareMinor > 0 }
                .mapNotNull { share ->
                    val debtor = resolver.canonical(share.personId)
                    if (debtor == payer) null
                    else Effect(payer, debtor, Money(share.shareMinor, entry.effectTotal.currency), entry.groupId)
                }
        }
    }

    fun compute(state: LedgerState): Balances {
        val resolver = IdentityResolver(state)
        val me = resolver.canonical(state.me.id)
        val pairwise = Sums<PersonId>()
        val groupNets = HashMap<GroupId, Sums<PersonId>>()
        val flows = HashMap<GroupId, Sums<Pair<PersonId, PersonId>>>()

        for (effect in effects(state, resolver)) {
            val currency = effect.amount.currency
            val amount = effect.amount.amountMinor
            val groupId = effect.groupId
            if (groupId == null) {
                if (effect.creditor == me) pairwise.add(effect.debtor, currency, amount)
                if (effect.debtor == me) pairwise.add(effect.creditor, currency, Math.negateExact(amount))
            } else {
                val nets = groupNets.getOrPut(groupId) { Sums() }
                nets.add(effect.creditor, currency, amount)
                nets.add(effect.debtor, currency, Math.negateExact(amount))
                flows.getOrPut(groupId) { Sums() }.add(effect.creditor to effect.debtor, currency, amount)
            }
        }

        return Balances(
            me = me,
            pairwise = pairwise.result(),
            groupNets = groupNets.mapValues { it.value.result() }.filterValues { it.isNotEmpty() },
            flows = flows.mapValues { it.value.result() }.filterValues { it.isNotEmpty() },
        )
    }

    /** `net(a, b)` over non-group effects, for any two canonical people (used by property tests and views). */
    fun nonGroupNet(effects: List<Effect>, a: PersonId, b: PersonId): Map<CurrencyCode, Long> {
        val sums = Sums<Unit>()
        for (effect in effects) {
            if (effect.groupId != null) continue
            if (effect.creditor == a && effect.debtor == b) sums.add(Unit, effect.amount.currency, effect.amount.amountMinor)
            if (effect.creditor == b && effect.debtor == a) {
                sums.add(Unit, effect.amount.currency, Math.negateExact(effect.amount.amountMinor))
            }
        }
        return sums.result()[Unit].orEmpty()
    }
}

/** Exact per-key, per-currency sums; drops zero results. */
internal class Sums<K> {
    private val sums = LinkedHashMap<K, LinkedHashMap<CurrencyCode, Long>>()

    fun add(key: K, currency: CurrencyCode, amount: Long) {
        val perCurrency = sums.getOrPut(key) { LinkedHashMap() }
        perCurrency[currency] = Math.addExact(perCurrency[currency] ?: 0L, amount)
    }

    fun result(): Map<K, Map<CurrencyCode, Long>> =
        sums.mapValues { (_, perCurrency) -> perCurrency.filterValues { it != 0L } }.filterValues { it.isNotEmpty() }
}
```

```kotlin
package io.github.codex07.iou.ledger.engine

import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.money.CurrencyCode
import io.github.codex07.iou.money.MAX_MINOR
import io.github.codex07.iou.money.Money

/** A suggested transfer: [from] pays [to] (spec §4.6). Never stored. */
data class PlannedTransfer(val from: PersonId, val to: PersonId, val amount: Money)

/** Greedy settle plans (spec §4.6). */
object SettlePlanner {

    fun planGroup(nets: Map<PersonId, Map<CurrencyCode, Long>>): List<PlannedTransfer> =
        nets.values
            .flatMap { it.keys }
            .distinct()
            .sortedBy { it.code }
            .flatMap { currency -> planCurrency(currency, nets.mapValues { it.value[currency] ?: 0L }) }

    fun planPerson(me: PersonId, other: PersonId, net: Map<CurrencyCode, Long>): List<PlannedTransfer> =
        net.entries
            .sortedBy { it.key.code }
            .flatMap { (currency, amount) ->
                when {
                    amount > 0 -> chunks(other, me, amount, currency)
                    amount < 0 -> chunks(me, other, Math.negateExact(amount), currency)
                    else -> emptyList()
                }
            }

    private fun planCurrency(currency: CurrencyCode, nets: Map<PersonId, Long>): List<PlannedTransfer> {
        val credits = nets.filterValues { it > 0 }.toMutableMap()
        val debts = nets.filterValues { it < 0 }.mapValues { Math.negateExact(it.value) }.toMutableMap()
        // Largest amount first; on equal amounts the lowest person ID wins.
        val largest = compareBy<Map.Entry<PersonId, Long>> { it.value }.thenByDescending { it.key.value }
        val plan = mutableListOf<PlannedTransfer>()

        while (credits.isNotEmpty() && debts.isNotEmpty()) {
            val creditor = credits.entries.maxWith(largest).key
            val debtor = debts.entries.maxWith(largest).key
            val amount = minOf(credits.getValue(creditor), debts.getValue(debtor))
            plan += chunks(debtor, creditor, amount, currency)
            settle(credits, creditor, amount)
            settle(debts, debtor, amount)
        }
        return plan
    }

    private fun settle(open: MutableMap<PersonId, Long>, person: PersonId, amount: Long) {
        val left = open.getValue(person) - amount
        if (left == 0L) open.remove(person) else open[person] = left
    }

    private fun chunks(from: PersonId, to: PersonId, amount: Long, currency: CurrencyCode): List<PlannedTransfer> {
        val result = mutableListOf<PlannedTransfer>()
        var left = amount
        while (left > 0) {
            val part = minOf(left, MAX_MINOR)
            result += PlannedTransfer(from, to, Money(part, currency))
            left -= part
        }
        return result
    }
}
```

```kotlin
package io.github.codex07.iou.ledger.engine

import io.github.codex07.iou.ledger.model.Expense
import io.github.codex07.iou.ledger.model.FieldChange
import io.github.codex07.iou.ledger.model.Group
import io.github.codex07.iou.ledger.model.GroupId
import io.github.codex07.iou.ledger.model.GroupMember
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.PaymentHandle
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.ledger.model.Transfer
import io.github.codex07.iou.money.Money

/** How IDs inside diffs are shown. Views pass display names; tests and imports may use raw IDs. */
interface DiffNames {
    fun person(id: PersonId): String
    fun group(id: GroupId): String

    companion object {
        val Ids: DiffNames = object : DiffNames {
            override fun person(id: PersonId) = id.value
            override fun group(id: GroupId) = id.value
        }
    }
}

/**
 * One business field of a snapshot: [value] is what is compared (IDs for references), [shown] how it is
 * displayed, [label] the `FieldChange.field` it is reported under.
 */
data class DiffField(val label: String, val value: String, val shown: String)

/** Field-level diffs of entity snapshots (spec §5.3). Sync columns other than the deleted state are ignored. */
object RevisionDiff {

    fun diff(before: LedgerEntity?, after: LedgerEntity, names: DiffNames = DiffNames.Ids): List<FieldChange> {
        val old = before?.let { fields(it, names) }.orEmpty()
        val new = fields(after, names)
        val keys = new.keys + (old.keys - new.keys)
        return keys.mapNotNull { key ->
            val was = old[key]
            val now = new[key]
            if (was?.value == now?.value) return@mapNotNull null
            // Different IDs that read the same ("Alex" and "Alex"): show the IDs too, or the change looks empty.
            val ambiguous = was != null && now != null && was.shown == now.shown
            fun DiffField.display() = if (ambiguous) "$shown ($value)" else shown
            FieldChange((now ?: was)!!.label, was?.display(), now?.display())
        }
    }

    /** Business fields, keyed so the same field of two snapshots pairs up (shares by person ID). Null values are omitted. */
    fun fields(entity: LedgerEntity, names: DiffNames = DiffNames.Ids): Map<String, DiffField> {
        val fields = LinkedHashMap<String, DiffField>()
        fun plain(label: String, value: String?) {
            if (value != null) fields[label] = DiffField(label, value, value)
        }
        fun person(label: String, id: PersonId?) {
            if (id != null) fields[label] = DiffField(label, id.value, names.person(id))
        }
        fun group(label: String, id: GroupId?) {
            if (id != null) fields[label] = DiffField(label, id.value, names.group(id))
        }
        when (entity) {
            is Person -> {
                plain("displayName", entity.displayName)
                plain("note", entity.note)
                plain("defaultCurrency", entity.defaultCurrency?.code)
                plain("archived", entity.archivedAt?.let { "yes" })
                person("mergedInto", entity.mergedIntoId)
            }
            is PaymentHandle -> {
                person("person", entity.personId)
                plain("type", entity.type.name)
                plain("value", entity.value)
                plain("holderName", entity.holderName)
                plain("bic", entity.bic)
                plain("label", entity.label)
                plain("isDefault", yesNo(entity.isDefault))
            }
            is Group -> {
                plain("name", entity.name)
                plain("defaultCurrency", entity.defaultCurrency.code)
                plain("fxMode", entity.fxMode.name)
                plain("archived", entity.archivedAt?.let { "yes" })
            }
            is GroupMember -> {
                group("group", entity.groupId)
                person("person", entity.personId)
                plain("removed", entity.removedAt?.let { "yes" })
            }
            is Transfer -> {
                person("from", entity.fromPersonId)
                person("to", entity.toPersonId)
                plain("amount", entity.amount.toString())
                plain("effect", entity.effectAmount.toString())
                plain("fxSnapshot", entity.fxSnapshotId?.value)
                plain("kind", entity.kind.name)
                plain("method", entity.method.name)
                plain("accountLabel", entity.accountLabel)
                group("group", entity.groupId)
                plain("occurredOn", entity.occurredOn.toString())
                plain("note", entity.note)
            }
            is Expense -> {
                person("payer", entity.payerPersonId)
                plain("description", entity.description)
                plain("category", entity.category?.name)
                plain("total", entity.total.toString())
                plain("effectTotal", entity.effectTotal.toString())
                plain("fxSnapshot", entity.fxSnapshotId?.value)
                plain("splitType", entity.splitType.name)
                group("group", entity.groupId)
                plain("occurredOn", entity.occurredOn.toString())
                plain("note", entity.note)
                for (share in entity.shares) {
                    val id = share.personId.value
                    val name = names.person(share.personId)
                    val amount = Money(share.shareMinor, entity.effectTotal.currency).toString()
                    fields["share[$id]"] = DiffField("share[$name]", amount, amount)
                    share.inputValue?.let { fields["input[$id]"] = DiffField("input[$name]", it.toString(), it.toString()) }
                }
            }
        }
        plain("state", if (entity.isDeleted) "deleted" else "active")
        return fields
    }

    private fun yesNo(value: Boolean) = if (value) "yes" else "no"
}
```

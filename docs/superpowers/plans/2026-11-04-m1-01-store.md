# M1 Part 1: The Shared Ledger Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** Turn the fake's in-memory ledger into a store both flavors share (ADR-0010). Writes become `suspend` and go through a persistence port (`LedgerJournal`). Ledger settings move into the store, and device-local settings and the app-lock state get their own ports. The fake keeps behaving exactly as before.

**Architecture:** `store.LedgerStore` holds the ledger as one `StateFlow` value (`StoreSnapshot` = `LedgerContent` + generation). A write runs a pure `ledger.ops` function under a coroutine `Mutex`, hands the validated plan with its revisions to the `LedgerJournal`, and publishes only after the journal returned. `exclusive { live, publish -> }` holds the same lock for whole-ledger replacements: first load, restore, undo of a restore. The four ledger-data APIs and the settings API move from `fake` to `store` (`Store*Api`) so that Part 3 can reuse them with a Room journal. FX, backup and import/export stay simulated in `fake` until their own parts.

**Tech Stack:** Kotlin, Coroutines/Flow (`Mutex`, `StateFlow`), JUnit 5, Kotest, Turbine.

## Global Constraints

- Android-free packages: `money`, `ledger`, `api`, `store`, `fake` (no `android.*`/`androidx.*` imports). No `Double`/`Float` in `money`, `ledger`, `api`, `store`, `data`, `io`. Both are enforced by `DomainPurityTest`, which this part extends with `store`.
- Ledger settings (home currency, backup encryption default) travel with the ledger: stored with it, swapped by a restore (spec §3.3). Device-local settings (app lock, lock timeout, screen protection, last manual backup) never do.
- Every successful ledger write appends one `EntryRevision` per changed entity and increments `ledgerSeq` (spec §5.1). A settings change is not a ledger write: `ledgerSeq` stays.
- All read `Flow`s re-emit after a replacement, even when the replaced data compares equal (spec §6.2).
- Nothing is published that the journal did not persist; a failed append leaves the store unchanged. What the journal did persist is published, even if the caller is cancelled while the journal returns.
- No behaviour visible through `api` changes in this part: all existing contract tests keep passing unchanged.

## Decisions this part makes

- **The store waits for its first load.** Built with `initial`, it starts loaded (the fake). Built without it (Part 3's Room flavor), reads emit nothing and writes suspend until an `exclusive` block publishes the loaded ledger. Writes wait for the load *before* taking the lock, so they never block the load itself.
- **`writeWith` is the general write.** It hands the op the whole `StoreSnapshot` and lets it return a `StoreWrite` (plan + import batches + new ledger settings). Setup uses it to store the home currency in the same journal entry as me. Revert uses it to read the revision log, and the import commit and undo use it to record batches. `write` is the common case without extras.
- **Persisting and publishing can't be cancelled.** Room can commit a transaction and still throw `CancellationException` while it resumes a cancelled caller on another dispatcher. The store would then serve old versions and an old `ledgerSeq` over committed data, and the next write would reuse those versions. So the new state is computed first, and `journal.append` and the publish run together under `NonCancellable`.
- **`ledgerSeq` counts ledger writes:** a commit with rows or import batches increments it; a settings-only change does not.
- **Rates for approximate totals** come from a `StateFlow<RateLookup>`: the fake's fixed table now, Part 4's rate cache later. Views are recomputed when it emits.
- **The fake keeps its own pre-restore copy** in `FakeBackupApi` and swaps through `exclusive`; restores no longer bump `ledgerSeq`. The fresh generation already invalidates everything prepared before.
- **M0 plan files are frozen.** Changes to M0 code made by M1 are documented in the M1 plans only; nothing is mirrored back into `2026-11-02-m0-*.md`.

import io.github.codex07.iou.api.LockTimeout
import io.github.codex07.iou.ledger.model.Change
import io.github.codex07.iou.ledger.model.EntryRevision
import io.github.codex07.iou.ledger.model.FxSnapshot
import io.github.codex07.iou.ledger.model.ImportBatch
import io.github.codex07.iou.ledger.model.LedgerGeneration
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.ops.WritePlan
import io.github.codex07.iou.money.CurrencyCode
import java.time.Instant

/** Ledger settings (spec §3.3): stored with the ledger, so a restore swaps them with it. */
data class LedgerSettings(
    val homeCurrency: CurrencyCode = CurrencyCode("EUR"),
    val backupEncryptionDefault: Boolean = true,
)

/** Device-local settings (spec §3.3): never backed up, restored or exported. */
data class DeviceSettings(
    val appLockEnabled: Boolean = false,
    val lockTimeout: LockTimeout = LockTimeout.ONE_MINUTE,
    val screenProtection: Boolean = false,
    val lastManualBackupAt: Instant? = null,
)

/** Everything one ledger database holds; a restore replaces all of it. */
data class LedgerContent(
    val state: LedgerState = LedgerState(),
    val revisions: List<EntryRevision> = emptyList(),
    val importBatches: List<ImportBatch> = emptyList(),
    val ledgerSeq: Long = 0,
    val settings: LedgerSettings = LedgerSettings(),
)

/** The live ledger and the generation it is served under (spec §5.1). */
data class StoreSnapshot(val content: LedgerContent, val generation: LedgerGeneration) {
    val state: LedgerState get() = content.state
    val revisions: List<EntryRevision> get() = content.revisions
    val importBatches: List<ImportBatch> get() = content.importBatches
    val ledgerSeq: Long get() = content.ledgerSeq
    val settings: LedgerSettings get() = content.settings
}

/** What a store write persists, besides the plan's rows: import batches to insert or replace, new settings. */
data class StoreWrite<out T>(
    val value: T,
    val plan: WritePlan,
    val importBatches: List<ImportBatch> = emptyList(),
    val settings: LedgerSettings? = null,
)

/** One committed write, in the order the journal must persist it. [ledgerSeq] and [settings] are the new values. */
data class JournalEntry(
    val changes: List<Change> = emptyList(),
    val snapshots: List<FxSnapshot> = emptyList(),
    val revisions: List<EntryRevision> = emptyList(),
    val importBatches: List<ImportBatch> = emptyList(),
    val ledgerSeq: Long,
    val settings: LedgerSettings,
)

/** Where the store persists committed writes: nowhere for the fake, one Room transaction for the real flavor. */
fun interface LedgerJournal {
    /** Persists [entry] atomically. Throws if it could not; then nothing of it was persisted. */
    suspend fun append(entry: JournalEntry)

    companion object {
        val None = LedgerJournal { }
    }
}

/** Rates for approximate home-currency totals: units of [to] per one unit of [from], or null if unknown. */
fun interface RateLookup {
    fun rate(from: CurrencyCode, to: CurrencyCode): String?

    companion object {
        val None = RateLookup { from, to -> if (from == to) "1" else null }
    }
}

package io.github.codex07.iou.store

import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update

/** Device-local settings storage: DataStore in the real flavor, memory in the fake and in tests. */
interface DeviceSettingsStore {
    val settings: Flow<DeviceSettings>

    suspend fun update(transform: (DeviceSettings) -> DeviceSettings)
}

class InMemoryDeviceSettings(initial: DeviceSettings = DeviceSettings()) : DeviceSettingsStore {
    private val state = MutableStateFlow(initial)

    override val settings: Flow<DeviceSettings> = state.asStateFlow()

    override suspend fun update(transform: (DeviceSettings) -> DeviceSettings) = state.update(transform)
}

/**
 * The app-lock state behind `SettingsApi.observeLockRequired` and `markUnlocked` (spec §9). The real
 * flavor's policy also follows the process lifecycle; [SimpleLockGate] only knows cold start and unlocks.
 */
interface LockGate {
    val required: Flow<Boolean>

    fun unlocked()

    /** Called after the app-lock setting changed; turning it on mid-session doesn't lock the open app. */
    fun lockEnabledChanged(enabled: Boolean)
}

/** Locked from start exactly when app lock was enabled at start; cleared by an unlock or by disabling it. */
class SimpleLockGate(lockedAtStart: Boolean = false) : LockGate {
    private val state = MutableStateFlow(lockedAtStart)

    override val required: Flow<Boolean> = state.asStateFlow()

    override fun unlocked() {
        state.value = false
    }

    override fun lockEnabledChanged(enabled: Boolean) {
        if (!enabled) state.value = false
    }
}

package io.github.codex07.iou.store

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.api.map
import io.github.codex07.iou.ledger.model.DeviceId
import io.github.codex07.iou.ledger.model.EntryRevision
import io.github.codex07.iou.ledger.model.IdGenerator
import io.github.codex07.iou.ledger.model.LedgerGeneration
import io.github.codex07.iou.ledger.model.RevisionId
import io.github.codex07.iou.ledger.ops.Planned
import io.github.codex07.iou.ledger.ops.WriteContext
import io.github.codex07.iou.ledger.views.LedgerViews
import java.time.Clock
import java.time.Instant
import java.time.LocalDate
import kotlinx.coroutines.NonCancellable
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.distinctUntilChanged
import kotlinx.coroutines.flow.filter
import kotlinx.coroutines.flow.filterNotNull
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext

/**
 * The ledger as one in-memory value, shared by both flavors (ADR-0010). Writes run a pure op from
 * `ledger.ops` under one lock, persist the validated plan through the [journal], and only then publish
 * it. The fake's journal keeps nothing; the real flavor's writes Room in one transaction.
 *
 * With [initial], the store starts loaded under a fresh generation. Without it, nothing is served until a
 * first [exclusive] block publishes the loaded ledger; reads and writes wait for that.
 */
class LedgerStore(
    val clock: Clock,
    val ids: IdGenerator,
    val deviceId: DeviceId,
    private val journal: LedgerJournal = LedgerJournal.None,
    private val rates: StateFlow<RateLookup> = MutableStateFlow(RateLookup.None),
    initial: LedgerContent? = null,
) {
    private val lock = Mutex()
    private val current = MutableStateFlow(initial?.let { StoreSnapshot(it, newGeneration()) })

    /** The live ledger, from the first load on. */
    val snapshot: Flow<StoreSnapshot> = current.filterNotNull()

    val views: Flow<LedgerViews> = combine(snapshot, rates, ::viewsOf)

    /** Views once setup has run; ledger-data reads observe this. */
    val ready: Flow<LedgerViews> = views.filter { it.state.meOrNull != null }

    /** A read of the set-up ledger. It re-emits after every replacement, even when its value compares equal (spec §6.2). */
    fun <T> read(project: (LedgerViews) -> T): Flow<T> = ready.perGeneration({ it.generation }, project)

    /** A read of other replaced state (import history, ledger settings); it re-emits the same way. */
    fun <T> readSnapshot(project: (StoreSnapshot) -> T): Flow<T> = snapshot.perGeneration({ it.generation }, project)

    /** The live ledger, waiting for the first load if needed. */
    suspend fun loaded(): StoreSnapshot = snapshot.first()

    suspend fun currentViews(): LedgerViews = viewsOf(loaded(), rates.value)

    fun now(): Instant = clock.instant()

    fun today(): LocalDate = LocalDate.now(clock)

    fun newGeneration() = LedgerGeneration(ids.next())

    /** Runs [op] against the live ledger; on success persists and publishes its plan atomically. */
    suspend fun <T> write(
        beforeSetup: Boolean = false,
        op: (WriteContext) -> LedgerResult<Planned<T>>,
    ): LedgerResult<T> = writeWith(beforeSetup) { _, context -> op(context).map { StoreWrite(it.value, it.plan) } }

    /**
     * Like [write], for writes that also record import batches or change ledger settings, or that check
     * more of the snapshot than [WriteContext] carries (e.g. an import preview's `ledgerSeq`).
     */
    suspend fun <T> writeWith(
        beforeSetup: Boolean = false,
        op: (StoreSnapshot, WriteContext) -> LedgerResult<StoreWrite<T>>,
    ): LedgerResult<T> {
        loaded()
        return lock.withLock {
            val snapshot = checkNotNull(current.value)
            if (!beforeSetup && snapshot.state.meOrNull == null) return@withLock LedgerResult.Err(LedgerError.NotFound("me"))
            val result = op(snapshot, WriteContext(snapshot.state, snapshot.generation, now(), ids))
            if (result is LedgerResult.Ok) commit(snapshot, result.value)
            result.map { it.value }
        }
    }

    /** Changes ledger settings outside any ledger write; `ledgerSeq` stays (spec §5.1 counts ledger writes). */
    suspend fun updateSettings(transform: (LedgerSettings) -> LedgerSettings) {
        loaded()
        lock.withLock {
            val snapshot = checkNotNull(current.value)
            val settings = transform(snapshot.settings)
            if (settings == snapshot.settings) return@withLock
            persist(JournalEntry(ledgerSeq = snapshot.ledgerSeq, settings = settings), snapshot.copy(content = snapshot.content.copy(settings = settings)))
        }
    }

    /**
     * Runs [block] holding the write lock, so no write is in flight and none starts until it returns.
     * [block] gets the live ledger (null before the first load) and may call `publish` to replace it:
     * the first load, a restore, or an undo of a restore, each under its own generation.
     */
    suspend fun <T> exclusive(block: suspend (live: StoreSnapshot?, publish: (LedgerContent, LedgerGeneration) -> Unit) -> T): T =
        lock.withLock { block(current.value) { content, generation -> current.value = StoreSnapshot(content, generation) } }

    private suspend fun commit(snapshot: StoreSnapshot, write: StoreWrite<*>) {
        val plan = write.plan
        if (plan.isEmpty && write.importBatches.isEmpty() && write.settings == null) return
        val at = now()
        val revisions = plan.changes.map { change ->
            val entity = change.entity
            EntryRevision(
                id = RevisionId(ids.next()), entityType = entity.entityType, entityId = entity.entityId,
                version = entity.meta.version, action = change.action, authorId = entity.meta.authorId,
                deviceId = deviceId, at = at, reason = change.reason, importBatchId = entity.meta.importBatchId,
                snapshot = entity,
            )
        }
        val ledgerWrite = !plan.isEmpty || write.importBatches.isNotEmpty()
        val content = snapshot.content
        val ledgerSeq = if (ledgerWrite) content.ledgerSeq + 1 else content.ledgerSeq
        val settings = write.settings ?: content.settings
        val batchIds = write.importBatches.map { it.id }.toSet()
        val next = snapshot.copy(
            content = content.copy(
                state = content.state.applying(plan.changes, plan.snapshots),
                revisions = content.revisions + revisions,
                importBatches = content.importBatches.filterNot { it.id in batchIds } + write.importBatches,
                ledgerSeq = ledgerSeq,
                settings = settings,
            ),
        )
        persist(JournalEntry(plan.changes, plan.snapshots, revisions, write.importBatches, ledgerSeq, settings), next)
    }

    /**
     * Persists [entry], then publishes [next]. Not cancellable: the journal may commit and still throw on the
     * way back to a cancelled caller (Room resumes it on another dispatcher), and the store must then hold what
     * the database holds. A failed append publishes nothing.
     */
    private suspend fun persist(entry: JournalEntry, next: StoreSnapshot) = withContext(NonCancellable) {
        journal.append(entry)
        current.value = next
    }

    private fun viewsOf(snapshot: StoreSnapshot, rates: RateLookup): LedgerViews {
        val home = snapshot.settings.homeCurrency
        return LedgerViews(snapshot.state, snapshot.revisions, snapshot.generation, home) { rates.rate(it, home) }
    }

    private fun <S, T> Flow<S>.perGeneration(generation: (S) -> LedgerGeneration, project: (S) -> T): Flow<T> =
        map { generation(it) to project(it) }.distinctUntilChanged().map { it.second }
}

/** Simulated backups (spec §6.3): restoring brings back the current data under a fresh generation. */
class FakeBackupApi(private val store: LedgerStore, private val device: DeviceSettingsStore) : BackupApi {
    private val passphrases = ConcurrentHashMap<String, String>()
    private val preRestore = MutableStateFlow<LedgerContent?>(null)

    override fun observeLedgerGeneration(): Flow<LedgerGeneration> = store.snapshot.map { it.generation }.distinctUntilChanged()

    override fun observeBackupReminder(): Flow<BackupReminder> = device.settings.map { settings ->
        val last = settings.lastManualBackupAt
        BackupReminder(due = last == null || Duration.between(last, store.now()) > Duration.ofDays(30), lastBackupAt = last)
    }.distinctUntilChanged()

    override suspend fun createBackup(target: DocumentRef, passphrase: CharArray?): LedgerResult<BackupInfo> {
        val now = store.now()
        passphrases[target.uri] = passphrase?.concatToString().orEmpty()
        device.update { it.copy(lastManualBackupAt = now) }
        return LedgerResult.Ok(BackupInfo(encrypted = passphrase != null, createdAt = now))
    }

    override suspend fun restoreBackup(source: DocumentRef, passphrase: CharArray?): LedgerResult<Unit> {
        val stored = passphrases[source.uri] ?: return LedgerResult.Err(LedgerError.CorruptFile("No IOU backup at ${source.uri}"))
        if (stored != passphrase?.concatToString().orEmpty()) return LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
        store.exclusive { live, publish ->
            val current = checkNotNull(live).content
            preRestore.value = current
            publish(current, store.newGeneration())
        }
        return LedgerResult.Ok(Unit)
    }

    override fun observeUndoRestoreAvailable(): Flow<Boolean> = preRestore.map { it != null }.distinctUntilChanged()

    override suspend fun undoLastRestore(): LedgerResult<Unit> = store.exclusive { live, publish ->
        val previous = preRestore.value ?: return@exclusive LedgerResult.Err(LedgerError.NotFound("restore"))
        preRestore.value = checkNotNull(live).content
        publish(previous, store.newGeneration())
        LedgerResult.Ok(Unit)
    }
}

/** Simulated import/export (M0 Part 7 "Decisions"): canned previews, real staleness checks. */
class FakeImportExportApi(private val store: LedgerStore) : ImportExportApi {

    override suspend fun export(request: ExportRequest, target: DocumentRef): LedgerResult<ExportInfo> {
        if (request.shape == ExportShape.NORMALIZED && request.scope != ExportScope.FullLedger) {
            return LedgerResult.Err(LedgerError.InvalidField("scope"))
        }
        return LedgerResult.Ok(ExportInfo(rowCount = store.loaded().state.entries.size))
    }

    override suspend fun parseImport(source: DocumentRef): LedgerResult<ImportPreview> {
        val name = source.uri.substringAfterLast('/')
        if ("corrupt" in name) return LedgerResult.Err(LedgerError.CorruptFile("Not an IOU export: $name"))
        val identity = if ("foreign" in name) ImportIdentity.NeedsConfirmation(PersonId("foreign-me")) else ImportIdentity.Same
        return LedgerResult.Ok(cannedPreview(store.loaded(), name, identity))
    }

    override suspend fun confirmIdentity(preview: ImportPreview, accept: Boolean): LedgerResult<ImportPreview> {
        val snapshot = store.loaded()
        // A preview parsed before a restore belongs to the replaced ledger, whatever the answer.
        if (preview.generation != snapshot.generation) return LedgerResult.Err(LedgerError.LedgerReplaced)
        val pending = preview.identity as? ImportIdentity.NeedsConfirmation ?: return LedgerResult.Ok(preview)
        if (!accept) return LedgerResult.Err(LedgerError.ForeignLedger)
        return LedgerResult.Ok(cannedPreview(snapshot, preview.fileName, ImportIdentity.Mapped(pending.sourceMe)))
    }

    override fun applyChoices(preview: ImportPreview, choices: ImportChoices): ImportPreview = preview

    /** Rebuilds the preview against the current ledger; rows that are new or whose diff changed are flagged. */
    override suspend fun refreshPreview(preview: ImportPreview): LedgerResult<ImportPreview> {
        val snapshot = store.loaded()
        if (preview.generation != snapshot.generation) return LedgerResult.Err(LedgerError.LedgerReplaced)
        val previous = preview.rows.associateBy { it.key }
        val fresh = cannedPreview(snapshot, preview.fileName, preview.identity)
        return LedgerResult.Ok(
            fresh.copy(id = preview.id, rows = fresh.rows.map { it.copy(changedSinceLastPreview = previous[it.key]?.changes != it.changes) }),
        )
    }

    override suspend fun commitImport(preview: ImportPreview, choices: ImportChoices): LedgerResult<ImportBatchId> =
        store.writeWith { snapshot, context ->
            when {
                preview.generation != snapshot.generation -> LedgerResult.Err(LedgerError.LedgerReplaced)
                preview.ledgerSeq != snapshot.ledgerSeq -> LedgerResult.Err(LedgerError.ImportPreviewStale)
                preview.identity is ImportIdentity.NeedsConfirmation -> LedgerResult.Err(LedgerError.ForeignLedger)
                preview.invalidRows.isNotEmpty() && !choices.skipInvalidRows -> LedgerResult.Err(LedgerError.InvalidField("invalidRows"))
                else -> {
                    val id = ImportBatchId(context.ids.next())
                    val rowCount = preview.counts.new + choices.takeIncoming.size
                    val batch = ImportBatch(id, ImportSource.OWN_NORMALIZED_CSV, preview.fileName, context.now, rowCount)
                    LedgerResult.Ok(StoreWrite(id, WritePlan.Empty, importBatches = listOf(batch)))
                }
            }
        }

    override fun observeImportBatches(): Flow<List<ImportBatchView>> = store.readSnapshot { snapshot ->
        snapshot.importBatches.sortedByDescending { it.importedAt }
            .map { ImportBatchView(it.id, it.fileName, it.importedAt, it.rowCount, it.undoneAt) }
    }

    override suspend fun undoImport(id: ImportBatchId): LedgerResult<UndoImportResult> =
        store.writeWith { snapshot, context ->
            val batch = snapshot.importBatches.firstOrNull { it.id == id }
                ?: return@writeWith LedgerResult.Err(LedgerError.NotFound(id.value))
            val undone = if (batch.undoneAt == null) listOf(batch.copy(undoneAt = context.now)) else emptyList()
            LedgerResult.Ok(StoreWrite(UndoImportResult(emptyList()), WritePlan.Empty, importBatches = undone))
        }

    /** The canned preview of [fileName] against [snapshot]; nothing but the identity question until confirmed. */
    private fun cannedPreview(snapshot: StoreSnapshot, fileName: String, identity: ImportIdentity): ImportPreview {
        val withRows = identity !is ImportIdentity.NeedsConfirmation
        val invalid = withRows && "invalid" in fileName
        val conflict = if (withRows) snapshot.state.transfers.values.firstOrNull { !it.isDeleted } else null
        val rows = listOfNotNull(conflict).map {
            ImportRow(
                key = ImportRowKey(EntityType.TRANSFER, it.id.value),
                label = "Transfer of ${it.amount} on ${it.occurredOn}",
                changes = listOf(FieldChange("note", it.note, "Imported note")),
                choice = ImportRowChoice.KeepOrTake,
                changedSinceLastPreview = false,
            )
        }
        val invalidRows = if (invalid) listOf(InvalidRow("transfers", 3, "amount has too many decimals", LedgerError.TooManyDecimals(2))) else emptyList()
        return ImportPreview(
            id = store.ids.next(),
            fileName = fileName,
            generation = snapshot.generation,
            ledgerSeq = snapshot.ledgerSeq,
            identity = identity,
            counts = ImportCounts(new = if (withRows) 2 else 0, conflicts = rows.size, duplicates = if (withRows) 5 else 0, invalid = invalidRows.size),
            rows = rows,
            invalidRows = invalidRows,
            balanceChanges = emptyList(),
        )
    }
}

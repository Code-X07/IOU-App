# M0 Part 6: `ledger.ops` (the Write Path as Pure Functions) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-02-m0-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** Every `api` write as a pure function from (current state, input) to a validated `WritePlan` (rows to write, each with one revision, plus new FX snapshots), or a typed error. The fake (Part 7) applies plans in memory; M1's `LedgerWriter` applies the same plans in one Room transaction.

**Architecture:** Four objects in `ledger.ops`: `PeopleOps`, `GroupOps`, `EntryOps`, `RevertOps`. Each function checks the edit token or basis, builds the changed rows with fresh sync columns, and runs `LedgerValidator` on the state the plan would produce. Validation failure → the first violation's error (or `RestoreConflict` for a revert). Ops never write, never read the clock or generate IDs on their own: `WriteContext` supplies state, generation, time and IDs.

**Tech Stack:** Kotlin, JUnit 5, Kotest assertions and property tests.

## Global Constraints

- Every update, delete, restore, archive, merge and revert takes an `EditToken`; every other write carries a `basis`. A token or basis from another generation → `LedgerReplaced`; a version mismatch → `StaleVersion`; either way nothing is written (spec §5.1). A token's generation is checked before its row is looked up (`edited(...)`), so an edit prepared before a restore that removed the row still gets `LedgerReplaced`, not `NotFound`.
- `create`: `version = 1`, revision `CREATED`; `update`: `version + 1`, `updatedAt = now`, `UPDATED`; `delete`: set `deletedAt`, `version + 1`, `DELETED`; `restore`: clear `deletedAt`, `version + 1`, `RESTORED`. Archive, merge and unmerge are updates with a descriptive reason (spec §5.1).
- Owned rows cascade: deleting a group deletes its non-deleted memberships (me's included), deleting a person deletes their non-deleted payment handles, with the same `deletedAt` (one revision per row); restoring the owner restores exactly the owned rows whose `deletedAt` equals the owner's (spec §5.2).
- Merge writes only the source row (`mergedIntoId = target`, reason "Merged into <target>"); unmerge clears it (reason "Unmerged from <target>"); merging requires distinct, non-deleted, non-me, canonical people (spec §5.6, rule 11).
- Setting a default handle through the `api` clears the flag on every other handle of that type resolving to the same canonical person (spec §3.2). That covers every op that can set `isDefault`: add, update and revert.
- Group creation adds me automatically; group operations act on the canonical person: removing sets `removedAt` on every active membership of their records in that group, re-adding clears it on all of them (spec §3.4).
- Required effect currency, in order: CONVERT group → group currency; else a transfer draft's `settlesCurrency`; else the paid currency. On every save it is recomputed; no conversion needed → snapshot dropped, effect = original; same pair → the snapshot may be kept (rate-based: effect recomputed from its rate; `BANK_ACTUAL`: only while the paid amount is unchanged, else `FxSnapshotMismatch`); different pair → a new rate is required (spec §4.5).
- **Stored person references follow spec §5.6:** a created entry stores the canonical ID of each drafted person (transfer sender/receiver, expense payer; shares are canonical already), so an entry created after a merge stays with the target after an unmerge, even when its draft was opened before the merge. An update keeps the stored record while the drafted person still resolves to the same canonical person, so editing never rewrites who an old entry referenced.
- Stored expense shares are authoritative: they are replaced only when an input of the split changes (effect total, i.e. paid amount, paid currency or FX choice; split type; participants or their inputs). A recomputed split is resolved over canonical participants, records of one person combined (inputs added; one slot for EQUAL), and stores canonical IDs (spec §4.4).
- Revert to version N = `update()` with the business fields of snapshot N, identity and sync columns current, reason "Reverted to vN"; if today's rules reject it, nothing is written and `RestoreConflict(violations)` is returned (spec §5.3). "Identity" includes the links that only their own ops change: a person's `isMe` and `mergedIntoId` (setup, merge, unmerge), a handle's `personId`, and a membership's `groupId`, `personId` and `joinedAt`. So reverting a person to a version from before a merge never undoes the merge, and a revert never moves a handle or membership to another person or group.
- In the MVP, me is never part of a merge (spec §5.6, rule 9).

## Decisions this part makes

- Ops return `LedgerResult<Planned<T>>` where `Planned(value, plan)`: `value` is the new ID (creates) or `Unit`.
- Deleting something already deleted, restoring something not deleted, adding an active member and removing a removed one return an empty plan (no revision) rather than an error.
- The author of every write is me (`authorId` is updated on every write, spec §3.1 "always the me identity until sync").
- `FxChoice.Rate` with `source = BANK_ACTUAL` is rejected (`InvalidRate`); bank-actual goes through `FxChoice.BankActual`. A bank-actual snapshot's `rateDate` is the entry's `occurredOn`.
- A merge's preconditions are checked before the plan is built, so a self-merge returns `InvalidMerge(SAME_PERSON)` (the validator alone would report a rule-15 cycle).
- One default per type is kept by the ops that set `isDefault` (`clearedDefaults`), not by the validator: the resolver already copes with several defaults across a person's records (spec §3.2), and the ops are the only `api` path that sets the flag.
- `updateHandle` reads `draft.isDefault` as the effective default the view showed (`PaymentHandleView.isDefault`), not as the stored flag. Left unchanged, the stored flag is kept and nothing else is cleared, so a merged alias's hidden default survives an edit and applies again after an unmerge; only switching it on clears the others. Changing the type takes `draft.isDefault` as given. A revert clears the others of the reverted type only when it makes the handle that type's default: the flag turns on, or stays on while the type changes.

import io.github.codex07.iou.testutil.T0
import java.time.Instant

/** Applies plans the way the fake and LedgerWriter do: rows replaced, one revision per change. */
class OpsHarness(initial: LedgerState) {
    val generation = LedgerGeneration("gen-1")
    var state: LedgerState = initial
        private set
    val revisions = mutableListOf<EntryRevision>()
    var lastPlan: WritePlan? = null
        private set
    var now: Instant = T0.plusSeconds(60)
    private val ids = SequentialIds("op")

    init {
        val entities: List<LedgerEntity> = initial.people.values + initial.handles.values + initial.groups.values +
            initial.members.values + initial.entries
        entities.forEach { record(it, RevisionAction.CREATED, null) }
    }

    fun ctx(): WriteContext = WriteContext(state, generation, now, ids)

    fun <T> run(op: (WriteContext) -> LedgerResult<Planned<T>>): LedgerResult<T> {
        val result = op(ctx())
        if (result is LedgerResult.Ok) {
            val plan = result.value.plan
            lastPlan = plan
            state = state.applying(plan.changes, plan.snapshots)
            plan.changes.forEach { record(it.entity, it.action, it.reason) }
        }
        return result.map { it.value }
    }

    fun token(entity: LedgerEntity): EditToken = EditToken(generation, entity.meta.version)

    private fun record(entity: LedgerEntity, action: RevisionAction, reason: String?) {
        revisions += EntryRevision(
            id = RevisionId("rev-${revisions.size + 1}"), entityType = entity.entityType, entityId = entity.entityId,
            version = entity.meta.version, action = action, authorId = ME, deviceId = DeviceId("device-test"),
            at = now, reason = reason, snapshot = entity,
        )
    }
}

package io.github.codex07.iou.ledger.ops

import io.github.codex07.iou.ledger.model.Change
import io.github.codex07.iou.ledger.model.FxSnapshot
import io.github.codex07.iou.ledger.model.IdGenerator
import io.github.codex07.iou.ledger.model.LedgerGeneration
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.PersonId
import java.time.Instant

/** Everything an op may read: the current state, the live generation, the time and an ID source. */
data class WriteContext(
    val state: LedgerState,
    val generation: LedgerGeneration,
    val now: Instant,
    val ids: IdGenerator,
) {
    val meId: PersonId get() = state.me.id
}

/** Rows to write (one revision each) and new FX snapshots; already validated against the resulting state. */
data class WritePlan(
    val changes: List<Change>,
    val snapshots: List<FxSnapshot> = emptyList(),
) {
    val isEmpty: Boolean get() = changes.isEmpty() && snapshots.isEmpty()

    companion object {
        val Empty = WritePlan(emptyList())
    }
}

/** An op's result: the value for the caller (new ID or Unit) and the plan to apply. */
data class Planned<out T>(val value: T, val plan: WritePlan)

import io.github.codex07.iou.ledger.model.Change
import io.github.codex07.iou.ledger.model.FxSnapshot
import io.github.codex07.iou.ledger.model.Group
import io.github.codex07.iou.ledger.model.GroupId
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.LedgerGeneration
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.ledger.model.SyncMeta
import io.github.codex07.iou.ledger.rules.LedgerValidator
import io.github.codex07.iou.ledger.rules.WriteOp
import io.github.codex07.iou.money.MAX_MINOR
import io.github.codex07.iou.money.Money
import java.time.Instant

internal fun ResultScope.checkBasis(ctx: WriteContext, basis: LedgerGeneration) {
    ensure(basis == ctx.generation) { LedgerError.LedgerReplaced }
}

/** Generation first (`LedgerReplaced`), then version (`StaleVersion`) (spec §5.1). */
internal fun ResultScope.checkToken(ctx: WriteContext, entity: LedgerEntity, token: EditToken) {
    ensure(token.generation == ctx.generation) { LedgerError.LedgerReplaced }
    ensure(token.version == entity.meta.version) {
        LedgerError.StaleVersion(entity.entityId, token.version, entity.meta.version)
    }
}

/**
 * The row a token edits. Generation first, before the lookup: a token from a replaced ledger is
 * `LedgerReplaced` even when the restored ledger lacks the row. Then `NotFound`, then `StaleVersion`.
 */
internal fun <E : LedgerEntity> ResultScope.edited(ctx: WriteContext, token: EditToken, id: String, find: (LedgerState) -> E?): E {
    ensure(token.generation == ctx.generation) { LedgerError.LedgerReplaced }
    val entity = find(ctx.state) ?: fail(LedgerError.NotFound(id))
    checkToken(ctx, entity, token)
    return entity
}

internal fun ResultScope.checkAmount(money: Money) {
    ensure(money.amountMinor > 0) { LedgerError.InvalidAmount }
    ensure(money.amountMinor <= MAX_MINOR) { LedgerError.AmountTooLarge }
}

internal fun WriteContext.newMeta(): SyncMeta = SyncMeta(createdAt = now, updatedAt = now, authorId = meId)

/** The entity's next version: `version + 1`, `updatedAt = now`, author me, and the given deleted state. */
@Suppress("UNCHECKED_CAST")
internal fun <E : LedgerEntity> WriteContext.touch(entity: E, deletedAt: Instant? = entity.meta.deletedAt): E =
    entity.withMeta(
        entity.meta.copy(updatedAt = now, authorId = meId, version = entity.meta.version + 1, deletedAt = deletedAt),
    ) as E

/** Runs the validator on the state [changes] would produce; the first violation becomes the error. */
internal fun ResultScope.validated(ctx: WriteContext, changes: List<Change>, snapshots: List<FxSnapshot> = emptyList()): WritePlan {
    if (changes.isEmpty() && snapshots.isEmpty()) return WritePlan.Empty
    val violations = LedgerValidator.validate(ctx.state, ctx.state.applying(changes, snapshots), WriteOp.Edit(changes))
    if (violations.isNotEmpty()) fail(violations.first().error)
    return WritePlan(changes, snapshots)
}

internal fun ResultScope.person(ctx: WriteContext, id: PersonId): Person =
    ctx.state.people[id] ?: fail(LedgerError.NotFound(id.value))

internal fun ResultScope.group(ctx: WriteContext, id: GroupId): Group =
    ctx.state.groups[id] ?: fail(LedgerError.NotFound(id.value))

internal fun String?.cleaned(): String? = this?.trim()?.ifEmpty { null }

package io.github.codex07.iou.ledger.ops

import io.github.codex07.iou.api.EditToken
import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.api.PersonDraft
import io.github.codex07.iou.api.ledgerResult
import io.github.codex07.iou.ledger.model.Change
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.LedgerGeneration
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.ledger.model.RevisionAction
import io.github.codex07.iou.ledger.model.SyncMeta

/** People, payment handles, merge and unmerge (spec §5.2, §5.6). */
object PeopleOps {

    /** First launch: creates me, the permanent global identity (spec §3.1). */
    fun setup(ctx: WriteContext, displayName: String): LedgerResult<Planned<PersonId>> = ledgerResult {
        ensure(ctx.state.meOrNull == null) { LedgerError.CannotModifyMe }
        val id = PersonId(ctx.ids.next())
        val me = Person(id = id, displayName = displayName.trim(), isMe = true, meta = SyncMeta(ctx.now, ctx.now, id))
        Planned(id, validated(ctx, listOf(Change(me, RevisionAction.CREATED))))
    }

    fun createPerson(ctx: WriteContext, draft: PersonDraft, basis: LedgerGeneration): LedgerResult<Planned<PersonId>> =
        ledgerResult {
            checkBasis(ctx, basis)
            val person = Person(
                id = PersonId(ctx.ids.next()),
                displayName = draft.displayName.trim(),
                note = draft.note.cleaned(),
                defaultCurrency = draft.defaultCurrency,
                meta = ctx.newMeta(),
            )
            Planned(person.id, validated(ctx, listOf(Change(person, RevisionAction.CREATED))))
        }

    fun updatePerson(ctx: WriteContext, id: PersonId, draft: PersonDraft, token: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val person = edited(ctx, token, id.value) { it.people[id] }
            val updated = ctx.touch(
                person.copy(displayName = draft.displayName.trim(), note = draft.note.cleaned(), defaultCurrency = draft.defaultCurrency),
            )
            Planned(Unit, validated(ctx, listOf(Change(updated, RevisionAction.UPDATED))))
        }

    fun setPersonArchived(ctx: WriteContext, id: PersonId, archived: Boolean, token: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val person = edited(ctx, token, id.value) { it.people[id] }
            val updated = ctx.touch(person.copy(archivedAt = if (archived) person.archivedAt ?: ctx.now else null))
            val reason = if (archived) "Archived" else "Unarchived"
            Planned(Unit, validated(ctx, listOf(Change(updated, RevisionAction.UPDATED, reason))))
        }

    /** Deletes the person and their live handles with one `deletedAt` (spec §5.2). */
    fun deletePerson(ctx: WriteContext, id: PersonId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val person = edited(ctx, token, id.value) { it.people[id] }
        if (person.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)

            Change(ctx.touch(it, deletedAt = null), RevisionAction.RESTORED)
        }

    fun addHandle(ctx: WriteContext, personId: PersonId, draft: HandleDraft, basis: LedgerGeneration): LedgerResult<Planned<HandleId>> =
        ledgerResult {
            checkBasis(ctx, basis)
            person(ctx, personId)
            val handle = PaymentHandle(
                id = HandleId(ctx.ids.next()),
                personId = personId,
                type = draft.type,
                value = FieldRules.normalizeHandleValue(draft.type, draft.value).bind(),
                holderName = draft.holderName.cleaned(),
                bic = draft.bic.cleaned()?.uppercase(),
                label = draft.label.trim(),
                isDefault = draft.isDefault,
                meta = ctx.newMeta(),
            )
            val changes = listOf(Change(handle, RevisionAction.CREATED)) + clearedDefaults(ctx, handle)
            Planned(handle.id, validated(ctx, changes))
        }

    fun updateHandle(ctx: WriteContext, id: HandleId, draft: HandleDraft, token: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val handle = edited(ctx, token, id.value) { it.handles[id] }
            // The draft's isDefault is the effective default the view showed. Left as shown, the stored flag stays
            // (a merged alias's own default survives for unmerge) and no other record's flag is cleared.
            val resolver = IdentityResolver(ctx.state)
            val sameType = draft.type == handle.type
            val wasDefault = sameType && resolver.defaultHandle(resolver.canonical(handle.personId), handle.type)?.id == handle.id
            val updated = ctx.touch(
                handle.copy(
                    type = draft.type,
                    value = FieldRules.normalizeHandleValue(draft.type, draft.value).bind(),
                    holderName = draft.holderName.cleaned(),
                    bic = draft.bic.cleaned()?.uppercase(),
                    label = draft.label.trim(),
                    isDefault = if (sameType && draft.isDefault == wasDefault) handle.isDefault else draft.isDefault,
                ),
            )
            val moved = if (draft.isDefault && !wasDefault) clearedDefaults(ctx, updated) else emptyList()
            val changes = listOf(Change(updated, RevisionAction.UPDATED)) + moved
            Planned(Unit, validated(ctx, changes))
        }

    fun deleteHandle(ctx: WriteContext, id: HandleId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val handle = edited(ctx, token, id.value) { it.handles[id] }
        if (handle.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)
        Planned(Unit, validated(ctx, listOf(Change(ctx.touch(handle, deletedAt = ctx.now), RevisionAction.DELETED))))
    }

    /** Sets `mergedIntoId` on the source only; collisions resolve at read time (spec §5.6). */
    fun merge(ctx: WriteContext, source: PersonId, target: PersonId, sourceToken: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val from = edited(ctx, sourceToken, source.value) { it.people[source] }
            val into = person(ctx, target)
            ensure(source != target) { LedgerError.InvalidMerge(MergeProblem.SAME_PERSON) }
            ensure(!from.isMe && !into.isMe) { LedgerError.CannotModifyMe }
            ensure(!from.isDeleted && !into.isDeleted) { LedgerError.InvalidMerge(MergeProblem.DELETED) }
            ensure(from.mergedIntoId == null && into.mergedIntoId == null) { LedgerError.InvalidMerge(MergeProblem.NOT_CANONICAL) }
            val merged = ctx.touch(from.copy(mergedIntoId = target))
            Planned(Unit, validated(ctx, listOf(Change(merged, RevisionAction.UPDATED, "Merged into ${into.displayName}"))))
        }

    /** Splits the person off with its own aliases (spec §5.6). Rule 12: must be merged. */
    fun unmerge(ctx: WriteContext, personId: PersonId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val person = edited(ctx, token, personId.value) { it.people[personId] }
        val target = person.mergedIntoId ?: fail(LedgerError.InvalidMerge(MergeProblem.NOT_MERGED))
        val targetName = ctx.state.people[target]?.displayName ?: target.value
        val split = ctx.touch(person.copy(mergedIntoId = null))
        Planned(Unit, validated(ctx, listOf(Change(split, RevisionAction.UPDATED, "Unmerged from $targetName"))))
    }

    /** Spec §3.2: a new default clears the flag on other handles of the type for the same canonical person. */
    internal fun clearedDefaults(ctx: WriteContext, handle: PaymentHandle): List<Change> {
        if (!handle.isDefault) return emptyList()
        val resolver = IdentityResolver(ctx.state)
        return resolver.handlesOf(resolver.canonical(handle.personId))
            .filter { it.id != handle.id && it.type == handle.type && it.isDefault }
            .map { Change(ctx.touch(it.copy(isDefault = false)), RevisionAction.UPDATED, "Default moved to ${handle.label}") }
    }

import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.ledger.model.RevisionAction

/** Groups and canonical membership (spec §3.4, §5.2). */
object GroupOps {

    fun createGroup(ctx: WriteContext, draft: GroupDraft, members: List<PersonId>, basis: LedgerGeneration): LedgerResult<Planned<GroupId>> =
        ledgerResult {
            checkBasis(ctx, basis)
            val resolver = IdentityResolver(ctx.state)
            val group = Group(GroupId(ctx.ids.next()), draft.name.trim(), draft.defaultCurrency, draft.fxMode, meta = ctx.newMeta())
            members.forEach { person(ctx, it) }
            val people = (listOf(ctx.meId) + members.map(resolver::canonical)).distinct()
            val memberships = people.map { membership(ctx, group.id, it) }
            val changes = (listOf<LedgerEntity>(group) + memberships).map { Change(it, RevisionAction.CREATED) }
            Planned(group.id, validated(ctx, changes))
        }

    fun updateGroup(ctx: WriteContext, id: GroupId, draft: GroupDraft, token: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val group = edited(ctx, token, id.value) { it.groups[id] }
            val updated = ctx.touch(group.copy(name = draft.name.trim(), defaultCurrency = draft.defaultCurrency, fxMode = draft.fxMode))
            Planned(Unit, validated(ctx, listOf(Change(updated, RevisionAction.UPDATED))))
        }

    /** Archiving = leaving; allowed with an open balance (spec §5.2). */
    fun setGroupArchived(ctx: WriteContext, id: GroupId, archived: Boolean, token: EditToken): LedgerResult<Planned<Unit>> =
        ledgerResult {
            val group = edited(ctx, token, id.value) { it.groups[id] }
            val updated = ctx.touch(group.copy(archivedAt = if (archived) group.archivedAt ?: ctx.now else null))
            val reason = if (archived) "Archived" else "Unarchived"
            Planned(Unit, validated(ctx, listOf(Change(updated, RevisionAction.UPDATED, reason))))
        }

    fun deleteGroup(ctx: WriteContext, id: GroupId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val group = edited(ctx, token, id.value) { it.groups[id] }
        if (group.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)
        val memberships = ctx.state.members.values.filter { it.groupId == id && !it.isDeleted }
        val changes = (listOf<LedgerEntity>(group) + memberships).map {
            Change(ctx.touch(it, deletedAt = ctx.now), RevisionAction.DELETED)
        }
        Planned(Unit, validated(ctx, changes))
    }

    fun restoreGroup(ctx: WriteContext, id: GroupId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val group = edited(ctx, token, id.value) { it.groups[id] }
        if (!group.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)
        val deletedAt = group.meta.deletedAt
        val memberships = ctx.state.members.values.filter { it.groupId == id && it.meta.deletedAt == deletedAt }
        val changes = (listOf<LedgerEntity>(group) + memberships).map {
            Change(ctx.touch(it, deletedAt = null), RevisionAction.RESTORED)
        }
        Planned(Unit, validated(ctx, changes))
    }

    /** Adds the canonical person, or re-adds them by clearing `removedAt` on all their memberships. */
    fun addMember(ctx: WriteContext, groupId: GroupId, personId: PersonId, basis: LedgerGeneration): LedgerResult<Planned<Unit>> =
        ledgerResult {
            checkBasis(ctx, basis)
            group(ctx, groupId)
            person(ctx, personId)
            val resolver = IdentityResolver(ctx.state)
            val canonical = resolver.canonical(personId)
            val memberships = resolver.memberships(groupId, canonical)
            val changes = when {
                memberships.any { it.removedAt == null } -> emptyList()
                memberships.isNotEmpty() -> memberships.map {
                    Change(ctx.touch(it.copy(removedAt = null)), RevisionAction.UPDATED, "Re-added")
                }
                else -> listOf(Change(membership(ctx, groupId, canonical), RevisionAction.CREATED))
            }
            Planned(Unit, validated(ctx, changes))
        }

    /** Sets `removedAt` on every active membership of the canonical person (rules 2 and 4 apply). */
    fun removeMember(ctx: WriteContext, groupId: GroupId, personId: PersonId, basis: LedgerGeneration): LedgerResult<Planned<Unit>> =
        ledgerResult {
            checkBasis(ctx, basis)
            group(ctx, groupId)
            person(ctx, personId)
            val resolver = IdentityResolver(ctx.state)
            val canonical = resolver.canonical(personId)
            ensure(canonical != ctx.meId) { LedgerError.CannotModifyMe }
            val changes = resolver.memberships(groupId, canonical)
                .filter { it.removedAt == null }
                .map { Change(ctx.touch(it.copy(removedAt = ctx.now)), RevisionAction.UPDATED, "Removed from group") }
            Planned(Unit, validated(ctx, changes))
        }

    private fun membership(ctx: WriteContext, groupId: GroupId, personId: PersonId) =
        GroupMember(MembershipId(ctx.ids.next()), groupId, personId, joinedAt = ctx.now, meta = ctx.newMeta())
}

/** What saving an expense draft would store (no write). */
data class SharePreview(val effectTotal: Money, val shares: List<ExpenseShare>, val recomputed: Boolean)

/** Transfers and expenses: FX choices (spec §4.5), split recompute rules (spec §4.4), delete and restore. */
object EntryOps {

    fun saveTransfer(ctx: WriteContext, draft: TransferDraft, mode: SaveMode): LedgerResult<Planned<EntryId>> = ledgerResult {
        val existing: Transfer? = when (mode) {
            is SaveMode.Create -> {
                checkBasis(ctx, mode.basis)
                null
            }
            is SaveMode.Update -> edited(ctx, mode.token, mode.id.value) { it.transfers[mode.id] }
        }
        checkAmount(draft.amount)
        val required = requiredEffectCurrency(ctx.state, draft.groupId, draft.amount.currency, draft.settlesCurrency)
        val fx = resolveFx(ctx, draft.amount, required, draft.fx, existing, draft.occurredOn)

        val resolver = IdentityResolver(ctx.state)
        val transfer = Transfer(
            id = existing?.id ?: EntryId(ctx.ids.next()),
            fromPersonId = storedPerson(resolver, draft.from, existing?.fromPersonId),
            toPersonId = storedPerson(resolver, draft.to, existing?.toPersonId),
            amount = draft.amount,
            effectAmount = fx.effect,
            fxSnapshotId = fx.snapshotId,
            kind = draft.kind,
            method = draft.method,
            accountLabel = draft.accountLabel.cleaned(),
            groupId = draft.groupId,
            occurredOn = draft.occurredOn,
            note = draft.note.cleaned(),
            meta = existing?.meta ?: ctx.newMeta(),
        ).let { if (existing == null) it else ctx.touch(it) }

        val action = if (existing == null) RevisionAction.CREATED else RevisionAction.UPDATED
        Planned(transfer.id, validated(ctx, listOf(Change(transfer, action)), listOfNotNull(fx.newSnapshot)))
    }

    fun saveExpense(ctx: WriteContext, draft: ExpenseDraft, mode: SaveMode): LedgerResult<Planned<EntryId>> = ledgerResult {
        val existing: Expense? = when (mode) {
            is SaveMode.Create -> {
                checkBasis(ctx, mode.basis)
                null
            }
            is SaveMode.Update -> edited(ctx, mode.token, mode.id.value) { it.expenses[mode.id] }
        }
        val (fx, preview) = sharesFor(ctx, draft, existing)

        val expense = Expense(
            id = existing?.id ?: EntryId(ctx.ids.next()),
            groupId = draft.groupId,
            payerPersonId = storedPerson(IdentityResolver(ctx.state), draft.payer, existing?.payerPersonId),
            description = draft.description.trim(),
            category = draft.category,
            total = draft.total,
            effectTotal = preview.effectTotal,
            fxSnapshotId = fx.snapshotId,
            splitType = draft.splitType,
            shares = preview.shares,
            occurredOn = draft.occurredOn,
            note = draft.note.cleaned(),
            meta = existing?.meta ?: ctx.newMeta(),
        ).let { if (existing == null) it else ctx.touch(it) }

        val action = if (existing == null) RevisionAction.CREATED else RevisionAction.UPDATED
        Planned(expense.id, validated(ctx, listOf(Change(expense, action)), listOfNotNull(fx.newSnapshot)))
    }

    /** The shares a save would store, for `previewSplit` (spec §4.4). Writes nothing. */
    fun previewShares(ctx: WriteContext, draft: ExpenseDraft, existing: Expense?): LedgerResult<SharePreview> =
        ledgerResult { sharesFor(ctx, draft, existing).second }

    fun deleteEntry(ctx: WriteContext, id: EntryId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val entry = edited(ctx, token, id.value) { it.entry(id) }
        if (entry.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)
        Planned(Unit, validated(ctx, listOf(Change(ctx.touch(entry, deletedAt = ctx.now), RevisionAction.DELETED))))
    }

    fun restoreEntry(ctx: WriteContext, id: EntryId, token: EditToken): LedgerResult<Planned<Unit>> = ledgerResult {
        val entry = edited(ctx, token, id.value) { it.entry(id) }
        if (!entry.isDeleted) return@ledgerResult Planned(Unit, WritePlan.Empty)
        Planned(Unit, validated(ctx, listOf(Change(ctx.touch(entry, deletedAt = null), RevisionAction.RESTORED))))
    }

    /** Spec §4.5: CONVERT group currency, else the transfer's `settlesCurrency`, else the paid currency. */
    fun requiredEffectCurrency(state: LedgerState, groupId: GroupId?, paid: CurrencyCode, settlesCurrency: CurrencyCode?): CurrencyCode {
        val group = groupId?.let { state.groups[it] }
        return when {
            group != null && group.fxMode == FxMode.CONVERT -> group.defaultCurrency
            settlesCurrency != null -> settlesCurrency
            else -> paid
        }
    }

    /** Canonical participants, records of one person combined: inputs added, one slot for EQUAL (spec §4.4). */
    fun combineInputs(inputs: List<SplitInput>, type: SplitType, resolver: IdentityResolver): List<SplitInput> {
        val combined = LinkedHashMap<PersonId, Long?>()
        for (input in inputs) {
            val person = resolver.canonical(input.personId)
            combined[person] = when {
                type == SplitType.EQUAL -> null
                person !in combined -> input.value
                else -> {
                    val a = combined[person]
                    val b = input.value
                    if (a == null || b == null) null else Math.addExact(a, b)
                }
            }
        }
        return combined.map { (person, value) -> SplitInput(person, value) }
    }

    /** The stored split as an edit draft shows it. */
    fun splitInputsOf(expense: Expense, resolver: IdentityResolver): List<SplitInput> =
        combineInputs(expense.shares.map { SplitInput(it.personId, it.inputValue) }, expense.splitType, resolver)

    // ---- internals ----

    /**
     * The ID to store for a drafted person (spec §5.6): the canonical person, so a new entry stays with the
     * merge target after an unmerge; an edit keeps the stored record while it resolves to the same person.
     */
    private fun storedPerson(resolver: IdentityResolver, drafted: PersonId, stored: PersonId?): PersonId {
        val canonical = resolver.canonical(drafted)
        return if (stored != null && resolver.canonical(stored) == canonical) stored else canonical
    }

    private data class FxResolution(val effect: Money, val snapshotId: FxSnapshotId?, val newSnapshot: FxSnapshot?)

    private fun ResultScope.sharesFor(ctx: WriteContext, draft: ExpenseDraft, existing: Expense?): Pair<FxResolution, SharePreview> {
        checkAmount(draft.total)
        val required = requiredEffectCurrency(ctx.state, draft.groupId, draft.total.currency, settlesCurrency = null)
        val fx = resolveFx(ctx, draft.total, required, draft.fx, existing, draft.occurredOn)
        val resolver = IdentityResolver(ctx.state)
        val inputs = combineInputs(draft.participants, draft.splitType, resolver)

        val keep = existing != null &&
            (draft.fx == null || draft.fx == FxChoice.KeepExisting) &&
            draft.total == existing.total &&
            fx.effect == existing.effectTotal &&
            draft.splitType == existing.splitType &&
            inputs.toSet() == splitInputsOf(existing, resolver).toSet()

        val shares = if (keep) {
            existing!!.shares
        } else {
            SplitResolver.resolve(draft.splitType, fx.effect.amountMinor, draft.total.amountMinor, inputs).bind()
        }
        return fx to SharePreview(fx.effect, shares, recomputed = !keep)
    }

    private fun ResultScope.resolveFx(
        ctx: WriteContext,
        paid: Money,
        required: CurrencyCode,
        choice: FxChoice?,
        existing: Entry?,
        occurredOn: LocalDate,
    ): FxResolution {
        if (required == paid.currency) return FxResolution(paid, null, null)
        val mismatch = LedgerError.FxSnapshotMismatch(existing?.id)
        return when (choice) {
            null -> fail(LedgerError.RateRequired(paid.currency, required))

            FxChoice.KeepExisting -> {
                val snapshot = existing?.fxSnapshotId?.let { ctx.state.fxSnapshots[it] } ?: fail(mismatch)
                ensure(snapshot.baseCurrency == paid.currency && snapshot.quoteCurrency == required) { mismatch }
                val effect = if (snapshot.source == FxSource.BANK_ACTUAL) {
                    ensure(snapshot.paidMinor == paid.amountMinor) { mismatch }
                    Money(snapshot.chargedMinor!!, required)
                } else {
                    FxConverter.convert(paid, required, snapshot.rate).bind()
                }
                FxResolution(effect, snapshot.id, null)
            }

            is FxChoice.Rate -> {
                val quote = choice.quote
                ensure(quote.base == paid.currency && quote.quote == required) { mismatch }
                ensure(quote.source != FxSource.BANK_ACTUAL) { LedgerError.InvalidRate(quote.rate) }
                val effect = FxConverter.convert(paid, required, quote.rate).bind()
                val snapshot = FxSnapshot(
                    id = FxSnapshotId(ctx.ids.next()), baseCurrency = paid.currency, quoteCurrency = required,
                    rate = quote.rate.trim(), rateDate = quote.rateDate, source = quote.source,
                    isStale = quote.isStale, fetchedAt = ctx.now,
                )
                FxResolution(effect, snapshot.id, snapshot)
            }

            is FxChoice.BankActual -> {
                ensure(choice.charged.currency == required) { mismatch }
                checkAmount(choice.charged)
                val snapshot = FxSnapshot(
                    id = FxSnapshotId(ctx.ids.next()), baseCurrency = paid.currency, quoteCurrency = required,
                    rate = FxConverter.deriveRate(paid, choice.charged), rateDate = occurredOn,
                    source = FxSource.BANK_ACTUAL, isStale = false, fetchedAt = ctx.now,
                    paidMinor = paid.amountMinor, chargedMinor = choice.charged.amountMinor,
                )
                FxResolution(choice.charged, snapshot.id, snapshot)
            }
        }
    }
}

import io.github.codex07.iou.api.EditToken
import io.github.codex07.iou.api.EntityRef

import io.github.codex07.iou.ledger.model.EntryRevision
import io.github.codex07.iou.ledger.model.GroupMember
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.PaymentHandle
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.RevisionAction
import io.github.codex07.iou.ledger.rules.LedgerValidator
import io.github.codex07.iou.ledger.rules.WriteOp

/** Revert to version (spec §5.3). */
object RevertOps {

    fun revertTo(
        ctx: WriteContext,
        ref: EntityRef,
        version: Int,
        token: EditToken,
        revisions: List<EntryRevision>,
    ): LedgerResult<Planned<Unit>> = ledgerResult {
        val current = edited(ctx, token, ref.id) { it.entity(ref.type, ref.id) }
        val snapshot = revisions
            .firstOrNull { it.entityType == ref.type && it.entityId == ref.id && it.version == version }
            ?.snapshot ?: fail(LedgerError.NotFound("${ref.id} v$version"))

        // Business fields from the snapshot; identity, links and sync columns (including the deleted state) stay current.
        val reverted = ctx.touch(businessFieldsOf(snapshot, current))
        // A revert that makes a handle the default of a type (flag turned on, or kept on while the type changes)
        // sets it through the api: it clears the others of that type (spec §3.2). A default that stays the
        // default of the same type leaves the other records' flags as they are.
        val clearedDefaults = (reverted as? PaymentHandle)
            ?.takeIf { it.isDefault && !(current as PaymentHandle).let { now -> now.isDefault && now.type == it.type } }
            ?.let { PeopleOps.clearedDefaults(ctx, it) }.orEmpty()
        val changes = listOf(Change(reverted, RevisionAction.UPDATED, "Reverted to v$version")) + clearedDefaults
        val violations = LedgerValidator.validate(ctx.state, ctx.state.applying(changes), WriteOp.Edit(changes))
        ensure(violations.isEmpty()) { LedgerError.RestoreConflict(violations) }
        Planned(Unit, WritePlan(changes))
    }

    /** [old]'s business fields on [current]'s identity: links only their own ops change stay as they are now. */
    private fun businessFieldsOf(old: LedgerEntity, current: LedgerEntity): LedgerEntity = when (old) {
        is Person -> (current as Person).let { old.copy(isMe = it.isMe, mergedIntoId = it.mergedIntoId) }
        is PaymentHandle -> (current as PaymentHandle).let { old.copy(personId = it.personId) }
        is GroupMember -> (current as GroupMember).let { old.copy(groupId = it.groupId, personId = it.personId, joinedAt = it.joinedAt) }
        else -> old
    }.withMeta(current.meta)
}

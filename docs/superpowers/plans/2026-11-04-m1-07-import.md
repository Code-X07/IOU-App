# M1 Part 7: Own-Export Import with Undo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** The `real` flavor imports its own normalized exports (Part 6). It reads them within limits and decodes every row with row-level errors. It maps another install's identity once the user confirms, classifies rows as new, duplicate or conflict, and validates them with attribution. The preview shows the person → payment-handle cascades, and the commit writes in one transaction with an `ImportBatch`. Undo is best-effort. The import/export contract suite passes against the real backend (AC M1-9, 10, 11, 16, 20, 21).

**Architecture:** Package `io` gains four pieces:
- `ImportReader`: zip, limits, manifest, CSV rows by header, unescaping.
- `ImportDecoder`: rows to records, with an `InvalidRow` for each problem.
- `ImportAnalysis`: identity mapping, classification, validation with attribution, and, for given choices, preview rows, balance changes and the commit plan.
- `ImportUndo`: the undo plan, from the revisions tagged with the batch.

`data.RealImportExportApi` keeps a parsed file in memory as a session under its preview's ID. It runs commit and undo through `LedgerStore.writeWith`, so they check generation and `ledgerSeq` and land in one journal transaction.

**Tech Stack:** Apache Commons CSV 1.14.1, `java.util.zip`, kotlinx.serialization, the M0 `ledger` packages (`LedgerValidator`, `FieldRules`, `RevisionDiff`, `LedgerEngine`), JUnit 5, Kotest.

## Global Constraints

- **Version numbers from the file never decide which side wins** (spec §7.4). Each incoming row is classified by UUID:
  - unknown: **new**, created at local version 1 with revision `CREATED`, reason "Imported from <file> (source v<N>)". A row deleted in the source is created and then deleted in the same transaction.
  - business fields and deleted state identical: **duplicate**, skipped.
  - otherwise: **conflict**, with a field diff that includes "active → deleted". The choice is keep local (default) or take incoming. Take incoming writes an `update` (and a `delete` or `restore`), reason "Import conflict resolved from <file> (source v<N>)".
- **Compared fields:** sync columns are ignored, except that `deletedAt` is compared as a deleted / not-deleted state (spec §7.4).
- **Deleted owners keep their cascade; an owned row's deleted state has a choice of its own only while its owner stays active and is not restored by this import.** The preview shows the forced outcome, "deleted with <owner>" or "restored with <owner>" (spec §7.4).
- **FX snapshots** are classified on their own:
  - unknown: inserted;
  - identical: duplicate;
  - different: an invalid row, and every entry that would be written with it is invalid too (spec §7.4).
- **Audit:** every imported entity's local history starts with a revision naming the file and source version (spec §7.4).
- **Import is checked against the state invariants, not the edit rules** (spec §7.4).
- **Identity mapping:** the same me UUID is imported as is. A different one needs confirmation. On confirmation, every reference to the source me becomes the local me, the source me's row is not imported, and the origin revision records "source identity <uuid> mapped to me". Declining gives `ForeignLedger` (spec §7.4).
- **Pipeline:** parse, map, validate each row (amounts with `BigDecimal`, never `Double`), then the state invariants over the complete resulting state with violations attributed to rows, then classify, preview and commit (spec §7.5).
- **Commit:** it checks the preview's generation (`LedgerReplaced`) and `ledgerSeq` (`ImportPreviewStale` after any write since the preview). `refreshPreview` keeps choices for unchanged rows and flags new or changed ones. Creates and updates go in dependency order, then deletions (entries; owned rows on their own; owners with their cascade). The state invariants are checked once, on the final state (spec §7.5).
- **Limits:** 20 MB per file, 100 000 rows; at most 50 zip entries, 200 MB uncompressed in total, compression ratio at most 100 (spec §7.5). Count all zip entries, including unknown names, and reject duplicate names. Enforce the global row budget while parsing; reject duplicate CSV headers and malformed CSV as corrupt files.
- **Undo** (spec §5.4), in one transaction:
  - Rows the batch created are deleted. Rows it updated are reverted to their pre-import snapshot, only if their version is still the one the import wrote.
  - Order: entries, then owned rows undone on their own, then owners. Owned rows that changed with their owner go back through the owner's cascade.
  - A step that would break an invariant waits and is tried again once the others are done, until a round applies nothing. A later step can be what makes it valid: a transfer the import moved from X to Y, with X then deleted, goes back to X only after the owner step restores X.
  - Undo protection wins over the cascade.
  - FX snapshots stay. Rows that changed since the import, or whose undo would break an invariant, are skipped and listed.
  - The reason is "Undo import <file>", and `ImportBatch.undoneAt` is set.

## Decisions this part makes

- **Group rows wait for M2** (index, locked decision 6). Rows of `groups` and `group_members`, and entries with a `group_id`, are invalid rows with the reason "group rows are imported from M2 on". In M1, the only owner → owned cascade is a person and their payment handles.
- **Row numbers are file rows:** the header is row 1, the first data row row 2. An empty cell is null.
- **Amounts** are parsed from the decimal column with `MoneyParser` (`TooManyDecimals`, `AmountTooLarge`, `InvalidAmount`) and must equal their `*_minor` column (`CorruptData("<column> mismatch")`).
  - Unknown currencies give `UnknownCurrency`, invalid rates `InvalidRate`, and bad dates, enums and booleans `InvalidField(column)`.
  - Duplicate IDs in one table give `CorruptData("duplicate id …")`, and a share whose expense isn't in the file gives `CorruptData("orphan share")`. Validate each applicable share before sorting by position; attribute bad shares to their own rows and omit the expense if any share is invalid.
- **Validation and attribution:**
  1. Each row to be written gets the field rules on its own.
  2. The state invariants run over the complete resulting state: every row, every conflict taken, through the same cascade-aware plan the commit uses. If it holds, no row is invalid. Example: a person deleted together with the transfers that involve them is valid as a whole, though the person alone would leave active transfers pointing at a deleted person.
  3. Otherwise rows are blamed: a row is invalid with a violation that goes away when it is left out. A new person is left out together with the rows that name them, since dangling references would make the validator report only the broken structure (rule 15) and hide the violation being tested. The person is then to blame only for a violation that stays while just those rows are left out. People and handles answer first, for the violations that remain when the incoming active entries are left out too (incoming deletions stay in). Then entries answer for the rest (AC M1-16: two deleted people merged into each other; AC M1-20).
  4. Each round repeats until nothing is broken or no single row is to blame, and both passes run again while either blames a row, since one broken rule can hide others (structural checks stop the validator early). Example: a deleted transfer that names an unknown person hides an invalid deletion until the entries pass rejects the transfer; the next people pass then blames the deletion.
  - A conflict that couldn't be taken is therefore an invalid row.
  - A valid file costs one validator run. An invalid one costs about one run per row and round. That is fine for a personal ledger; the 100 000-row limit is a size guard, not a performance target.
- **Deleted at a different time:** an owned row that the file shows deleted at a different time than its deleted owner is deleted on its own, 1 ns before the owner's cascade, so the shared `deletedAt` still names exactly what went together. That holds for a handle the import creates and for an existing one whose owner the import deletes, whether or not the handle's own conflict is taken (its deleted state is not a choice there).
  - Under an owner that stays deleted locally, a new handle gets the owner's local `deletedAt`, unless the file shows it deleted apart from the owner (compared with the owner's row in the file, even when that row duplicates the local one). Then it is deleted 1 ns before the owner's local deletion, so restoring the owner leaves it deleted (spec §7.4).
- **Preview rows** are the conflicts, plus every row whose deleted state a cascade forces. That includes local handles that aren't in the file, so a handle added after the preview shows up in the refreshed cascade (AC M1-21).
- **Sessions:** a parsed file stays in memory under its preview's ID with the last choices passed to `applyChoices`. `refreshPreview` reuses those choices. Sessions don't survive the process: a preview from before a restart gives `NotFound("preview")`.
- **The commit** binds the cached analysis to the exact immutable snapshot under the write lock; an out-of-order refresh whose analysis has an older basis returns `ImportPreviewStale`. It writes an `ImportBatch` even when every row was a duplicate. `rowCount` is the number of distinct rows written plus new snapshots. The final state is validated once; its first violation is the error.
- **`importBatchId` names the batch that wrote an entity's current version.** `touch` (M0's `OpsSupport`) now clears it, so a later edit's revision isn't tagged with the import. Undo finds the import's revisions by batch ID and calls a row unchanged when its version is still the last one the import wrote.
- **Undo works out "changed with its owner" from the data:**
  - a handle the batch created under a person it created;
  - a handle restored with a person the batch restored (same pre-import `deletedAt`);
  - a handle deleted with a person the batch deleted (same `deletedAt`).
  - What undo reverts gets its pre-import business fields back, through the owner's cascade too: undoing an import that restored a person and their handle with new values deletes both with the old values.
  - Undo writes are not tagged with a batch. Each step is validated. A step that still breaks an invariant when a whole retry round applies nothing is skipped with "would break rule N". Undoing an undone batch does nothing.
- **Before setup**, `parseImport` gives `NotFound("me")`. The file name is the last segment of the document URI, URL-decoded (SAF URIs encode the path).
- **`readAtMost`** moves from `data.BackupCipher` to `store` next to `DocumentStore`, so `io` can use it.
- **The fake is unchanged:** it keeps its canned previews.

package io.github.codex07.iou.testutil

import java.io.ByteArrayInputStream
import java.io.ByteArrayOutputStream
import java.util.zip.ZipEntry
import java.util.zip.ZipInputStream
import java.util.zip.ZipOutputStream

/** Zip files as ordered maps of entry name to text, for building and editing import files in tests. */
object Zips {
    fun read(bytes: ByteArray): LinkedHashMap<String, String> {
        val entries = linkedMapOf<String, String>()
        ZipInputStream(ByteArrayInputStream(bytes)).use { zip ->
            while (true) {
                val entry = zip.nextEntry ?: break
                entries[entry.name] = zip.readBytes().toString(Charsets.UTF_8)
            }
        }
        return entries
    }

    fun write(entries: Map<String, String>): ByteArray {
        val out = ByteArrayOutputStream()
        ZipOutputStream(out).use { zip ->
            for ((name, text) in entries) {
                zip.putNextEntry(ZipEntry(name))
                zip.write(text.toByteArray(Charsets.UTF_8))
                zip.closeEntry()
            }
        }
        return out.toByteArray()
    }

    /** Builds an archive with two identical names by renaming equal-length ZIP header names. */
    fun duplicateName(bytes: ByteArray, first: String, second: String): ByteArray {
        require(first.length == second.length)
        val entries = read(bytes).also { it[first] = "a"; it[second] = "b" }
        val archive = write(entries)
        val from = second.toByteArray(Charsets.UTF_8)
        val to = first.toByteArray(Charsets.UTF_8)
        for (i in 0..archive.size - from.size) {
            if (from.indices.all { archive[i + it] == from[it] }) {
                to.copyInto(archive, i)
            }
        }
        return archive
    }

    /** [bytes] with [name]'s text transformed. */
    fun edit(bytes: ByteArray, name: String, transform: (String) -> String): ByteArray =
        write(read(bytes).also { it[name] = transform(it.getValue(name)) })
}

package io.github.codex07.iou.io

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.store.readAtMost
import java.io.ByteArrayInputStream
import java.io.IOException
import java.io.UncheckedIOException
import java.util.zip.ZipException
import java.util.zip.ZipInputStream
import kotlinx.serialization.SerializationException
import kotlinx.serialization.json.Json
import org.apache.commons.csv.CSVFormat

/** One data row: its row number in the file (the header is row 1) and its cells by column name. */
data class CsvRow(val number: Int, val cells: Map<String, String>)

/** A normalized export as read: its manifest and the rows of each table it contains. */
data class ImportFile(val manifest: ExportManifest, val tables: Map<String, List<CsvRow>>) {
    fun rows(table: CsvTable<*>): List<CsvRow> = tables[table.name].orEmpty()
}

/** Limits on an import file (spec §7.5). */
data class ImportLimits(
    val maxFileBytes: Long = 20L * 1024 * 1024,
    val maxRows: Int = 100_000,
    val maxEntries: Int = 50,
    val maxUncompressedBytes: Long = 200L * 1024 * 1024,
    val maxCompressionRatio: Int = 100,
)

/**
 * Reads an own normalized export (spec §7.4, §7.5 step 1): the zip within [limits], `manifest.json`, and
 * every known table's CSV by its header. Free-text cells are unescaped when the manifest declares
 * [TextEscaping.NAME]. Entries that aren't tables of the normalized shape are ignored.
 */
class ImportReader(private val limits: ImportLimits = ImportLimits()) {

    private val tablesByFile = NormalizedTables.all.associateBy { it.fileName }

    /** Errors: `CorruptFile` (not a zip or not an IOU export), `SchemaTooNew`, `LimitsExceeded`. */
    fun read(file: ByteArray): LedgerResult<ImportFile> {
        if (file.size > limits.maxFileBytes) return limit("File larger than ${limits.maxFileBytes} bytes")
        val entries = linkedMapOf<String, ByteArray>()
        var total = 0L
        var entryCount = 0
        try {
            ZipInputStream(ByteArrayInputStream(file)).use { zip ->
                while (true) {
                    val entry = zip.nextEntry ?: break
                    if (++entryCount > limits.maxEntries) return limit("More than ${limits.maxEntries} entries")
                    if (entry.name in entries) return corrupt("Duplicate zip entry ${entry.name}")
                    val budget = minOf(limits.maxUncompressedBytes, file.size.toLong() * limits.maxCompressionRatio) - total
                    val bytes = zip.readBytesUpTo(budget) ?: return limit("Uncompressed size or compression ratio too large")
                    total += bytes.size
                    entries[entry.name] = bytes
                }
            }
        } catch (_: ZipException) {
            return corrupt("Not a zip file")
        } catch (_: IOException) {
            return corrupt("Damaged zip file")
        }
        val manifestBytes = entries[LedgerExport.MANIFEST] ?: return corrupt("Not an IOU export: no manifest.json")
        val manifest = try {
            json.decodeFromString(ExportManifest.serializer(), manifestBytes.toString(Charsets.UTF_8))
        } catch (_: SerializationException) {
            return corrupt("Unreadable manifest.json")
        } catch (_: IllegalArgumentException) {
            return corrupt("Unreadable manifest.json")
        }
        if (manifest.format != LedgerExport.FORMAT) return corrupt("Not an IOU normalized export")
        if (manifest.schemaVersion > NormalizedTables.SCHEMA_VERSION) {
            return LedgerResult.Err(LedgerError.SchemaTooNew(manifest.schemaVersion, NormalizedTables.SCHEMA_VERSION))
        }
        if (manifest.textEscaping != TextEscaping.NAME) return corrupt("Unknown text escaping ${manifest.textEscaping}")
        val delimiter = manifest.delimiter.singleOrNull() ?: return corrupt("Bad delimiter ${manifest.delimiter}")

        val tables = linkedMapOf<String, List<CsvRow>>()
        var rowCount = 0
        for ((name, bytes) in entries) {
            val table = tablesByFile[name] ?: continue
            val rows = try {
                parse(table, bytes, delimiter, limits.maxRows - rowCount)
                    ?: return limit("More than ${limits.maxRows} rows")
            } catch (e: UncheckedIOException) {
                return corrupt("$name: ${e.message}")
            } catch (e: IOException) {
                return corrupt("$name: ${e.message}")
            } catch (e: IllegalArgumentException) {
                return corrupt("$name: ${e.message}")
            } catch (e: IllegalStateException) {
                return corrupt("$name: ${e.message}")
            }
            rowCount += rows.size
            tables[table.name] = rows
        }
        return LedgerResult.Ok(ImportFile(manifest, tables))
    }

    private fun parse(table: CsvTable<*>, bytes: ByteArray, delimiter: Char, budget: Int): List<CsvRow>? {
        val text = bytes.toString(Charsets.UTF_8).removePrefix(LedgerExport.BOM)
        val textColumns = table.columns.filter { it.text }.map { it.name }.toSet()
        val format = CSVFormat.RFC4180.builder().setDelimiter(delimiter).setHeader().setSkipHeaderRecord(true).get()
        return format.parse(text.reader()).use { parser ->
            require(parser.headerNames.size == parser.headerNames.toSet().size) { "Duplicate CSV header" }
            val rows = mutableListOf<CsvRow>()
            for (record in parser) {
                if (rows.size >= budget) return null
                val cells = record.toMap().mapValues { (column, value) ->
                    if (column in textColumns) TextEscaping.unescape(value) else value
                }
                rows.add(CsvRow(rows.size + 2, cells))
            }
            rows
        }
    }

    private fun ZipInputStream.readBytesUpTo(budget: Long): ByteArray? = if (budget < 0) null else readAtMost(budget)

    private fun corrupt(detail: String) = LedgerResult.Err(LedgerError.CorruptFile(detail))

    private fun limit(detail: String) = LedgerResult.Err(LedgerError.LimitsExceeded(detail))

    private companion object {
        val json = Json { ignoreUnknownKeys = true }
    }
}

import io.github.codex07.iou.api.InvalidRow

import io.github.codex07.iou.money.MoneyParser
import java.time.Instant
import java.time.LocalDate
import java.time.format.DateTimeParseException

/** An incoming record, the row it came from and the version it had in the source. */
data class Incoming<out T>(val table: String, val row: Int, val record: T, val sourceVersion: Int)

/** Every record of an import that decoded. Expenses carry their shares, in `position` order. */
data class IncomingLedger(
    val people: List<Incoming<Person>> = emptyList(),
    val handles: List<Incoming<PaymentHandle>> = emptyList(),
    val fxSnapshots: List<Incoming<FxSnapshot>> = emptyList(),
    val transfers: List<Incoming<Transfer>> = emptyList(),
    val expenses: List<Incoming<Expense>> = emptyList(),
)

/** The decoded records and the rows that didn't decode. */
data class DecodedImport(val ledger: IncomingLedger, val invalid: List<InvalidRow>)

/**
 * Turns the rows of an [ImportFile] into records (spec §7.5 step 2–3, per row). Every problem becomes an
 * [InvalidRow] with its table, row number and reason; nothing is thrown. Amounts are parsed from their
 * decimal strings with [MoneyParser] and must match their `*_minor` column. Group rows, memberships and
 * entries in a group are invalid until M2 (index, locked decision 6).
 */
object ImportDecoder {

    const val GROUPS_IN_M2 = "group rows are imported from M2 on"

    private class RowError(val reason: String, val error: LedgerError?) : Exception(reason)

    private class ShareErrors(val rows: List<InvalidRow>) : Exception()

    fun decode(file: ImportFile): DecodedImport {
        val invalid = mutableListOf<InvalidRow>()

        fun <T> table(table: CsvTable<*>, id: (CsvRow) -> String, decode: RowReader.() -> T): List<Incoming<T>> {
            val seen = mutableSetOf<String>()
            return file.rows(table).mapNotNull { row ->
                try {
                    val reader = RowReader(row)
                    val rowId = id(row)
                    if (!seen.add(rowId)) throw RowError("duplicate id $rowId", LedgerError.CorruptData("duplicate id $rowId"))
                    Incoming(table.name, row.number, reader.decode(), reader.sourceVersion())
                } catch (e: ShareErrors) {
                    invalid += e.rows
                    null
                } catch (e: RowError) {
                    invalid += InvalidRow(table.name, row.number, e.reason, e.error)
                    null
                }
            }
        }

        for (table in listOf(NormalizedTables.groups, NormalizedTables.groupMembers)) {
            file.rows(table).forEach { invalid += InvalidRow(table.name, it.number, GROUPS_IN_M2, null) }
        }

        val people = table(NormalizedTables.people, { it.cells["id"].orEmpty() }) { person() }
        val handles = table(NormalizedTables.paymentHandles, { it.cells["id"].orEmpty() }) { handle() }
        val snapshots = table(NormalizedTables.fxSnapshots, { it.cells["id"].orEmpty() }) { snapshot() }
        val transfers = table(NormalizedTables.transfers, { it.cells["id"].orEmpty() }) { transfer() }

        val shareRows = file.rows(NormalizedTables.expenseShares).groupBy { it.cells["expense_id"].orEmpty() }
        val expenseIds = file.rows(NormalizedTables.expenses).map { it.cells["id"].orEmpty() }.toSet()
        for ((expenseId, rows) in shareRows) {
            if (expenseId !in expenseIds) {
                rows.forEach {
                    invalid += InvalidRow(NormalizedTables.expenseShares.name, it.number, "share of an expense that isn't in the file", LedgerError.CorruptData("orphan share"))
                }
            }
        }
        val expenses = table(NormalizedTables.expenses, { it.cells["id"].orEmpty() }) {
            expense(shareRows[cells["id"].orEmpty()].orEmpty())
        }
        return DecodedImport(IncomingLedger(people, handles, snapshots, transfers, expenses), invalid)
    }

    /** Reads typed values from one row; every failure is a [RowError] naming the column. */
    private class RowReader(row: CsvRow) {
        val cells = row.cells

        private fun fail(column: String, problem: String, error: LedgerError? = LedgerError.InvalidField(column)): Nothing =
            throw RowError("$column: $problem", error)

        fun optional(column: String): String? = cells[column]?.takeIf { it.isNotEmpty() }

        fun required(column: String): String = optional(column) ?: fail(column, "missing")

        fun long(column: String): Long = required(column).toLongOrNull() ?: fail(column, "not a whole number")

        fun optionalLong(column: String): Long? = optional(column)?.let { it.toLongOrNull() ?: fail(column, "not a whole number") }

        fun bool(column: String): Boolean = when (required(column)) {
            "true" -> true
            "false" -> false
            else -> fail(column, "not true or false")
        }

        fun instant(column: String): Instant = parseInstant(column, required(column))

        fun optionalInstant(column: String): Instant? = optional(column)?.let { parseInstant(column, it) }

        private fun parseInstant(column: String, text: String): Instant =
            try { Instant.parse(text) } catch (_: DateTimeParseException) { fail(column, "not an ISO-8601 instant") }

        fun date(column: String): LocalDate =
            try { LocalDate.parse(required(column)) } catch (_: DateTimeParseException) { fail(column, "not a yyyy-MM-dd date") }

        fun currency(column: String): CurrencyCode = required(column).let { code ->
            CurrencyCode.parse(code) ?: fail(column, "unknown currency $code", LedgerError.UnknownCurrency(code))
        }

        fun optionalCurrency(column: String): CurrencyCode? = optional(column)?.let { currency(column) }

        inline fun <reified E : Enum<E>> enum(column: String): E = required(column).let { name ->
            enumValues<E>().firstOrNull { it.name == name } ?: fail(column, "unknown value $name")
        }

        inline fun <reified E : Enum<E>> optionalEnum(column: String): E? = optional(column)?.let { enum<E>(column) }

        /** `<prefix>` as a decimal string in [currencyColumn], checked against `<prefix>_minor`. */
        fun money(prefix: String, currencyColumn: String): Money = amount(prefix, required(prefix), currency(currencyColumn), long("${prefix}_minor"))

        fun amount(column: String, text: String, currency: CurrencyCode, minor: Long): Money {
            val money = when (val parsed = MoneyParser.parse(text, currency)) {
                is MoneyParseResult.Ok -> parsed.money
                is MoneyParseResult.Err -> fail(column, "invalid amount $text", parsed.error.toLedgerError())
            }
            if (money.amountMinor != minor) fail(column, "$text doesn't match ${column}_minor $minor", LedgerError.CorruptData("$column mismatch"))
            return money
        }

        fun meta(): SyncMeta = SyncMeta(
            createdAt = instant("created_at"),
            updatedAt = instant("updated_at"),
            authorId = PersonId(required("author_id")),
            deletedAt = optionalInstant("deleted_at"),
            version = sourceVersion(),
        )

        fun sourceVersion(): Int = cells["version"]?.let { text ->
            text.toIntOrNull()?.takeIf { it >= 1 } ?: fail("version", "not a positive whole number")
        } ?: 1

        fun noGroup() {
            if (optional("group_id") != null) throw RowError(GROUPS_IN_M2, null)
        }

        fun person() = Person(
            id = PersonId(required("id")),
            displayName = required("display_name"),
            isMe = bool("is_me"),
            note = optional("note"),
            defaultCurrency = optionalCurrency("default_currency"),
            archivedAt = optionalInstant("archived_at"),
            mergedIntoId = optional("merged_into_id")?.let(::PersonId),
            meta = meta(),
        )

        fun handle() = PaymentHandle(
            id = HandleId(required("id")),
            personId = PersonId(required("person_id")),
            type = enum<HandleType>("type"),
            value = required("value"),
            holderName = optional("holder_name"),
            bic = optional("bic"),
            label = required("label"),
            isDefault = bool("is_default"),
            meta = meta(),
        )

        fun snapshot(): FxSnapshot {
            val rate = required("rate")
            if (FxConverter.validateRate(rate) is LedgerResult.Err) fail("rate", "invalid rate $rate", LedgerError.InvalidRate(rate))
            return FxSnapshot(
                id = FxSnapshotId(required("id")),
                baseCurrency = currency("base_currency"),
                quoteCurrency = currency("quote_currency"),
                rate = rate,
                rateDate = date("rate_date"),
                source = enum<FxSource>("source"),
                isStale = bool("is_stale"),
                fetchedAt = instant("fetched_at"),
                paidMinor = optionalLong("paid_minor"),
                chargedMinor = optionalLong("charged_minor"),
            )
        }

        fun transfer(): Transfer {
            noGroup()
            return Transfer(
                id = EntryId(required("id")),
                fromPersonId = PersonId(required("from_person_id")),
                toPersonId = PersonId(required("to_person_id")),
                amount = money("amount", "currency"),
                effectAmount = money("effect_amount", "effect_currency"),
                fxSnapshotId = optional("fx_snapshot_id")?.let(::FxSnapshotId),
                kind = enum<TransferKind>("kind"),
                method = enum<TransferMethod>("method"),
                accountLabel = optional("account_label"),
                occurredOn = date("occurred_on"),
                note = optional("note"),
                meta = meta(),
            )
        }

        fun expense(shareRows: List<CsvRow>): Expense {
            noGroup()
            val effectTotal = money("effect_total", "effect_currency")
            val errors = mutableListOf<InvalidRow>()
            val shares = shareRows.mapNotNull { row ->
                val share = RowReader(row)
                try {
                    val position = share.long("position")
                    position to ExpenseShare(
                        personId = PersonId(share.required("person_id")),
                        shareMinor = share.amount("share", share.required("share"), effectTotal.currency, share.long("share_minor")).amountMinor,
                        inputValue = share.optionalLong("input_value"),
                    )
                } catch (e: RowError) {
                    errors += InvalidRow(NormalizedTables.expenseShares.name, row.number, e.reason, e.error)
                    null
                }
            }
            if (errors.isNotEmpty()) throw ShareErrors(errors)
            return Expense(
                id = EntryId(required("id")),
                payerPersonId = PersonId(required("payer_person_id")),
                description = required("description"),
                category = optionalEnum<Category>("category"),
                total = money("total", "currency"),
                effectTotal = effectTotal,
                fxSnapshotId = optional("fx_snapshot_id")?.let(::FxSnapshotId),
                splitType = enum<SplitType>("split_type"),
                shares = shares.sortedBy { it.first }.map { it.second },
                occurredOn = date("occurred_on"),
                note = optional("note"),
                meta = meta(),
            )
        }
    }
}

/** How an incoming row compares with the local ledger (spec §7.4). */
enum class Classification { NEW, DUPLICATE, CONFLICT }

/** An incoming record after identity mapping, the local row with its ID (if any) and how they compare. */
data class Classified<T : LedgerEntity>(val incoming: Incoming<T>, val local: T?, val kind: Classification) {
    val record: T get() = incoming.record
    val key: ImportRowKey get() = ImportRowKey(record.entityType, record.entityId)
}

/**
 * What an import would do to one local ledger (spec §7.4, §7.5 steps 2–4): identity mapping, classification
 * by UUID, row validation with attribution, and, for a set of choices, the preview rows, the balance changes
 * and the plan the commit writes. Owned rows follow their owner through the §5.2 cascade; in M1 the only
 * owners are people with their payment handles (group rows wait for M2).
 */
class ImportAnalysis private constructor(
    val state: LedgerState,
    val fileName: String,
    private val mappedFrom: PersonId?,
    val people: List<Classified<Person>>,
    val handles: List<Classified<PaymentHandle>>,
    val snapshots: List<Incoming<FxSnapshot>>,
    val transfers: List<Classified<Transfer>>,
    val expenses: List<Classified<Expense>>,
    val invalid: List<InvalidRow>,
    private val duplicates: Int,
    private val mappedKeys: Set<ImportRowKey>,
    /** When the file shows each of its people deleted, duplicates of local rows included. */
    private val sourceDeletedAt: Map<PersonId, Instant?>,
) {
    private val entries: List<Classified<out Entry>> get() = transfers + expenses
    private val rows: List<Classified<out LedgerEntity>> get() = people + handles + entries

    val counts: ImportCounts
        get() = ImportCounts(
            new = rows.count { it.kind == Classification.NEW } + snapshots.size,
            conflicts = rows.count { it.kind == Classification.CONFLICT },
            duplicates = duplicates,
            invalid = invalid.size,
        )

    // ---- Owners and their cascades ----

    private enum class OwnerAction { NONE, CREATE_DELETED, DELETE, RESTORE }

    private fun Classified<Person>.action(take: Set<ImportRowKey>): OwnerAction {
        val taken = kind == Classification.CONFLICT && key in take
        return when {
            kind == Classification.NEW && record.isDeleted -> OwnerAction.CREATE_DELETED
            taken && local!!.isDeleted != record.isDeleted -> if (record.isDeleted) OwnerAction.DELETE else OwnerAction.RESTORE
            else -> OwnerAction.NONE
        }
    }

    private fun ownerName(id: PersonId): String =
        people.firstOrNull { it.record.id == id }?.record?.displayName ?: state.people[id]?.displayName ?: id.value

    /** How [handle]'s deleted state is decided: by its owner's cascade, or (null) by its own row. */
    private fun forcedBy(handle: PaymentHandle, local: PaymentHandle?, take: Set<ImportRowKey>): ImportRowChoice? {
        val owner = people.firstOrNull { it.record.id == handle.personId }
        val name = ownerName(handle.personId)
        return when (owner?.action(take)) {
            OwnerAction.CREATE_DELETED, OwnerAction.DELETE -> ImportRowChoice.DeletedWith(name)
            OwnerAction.RESTORE ->
                if (local != null && local.meta.deletedAt == owner.local!!.meta.deletedAt) ImportRowChoice.RestoredWith(name) else null
            // The owner stays deleted locally: its handles end deleted too.
            else -> if (state.people[handle.personId]?.isDeleted == true) ImportRowChoice.DeletedWith(name) else null
        }
    }

    // ---- Preview ----

    /** Conflicts with their field diffs, and every row whose outcome a cascade forces (local rows included). */
    fun previewRows(take: Set<ImportRowKey>): List<ImportRow> {
        val shown = mutableListOf<ImportRow>()
        for (row in rows) {
            val handle = row.record as? PaymentHandle
            val forced = handle?.let { forcedBy(it, row.local as PaymentHandle?, take) }
            if (row.kind == Classification.CONFLICT || forced != null) {
                shown += ImportRow(row.key, label(row.record), diff(row.local, row.record), forced ?: ImportRowChoice.KeepOrTake, changedSinceLastPreview = false)
            }
        }
        val listed = shown.map { it.key }.toSet()
        for (owner in people) {
            val action = owner.action(take)
            val local = state.handles.values.filter { it.personId == owner.record.id }
            val touched = when (action) {
                OwnerAction.DELETE -> local.filter { !it.isDeleted }.map { it to ImportRowChoice.DeletedWith(owner.record.displayName) }
                OwnerAction.RESTORE -> local.filter { it.meta.deletedAt == owner.local!!.meta.deletedAt }
                    .map { it to ImportRowChoice.RestoredWith(owner.record.displayName) }
                else -> emptyList()
            }
            for ((handle, choice) in touched) {
                val key = ImportRowKey(EntityType.PAYMENT_HANDLE, handle.id.value)
                if (key in listed) continue
                val after = handle.withMeta(handle.meta.copy(deletedAt = if (action == OwnerAction.DELETE) Instant.EPOCH else null))
                shown += ImportRow(key, label(handle), diff(handle, after), choice, changedSinceLastPreview = false)
            }
        }
        return shown
    }

    /** Non-group balances with each person before and after the import with [take], where they differ. */
    fun balanceChanges(take: Set<ImportRowKey>): List<BalanceChange> {
        val before = LedgerEngine.compute(state).pairwise
        val afterState = state.applying(plan(take, PREVIEW_BATCH, Instant.EPOCH).changes)
        val after = LedgerEngine.compute(afterState).pairwise
        return (before.keys + after.keys).mapNotNull { person ->
            val was = before[person].orEmpty()
            val now = after[person].orEmpty()
            if (was == now) return@mapNotNull null
            val name = afterState.people[person]?.displayName ?: person.value
            BalanceChange(name, was.toMoney(), now.toMoney())
        }.sortedBy { it.counterpart }
    }

    private fun Map<io.github.codex07.iou.money.CurrencyCode, Long>.toMoney() =
        entries.sortedBy { it.key.code }.map { Money(it.value, it.key) }

    private fun label(entity: LedgerEntity): String = when (entity) {
        is Person -> "Person ${entity.displayName}"
        is PaymentHandle -> "${entity.type.name} ${entity.label} of ${ownerName(entity.personId)}"
        is Transfer -> "Transfer of ${entity.amount} on ${entity.occurredOn}"
        is Expense -> "Expense ${entity.description} on ${entity.occurredOn}"
        else -> "${entity.entityType} ${entity.entityId}"
    }

    private fun diff(local: LedgerEntity?, incoming: LedgerEntity): List<FieldChange> = RevisionDiff.diff(local, incoming, names)

    private val names = object : DiffNames {
        override fun person(id: PersonId) = ownerName(id)
        override fun group(id: GroupId) = state.groups[id]?.name ?: id.value
    }

    // ---- Commit plan ----

    /**
     * The rows the commit writes for [take] (spec §7.5 step 6): creates and updates in dependency order, then
     * deletions (entries, owned rows on their own, owners with their cascade). Invalid rows are left out. Rows
     * get [batch] as their `importBatchId` and a reason naming the file and source version.
     */
    fun plan(take: Set<ImportRowKey>, batch: ImportBatchId, now: Instant): PlanResult {
        val writer = Writer(state, batch, now)
        val ownerActions = people.associate { it.record.id to it.action(take) }

        for (row in people) {
            when (row.kind) {
                Classification.NEW -> writer.create(row.record, reasonNew(row))
                Classification.CONFLICT -> if (row.key in take) writer.update(row, reasonConflict(row))
                Classification.DUPLICATE -> Unit
            }
            if (ownerActions[row.record.id] == OwnerAction.RESTORE) {
                val restoredAt = row.local!!.meta.deletedAt
                writer.restore(row.record.id.value, EntityType.PERSON, reasonConflict(row))
                state.handles.values.filter { it.personId == row.record.id && it.meta.deletedAt == restoredAt }.forEach {
                    writer.restore(it.id.value, EntityType.PAYMENT_HANDLE, "${reasonConflict(row)} with ${row.record.displayName}")
                }
            }
        }
        val handleDeletions = mutableListOf<Pair<Classified<PaymentHandle>, Instant>>()
        for (row in handles) {
            val ownerAction = ownerActions[row.record.personId] ?: OwnerAction.NONE
            val ownerLocal = state.people[row.record.personId]
            when (row.kind) {
                Classification.NEW -> {
                    writer.create(row.record, reasonNew(row))
                    when {
                        ownerAction == OwnerAction.CREATE_DELETED || ownerAction == OwnerAction.DELETE ->
                            if (deletedApart(row)) handleDeletions += row to now.minusNanos(1)
                        // Under an owner that stays deleted, it goes with the owner unless the file shows it deleted
                        // apart; then it is deleted on its own, just before the owner, so restoring the owner skips it.
                        ownerAction == OwnerAction.NONE && ownerLocal?.isDeleted == true ->
                            handleDeletions += row to ownerLocal.meta.deletedAt!!.let { if (deletedApart(row)) it.minusNanos(1) else it }
                        row.record.isDeleted -> handleDeletions += row to now
                    }
                }
                Classification.CONFLICT -> {
                    if (row.key in take) writer.update(row, reasonConflict(row))
                    val local = row.local!!
                    when {
                        // Its deleted state isn't a choice here ("deleted with <owner>"), whether or not it is taken.
                        ownerAction == OwnerAction.DELETE -> if (deletedApart(row)) handleDeletions += row to now.minusNanos(1)
                        row.key in take && forcedBy(row.record, local, take) == null && local.isDeleted != row.record.isDeleted ->
                            if (row.record.isDeleted) handleDeletions += row to now else writer.restore(row.record.id.value, EntityType.PAYMENT_HANDLE, reasonConflict(row))
                    }
                }
                Classification.DUPLICATE -> Unit
            }
        }
        val snapshots = this.snapshots.map { it.record }
        val entryDeletions = mutableListOf<Classified<out Entry>>()
        for (row in entries) {
            when (row.kind) {
                Classification.NEW -> {
                    writer.create(row.record, reasonNew(row))
                    if (row.record.isDeleted) entryDeletions += row
                }
                Classification.CONFLICT -> if (row.key in take) {
                    writer.update(row, reasonConflict(row))
                    val local = row.local!!
                    if (local.isDeleted != row.record.isDeleted) {
                        if (row.record.isDeleted) entryDeletions += row else writer.restore(row.record.entityId, row.record.entityType, reasonConflict(row))
                    }
                }
                Classification.DUPLICATE -> Unit
            }
        }
        for (row in entryDeletions) writer.delete(row.record.entityId, row.record.entityType, now, reasonDeleted(row))
        for ((row, at) in handleDeletions) writer.delete(row.record.id.value, EntityType.PAYMENT_HANDLE, at, reasonDeleted(row))
        for (row in people) {
            val action = ownerActions.getValue(row.record.id)
            if (action != OwnerAction.CREATE_DELETED && action != OwnerAction.DELETE) continue
            val reason = if (action == OwnerAction.DELETE) reasonConflict(row) else reasonDeleted(row)
            writer.delete(row.record.id.value, EntityType.PERSON, now, reason)
            writer.current.handles.values.filter { it.personId == row.record.id && !it.isDeleted }.forEach {
                writer.delete(it.id.value, EntityType.PAYMENT_HANDLE, now, "$reason with ${row.record.displayName}")
            }
        }
        return PlanResult(writer.changes, snapshots, writer.current.applyingSnapshots(snapshots))
    }

    /** The changes, the new FX snapshots, and the state they produce. */
    data class PlanResult(val changes: List<Change>, val snapshots: List<FxSnapshot>, val state: LedgerState) {
        val rowCount: Int get() = changes.map { it.entity.entityType to it.entity.entityId }.distinct().size + snapshots.size
    }

    private fun LedgerState.applyingSnapshots(snapshots: List<FxSnapshot>) = snapshots.fold(this) { s, snapshot -> s.with(snapshot) }

    /**
     * A handle the file shows deleted at another time than its owner as the file shows it (the owner's row counts
     * even when it duplicates the local one): it is deleted on its own, so restoring the owner later doesn't bring
     * it back (spec §7.4).
     */
    private fun deletedApart(row: Classified<PaymentHandle>) =
        row.record.isDeleted && row.record.meta.deletedAt != sourceDeletedAt[row.record.personId]

    private fun mapping(row: Classified<*>) = if (mappedFrom != null && row.key in mappedKeys) ", source identity ${mappedFrom.value} mapped to me" else ""

    private fun reasonNew(row: Classified<*>) = "Imported from $fileName (source v${row.incoming.sourceVersion})${mapping(row)}"

    private fun reasonDeleted(row: Classified<*>) = "${reasonNew(row)}, deleted in the source"

    private fun reasonConflict(row: Classified<*>) = "Import conflict resolved from $fileName (source v${row.incoming.sourceVersion})${mapping(row)}"

    /** Writes rows against a running state, so later rows see earlier ones. */
    private class Writer(var current: LedgerState, private val batch: ImportBatchId, private val now: Instant) {
        val changes = mutableListOf<Change>()
        private val me = current.me.id

        private fun write(entity: LedgerEntity, action: RevisionAction, reason: String) {
            changes += Change(entity, action, reason)
            current = current.with(entity)
        }

        private fun next(entity: LedgerEntity, deletedAt: Instant?): SyncMeta =
            entity.meta.copy(updatedAt = now, authorId = me, version = entity.meta.version + 1, deletedAt = deletedAt, importBatchId = batch)

        private fun find(id: String, type: EntityType): LedgerEntity = when (type) {
            EntityType.PERSON -> current.people.getValue(PersonId(id))
            EntityType.PAYMENT_HANDLE -> current.handles.getValue(HandleId(id))
            EntityType.TRANSFER -> current.transfers.getValue(EntryId(id))
            EntityType.EXPENSE -> current.expenses.getValue(EntryId(id))
            else -> error("$type rows are not imported in M1")
        }

        /** Version 1, active; a row deleted in the source is deleted afterwards. */
        fun create(record: LedgerEntity, reason: String) =
            write(record.withMeta(SyncMeta(createdAt = now, updatedAt = now, authorId = me, importBatchId = batch)), RevisionAction.CREATED, reason)

        /** The incoming business fields on the local row; the deleted state changes separately. */
        fun update(row: Classified<*>, reason: String) {
            val local = find(row.record.entityId, row.record.entityType)
            if (local.withMeta(NEUTRAL) == row.record.withMeta(NEUTRAL)) return
            write(row.record.withMeta(next(local, local.meta.deletedAt)), RevisionAction.UPDATED, reason)
        }

        fun delete(id: String, type: EntityType, at: Instant, reason: String) {
            val entity = find(id, type)
            if (!entity.isDeleted) write(entity.withMeta(next(entity, at)), RevisionAction.DELETED, reason)
        }

        fun restore(id: String, type: EntityType, reason: String) {
            val entity = find(id, type)
            if (entity.isDeleted) write(entity.withMeta(next(entity, null)), RevisionAction.RESTORED, reason)
        }
    }

    companion object {
        private val PREVIEW_BATCH = ImportBatchId("preview")
        private val NEUTRAL = SyncMeta(Instant.EPOCH, Instant.EPOCH, PersonId(""))

        /** Business fields and deleted state equal: the sync columns are ignored (spec §7.4). */
        private fun same(a: LedgerEntity, b: LedgerEntity) = a.withMeta(NEUTRAL) == b.withMeta(NEUTRAL) && a.isDeleted == b.isDeleted

        /**
         * Analyses [decoded] against [state]. With [mapFrom], every reference to that source me becomes the local
         * me and the source me's own row is dropped (spec §7.4, identity mapping).
         */
        fun build(state: LedgerState, fileName: String, decoded: DecodedImport, mapFrom: PersonId?): ImportAnalysis {
            val me = state.me.id
            val invalid = decoded.invalid.toMutableList()
            val mappedKeys = mutableSetOf<ImportRowKey>()
            fun mapped(id: PersonId) = if (id == mapFrom) me else id
            fun <T : LedgerEntity> Incoming<T>.mapped(transform: (T) -> T): Incoming<T> {
                val after = transform(record)
                if (after != record) mappedKeys += ImportRowKey(record.entityType, record.entityId)
                return copy(record = after)
            }

            val incoming = decoded.ledger
            val people = incoming.people.filter { mapFrom == null || it.record.id != mapFrom }
                .map { row -> row.mapped { it.copy(mergedIntoId = it.mergedIntoId?.let(::mapped)) } }
            val sourceDeletedAt = people.associate { it.record.id to it.record.meta.deletedAt }
            val handles = incoming.handles.map { row -> row.mapped { it.copy(personId = mapped(it.personId)) } }
            val transfers = incoming.transfers.map { row -> row.mapped { it.copy(fromPersonId = mapped(it.fromPersonId), toPersonId = mapped(it.toPersonId)) } }
            val expenses = incoming.expenses.map { row ->
                row.mapped { e -> e.copy(payerPersonId = mapped(e.payerPersonId), shares = e.shares.map { it.copy(personId = mapped(it.personId)) }) }
            }

            var duplicates = 0
            fun <T : LedgerEntity> classify(rows: List<Incoming<T>>, local: (T) -> T?): List<Classified<T>> = rows.mapNotNull { row ->
                val existing = local(row.record)
                when {
                    existing == null -> Classified(row, null, Classification.NEW)
                    same(existing, row.record) -> { duplicates++; null }
                    else -> Classified(row, existing, Classification.CONFLICT)
                }
            }

            // FX snapshots are immutable: unknown → new, identical → duplicate, different → invalid (spec §7.4).
            val rejectedSnapshots = mutableSetOf<String>()
            val newSnapshots = incoming.fxSnapshots.filter { row ->
                val existing = state.fxSnapshots[row.record.id]
                when {
                    existing == null -> true
                    existing == row.record -> { duplicates++; false }
                    else -> {
                        rejectedSnapshots += row.record.id.value
                        invalid += InvalidRow(row.table, row.row, "differs from the local FX snapshot with the same ID", LedgerError.CorruptData("FX snapshot ${row.record.id.value} differs"))
                        false
                    }
                }
            }

            var classifiedPeople = classify(people) { state.people[it.id] }
            var classifiedHandles = classify(handles) { state.handles[it.id] }
            var classifiedTransfers = classify(transfers) { state.transfers[it.id] }
            var classifiedExpenses = classify(expenses) { state.expenses[it.id] }

            fun reject(row: Classified<*>, reason: String, error: LedgerError?) {
                invalid += InvalidRow(row.incoming.table, row.incoming.row, reason, error)
            }

            // Entries that would be written with a rejected snapshot, and rows that fail their own field checks.
            fun <T : LedgerEntity> List<Classified<T>>.checked(): List<Classified<T>> = filter { row ->
                val entry = row.record as? Entry
                if (entry?.fxSnapshotId?.value in rejectedSnapshots) {
                    reject(row, "references an FX snapshot that differs from the local copy", LedgerError.FxSnapshotMismatch(entry?.id))
                    return@filter false
                }
                val field = if (row.record.isDeleted) null else FieldRules.check(listOf(row.record)).firstOrNull()
                if (field != null) reject(row, describe(field), field.error)
                field == null
            }
            classifiedPeople = classifiedPeople.checked()
            classifiedHandles = classifiedHandles.checked()
            classifiedTransfers = classifiedTransfers.checked()
            classifiedExpenses = classifiedExpenses.checked()

            // State invariants (spec §3.4) over the complete state the import would produce with every conflict
            // taken, cascades included. Only when it breaks one are rows blamed: a row is to blame for a violation
            // that goes away without it. Leaving out a new person would leave the rows that name them dangling, and
            // the validator then reports only that broken structure (rule 15), hiding every other violation; so a
            // new person is left out together with those rows, and is to blame only for a violation that stays
            // while just those rows are left out. People and handles answer first, for the violations that also
            // remain with the incoming active entries left out; incoming deletions stay in, as they can be what
            // makes a deletion valid (a person deleted together with their transfers). Entries answer for the rest.
            // Each round repeats until nothing is broken or no row is to blame, and both passes run again while
            // either blames a row, since one broken rule (above all a dangling reference) can hide others.
            val rejected = mutableSetOf<ImportRowKey>()
            fun <T : LedgerEntity> List<Classified<T>>.kept() = filter { it.key !in rejected }
            fun violations(withActiveEntries: Boolean, without: Set<ImportRowKey> = emptySet()): Set<RuleViolation> {
                fun <T : LedgerEntity> List<Classified<T>>.taken(entries: Boolean) =
                    kept().filter { it.key !in without && (!entries || withActiveEntries || it.record.isDeleted) }
                val rows = ImportAnalysis(
                    state, fileName, mapFrom, classifiedPeople.taken(false), classifiedHandles.taken(false), newSnapshots,
                    classifiedTransfers.taken(true), classifiedExpenses.taken(true), emptyList(), 0, emptySet(), sourceDeletedAt,
                )
                val after = rows.plan(rows.rows.filter { it.kind == Classification.CONFLICT }.map { it.key }.toSet(), PREVIEW_BATCH, Instant.EPOCH).state
                return LedgerValidator.validate(state, after, WriteOp.Import).toSet()
            }
            fun references(row: Classified<*>): Set<PersonId> = when (val record = row.record) {
                is Person -> setOfNotNull(record.mergedIntoId)
                is PaymentHandle -> setOf(record.personId)
                is Transfer -> setOf(record.fromPersonId, record.toPersonId)
                is Expense -> record.shares.map { it.personId }.toSet() + record.payerPersonId
                else -> emptySet()
            }
            // The kept rows that name [row] if it is a new person, directly or through other new people.
            fun dependents(row: Classified<*>): Set<ImportRowKey> {
                val rows = classifiedPeople.kept() + classifiedHandles.kept() + classifiedTransfers.kept() + classifiedExpenses.kept()
                val gone = mutableSetOf<PersonId>()
                val found = mutableSetOf<ImportRowKey>()
                var next: List<Classified<*>> = listOf(row)
                while (next.isNotEmpty()) {
                    gone += next.mapNotNull { r -> (r.record as? Person)?.id?.takeIf { r.local == null } }
                    next = rows.filter { it.key != row.key && it.key !in found && references(it).any(gone::contains) }
                    found += next.map { it.key }
                }
                return found
            }
            fun blame(candidates: List<Classified<*>>, broken: () -> Set<RuleViolation>, without: (Set<ImportRowKey>) -> Set<RuleViolation>): Boolean {
                var any = false
                var found = broken()
                while (found.isNotEmpty()) {
                    val blamed = candidates.filter { it.key !in rejected }.filter { row ->
                        val others = dependents(row)
                        val stays = if (others.isEmpty()) found else found intersect without(others)
                        (stays - without(others + row.key)).firstOrNull()?.let { reject(row, describe(it), it.error) } != null
                    }
                    if (blamed.isEmpty()) return any
                    any = true
                    rejected += blamed.map { it.key }
                    found = broken()
                }
                return any
            }
            while (violations(withActiveEntries = true).isNotEmpty()) {
                val owners = blame(
                    classifiedPeople + classifiedHandles,
                    broken = { violations(withActiveEntries = false) intersect violations(withActiveEntries = true) },
                    without = { violations(withActiveEntries = false, without = it) },
                )
                val entries = blame(
                    classifiedTransfers + classifiedExpenses,
                    broken = { violations(withActiveEntries = true) },
                    without = { violations(withActiveEntries = true, without = it) },
                )
                if (!owners && !entries) break
            }
            classifiedPeople = classifiedPeople.kept()
            classifiedHandles = classifiedHandles.kept()
            classifiedTransfers = classifiedTransfers.kept()
            classifiedExpenses = classifiedExpenses.kept()

            return ImportAnalysis(
                state, fileName, mapFrom, classifiedPeople, classifiedHandles, newSnapshots,
                classifiedTransfers, classifiedExpenses, invalid.sortedWith(compareBy({ it.table }, { it.rowNumber })), duplicates, mappedKeys, sourceDeletedAt,
            )
        }

        private fun describe(violation: RuleViolation) =
            if (violation.rule == 0) "invalid field: ${violation.error}" else "breaks rule ${violation.rule}: ${violation.error}"
    }
}

package io.github.codex07.iou.io

import io.github.codex07.iou.api.ImportRowKey
import io.github.codex07.iou.api.SkippedRow
import io.github.codex07.iou.ledger.model.Change
import io.github.codex07.iou.ledger.model.EntityType
import io.github.codex07.iou.ledger.model.EntryRevision

import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.PaymentHandle
import io.github.codex07.iou.ledger.model.Person

import io.github.codex07.iou.ledger.rules.LedgerValidator
import io.github.codex07.iou.ledger.rules.WriteOp
import java.time.Instant

/**
 * Undo of one import batch (spec §5.4), best-effort. It reads what the batch did from the revisions tagged
 * with its ID, and works out from the data alone which owned rows changed together with their owner.
 *
 * Order: entries, then handles undone on their own, then people with their cascade. A row is undone only if
 * its current version is still the one the import wrote. An owner is skipped when a row its cascade would
 * touch isn't one the import changed through it, unchanged since. Each step is checked against the state
 * invariants. One that would break one waits and is tried again once the other steps are done, since a later
 * step can be what makes it valid (a transfer moved back to a person whom the import deleted, restored by the
 * people step). Steps that still break one when a whole retry round applies nothing are skipped.
 */
object ImportUndo {

    data class Result(val changes: List<Change>, val skipped: List<SkippedRow>)

    private class Touched(val revisions: List<EntryRevision>, val pre: LedgerEntity?) {
        val created: Boolean get() = revisions.first().action == RevisionAction.CREATED
        val lastVersion: Int get() = revisions.last().version
        fun did(action: RevisionAction) = revisions.any { it.action == action }
    }

    fun plan(state: LedgerState, revisions: List<EntryRevision>, batch: ImportBatch, now: Instant): Result {
        if (batch.undoneAt != null) return Result(emptyList(), emptyList())
        val reason = "Undo import ${batch.fileName}"
        val me = state.me.id
        val byEntity = revisions.groupBy { it.entityType to it.entityId }
        val touched = byEntity.mapNotNull { (key, history) ->
            val ofBatch = history.filter { it.importBatchId == batch.id }
            if (ofBatch.isEmpty()) return@mapNotNull null
            val pre = history.lastOrNull { it.version < ofBatch.first().version }?.snapshot
            key to Touched(ofBatch, pre)
        }.toMap()

        var current = state
        val changes = mutableListOf<Change>()
        val skipped = mutableListOf<SkippedRow>()

        fun entity(type: EntityType, id: String): LedgerEntity? = when (type) {
            EntityType.PERSON -> current.people.values.firstOrNull { it.entityId == id }
            EntityType.PAYMENT_HANDLE -> current.handles.values.firstOrNull { it.entityId == id }
            EntityType.TRANSFER, EntityType.EXPENSE -> current.entries.firstOrNull { it.entityId == id }
            else -> null
        }

        fun unchanged(type: EntityType, id: String): Boolean =
            entity(type, id)?.meta?.version == touched[type to id]?.lastVersion

        fun change(entity: LedgerEntity, target: LedgerEntity, deletedAt: Instant?): Change {
            val action = when {
                entity.isDeleted && deletedAt == null -> RevisionAction.RESTORED
                !entity.isDeleted && deletedAt != null -> RevisionAction.DELETED
                else -> RevisionAction.UPDATED
            }
            val meta = entity.meta.copy(updatedAt = now, authorId = me, version = entity.meta.version + 1, deletedAt = deletedAt, importBatchId = null)
            return Change(target.withMeta(meta), action, reason)
        }

        /** Applies [step] if it keeps the state invariants; otherwise returns the rules it would break. */
        fun apply(step: List<Change>): List<Int> {
            val after = current.applying(step)
            val broken = LedgerValidator.validate(current, after, WriteOp.UndoImport) - LedgerValidator.validate(current, current, WriteOp.UndoImport).toSet()
            if (broken.isEmpty()) {
                current = after
                changes += step
            }
            return broken.map { it.rule }
        }

        /** Steps that would break an invariant when tried, with their keys, to try again at the end. */
        val waiting = mutableListOf<Pair<List<ImportRowKey>, List<Change>>>()

        fun attempt(keys: List<ImportRowKey>, step: List<Change>) {
            if (step.isNotEmpty() && apply(step).isNotEmpty()) waiting += keys to step
        }

        /** The undo of one row on its own: delete what it created, put back what it changed. */
        fun ownUndo(type: EntityType, id: String): Change? {
            val row = touched.getValue(type to id)
            val entity = entity(type, id) ?: return null
            return if (row.created) {
                if (entity.isDeleted) null else change(entity, entity, now)
            } else {
                val pre = row.pre ?: return null
                val deletedAt = if (pre.isDeleted) (entity.meta.deletedAt ?: now) else null
                change(entity, pre, deletedAt).takeIf { it.entity.meta.deletedAt != entity.meta.deletedAt || pre.withMeta(entity.meta) != entity }
            }
        }

        fun key(type: EntityType, id: String) = ImportRowKey(type, id)

        /** [entity] with its business fields from before the batch, unless the batch created it. */
        fun beforeImport(entity: LedgerEntity): LedgerEntity =
            touched[entity.entityType to entity.entityId]?.takeIf { !it.created }?.pre ?: entity

        // Entries.
        for ((key, _) in touched.filterKeys { it.first == EntityType.TRANSFER || it.first == EntityType.EXPENSE }) {
            val (type, id) = key
            if (!unchanged(type, id)) {
                skipped += SkippedRow(key(type, id), "changed since the import")
                continue
            }
            ownUndo(type, id)?.let { attempt(listOf(key(type, id)), listOf(it)) }
        }

        // Handles that changed with their owner go back with the owner's cascade; the rest go back on their own.
        val people = touched.filterKeys { it.first == EntityType.PERSON }
        fun withOwner(handle: PaymentHandle, row: Touched): Boolean {
            val owner = people[EntityType.PERSON to handle.personId.value] ?: return false
            val ownerEntity = state.people[handle.personId] ?: return false
            return when {
                owner.created -> row.created
                owner.did(RevisionAction.RESTORED) && !ownerEntity.isDeleted ->
                    row.created || (row.did(RevisionAction.RESTORED) && row.pre?.meta?.deletedAt == owner.pre?.meta?.deletedAt)
                owner.did(RevisionAction.DELETED) && ownerEntity.isDeleted -> handle.meta.deletedAt == ownerEntity.meta.deletedAt
                else -> false
            }
        }
        val handles = touched.filterKeys { it.first == EntityType.PAYMENT_HANDLE }
        val handlesWithOwner = mutableSetOf<String>()
        for ((key, row) in handles) {
            val handle = entity(key.first, key.second) as? PaymentHandle ?: continue
            if (withOwner(handle, row)) {
                handlesWithOwner += key.second
                continue
            }
            if (!unchanged(key.first, key.second)) {
                skipped += SkippedRow(key(key.first, key.second), "changed since the import")
                continue
            }
            ownUndo(key.first, key.second)?.let { attempt(listOf(key(key.first, key.second)), listOf(it)) }
        }

        // People, with their cascade.
        for ((key, row) in people) {
            val person = entity(key.first, key.second) as? Person ?: continue
            val personKey = key(EntityType.PERSON, person.id.value)
            val deleting = !person.isDeleted && (row.created || row.did(RevisionAction.RESTORED))
            val restoring = person.isDeleted && !row.created && row.did(RevisionAction.DELETED)
            val cascade = when {
                deleting -> current.handles.values.filter { it.personId == person.id && !it.isDeleted }
                restoring -> current.handles.values.filter { it.personId == person.id && it.meta.deletedAt == person.meta.deletedAt && touched[EntityType.PAYMENT_HANDLE to it.id.value]?.created != true }
                else -> emptyList()
            }
            val cascadeKeys = cascade.map { key(EntityType.PAYMENT_HANDLE, it.id.value) }
            val protected = cascade.filter { it.id.value !in handlesWithOwner || !unchanged(EntityType.PAYMENT_HANDLE, it.id.value) }
            if (!unchanged(EntityType.PERSON, person.id.value)) {
                skipped += SkippedRow(personKey, "changed since the import")
                cascadeKeys.forEach { skipped += SkippedRow(it, "its owner changed since the import") }
                continue
            }
            if (protected.isNotEmpty()) {
                skipped += SkippedRow(personKey, "owns rows changed or added since the import")
                cascadeKeys.forEach { skipped += SkippedRow(it, "owns rows changed or added since the import") }
                continue
            }
            val step = when {
                deleting -> (listOf<LedgerEntity>(person) + cascade).map { change(it, beforeImport(it), now) }
                restoring -> (listOf<LedgerEntity>(person) + cascade).map { change(it, beforeImport(it), null) }
                row.created -> emptyList()
                else -> listOfNotNull(ownUndo(EntityType.PERSON, person.id.value))
            }
            attempt(listOf(personKey) + cascadeKeys, step)
        }

        // Retry what waited until a round applies nothing. A waiting step's rows changed in no other step, so
        // the step still applies as built.
        do {
            val round = waiting.toList()
            waiting.clear()
            round.forEach { (keys, step) -> attempt(keys, step) }
        } while (waiting.isNotEmpty() && waiting.size < round.size)
        for ((keys, step) in waiting) {
            val rule = apply(step).first()
            keys.forEach { skipped += SkippedRow(it, "would break rule $rule") }
        }
        return Result(changes, skipped)
    }
}

/**
 * The real flavor's import and export (spec §7.2, §7.4, §7.5, §5.4). A parsed file stays in memory as a
 * session under its preview's ID, so `applyChoices` stays pure and a refresh can rebuild the preview against
 * the current ledger. Sessions don't survive the process; a preview from before a restart gives
 * `NotFound("preview")`.
 */
class RealImportExportApi(
    private val store: LedgerStore,
    private val documents: DocumentStore,
    private val exporter: LedgerExport,
    private val reader: ImportReader = ImportReader(),
    private val maxFileBytes: Long = 20L * 1024 * 1024,
    private val computeDispatcher: CoroutineDispatcher = Dispatchers.Default,
) : ImportExportApi {

    private class Session(val fileName: String, val decoded: DecodedImport, val sourceMe: PersonId?) {
        @Volatile var mapped = false
        @Volatile var choices = ImportChoices()
        @Volatile var analysis: ImportAnalysis? = null
    }

    private val sessions = ConcurrentHashMap<String, Session>()

    /** Errors: those of `ExportRules.check`, `NotFound` for the scope, `FileAccessFailed`. */
    override suspend fun export(request: ExportRequest, target: DocumentRef): LedgerResult<ExportInfo> {
        ExportRules.check(request)?.let { return LedgerResult.Err(it) }
        val state = store.loaded().state
        exporter.scopeError(state, request.scope)?.let { return LedgerResult.Err(it) }
        val now = store.now()
        val written = withContext(Dispatchers.IO) {
            access(target) {
                documents.openWrite(target).use { out ->
                    when (request.shape) {
                        ExportShape.NORMALIZED -> LedgerResult.Ok(exporter.normalized(state, now, request.excelFriendly, out))
                        ExportShape.REPORT -> exporter.report(state, request.scope, request.from, request.to, request.excelFriendly, out)
                    }
                }
            }
        }
        return when (written) {
            is LedgerResult.Err -> written
            is LedgerResult.Ok -> written.value.map(::ExportInfo)
        }
    }

    /** Errors: `FileAccessFailed`, `CorruptFile`, `SchemaTooNew`, `LimitsExceeded`, `NotFound("me")` before setup. */
    override suspend fun parseImport(source: DocumentRef): LedgerResult<ImportPreview> = withContext(computeDispatcher) {
        val bytes = when (val read = withContext(Dispatchers.IO) { access(source) { documents.openRead(source).use { it.readAtMost(maxFileBytes) } } }) {
            is LedgerResult.Err -> return@withContext read
            is LedgerResult.Ok -> read.value ?: return@withContext LedgerResult.Err(LedgerError.LimitsExceeded("File larger than $maxFileBytes bytes"))
        }
        val file = when (val parsed = reader.read(bytes)) {
            is LedgerResult.Err -> return@withContext parsed
            is LedgerResult.Ok -> parsed.value
        }
        val snapshot = store.loaded()
        val me = snapshot.state.meOrNull?.id ?: return@withContext LedgerResult.Err(LedgerError.NotFound("me"))
        val decoded = ImportDecoder.decode(file)
        val sourceMe = decoded.ledger.people.firstOrNull { it.record.isMe }?.record?.id
        val session = Session(fileName(source), decoded, sourceMe)
        val id = store.ids.next()
        sessions[id] = session
        LedgerResult.Ok(
            if (sourceMe == null || sourceMe == me) {
                build(id, session, snapshot, ImportIdentity.Same, previous = null)
            } else {
                pending(id, session, snapshot, sourceMe)
            },
        )
    }

    override suspend fun confirmIdentity(preview: ImportPreview, accept: Boolean): LedgerResult<ImportPreview> {
        val snapshot = store.loaded()
        if (preview.generation != snapshot.generation) return LedgerResult.Err(LedgerError.LedgerReplaced)
        val pending = preview.identity as? ImportIdentity.NeedsConfirmation ?: return LedgerResult.Ok(preview)
        if (!accept) {
            sessions.remove(preview.id)
            return LedgerResult.Err(LedgerError.ForeignLedger)
        }
        val session = sessions[preview.id] ?: return LedgerResult.Err(LedgerError.NotFound("preview"))
        session.mapped = true
        return LedgerResult.Ok(build(preview.id, session, snapshot, ImportIdentity.Mapped(pending.sourceMe), previous = null))
    }

    override fun applyChoices(preview: ImportPreview, choices: ImportChoices): ImportPreview {
        val session = sessions[preview.id] ?: return preview
        val analysis = session.analysis ?: return preview
        session.choices = choices
        val flagged = preview.rows.associate { it.key to it.changedSinceLastPreview }
        return preview.copy(
            rows = analysis.previewRows(choices.takeIncoming).map { it.copy(changedSinceLastPreview = flagged[it.key] ?: false) },
            balanceChanges = analysis.balanceChanges(choices.takeIncoming),
        )
    }

    override suspend fun refreshPreview(preview: ImportPreview): LedgerResult<ImportPreview> {
        val snapshot = store.loaded()
        if (preview.generation != snapshot.generation) return LedgerResult.Err(LedgerError.LedgerReplaced)
        val session = sessions[preview.id] ?: return LedgerResult.Err(LedgerError.NotFound("preview"))
        if (preview.identity is ImportIdentity.NeedsConfirmation) return LedgerResult.Ok(preview)
        return LedgerResult.Ok(withContext(computeDispatcher) { build(preview.id, session, snapshot, preview.identity, previous = preview) })
    }

    override suspend fun commitImport(preview: ImportPreview, choices: ImportChoices): LedgerResult<ImportBatchId> {
        val result = store.writeWith { snapshot, context ->
            val analysis = sessions[preview.id]?.analysis
            when {
                preview.generation != snapshot.generation -> LedgerResult.Err(LedgerError.LedgerReplaced)
                preview.ledgerSeq != snapshot.ledgerSeq -> LedgerResult.Err(LedgerError.ImportPreviewStale)
                preview.identity is ImportIdentity.NeedsConfirmation -> LedgerResult.Err(LedgerError.ForeignLedger)
                analysis == null -> LedgerResult.Err(LedgerError.NotFound("preview"))
                analysis.state !== snapshot.state -> LedgerResult.Err(LedgerError.ImportPreviewStale)
                analysis.invalid.isNotEmpty() && !choices.skipInvalidRows -> LedgerResult.Err(LedgerError.InvalidField("invalidRows"))
                else -> {
                    val id = ImportBatchId(context.ids.next())
                    val plan = analysis.plan(choices.takeIncoming, id, context.now)
                    val violation = LedgerValidator.validate(snapshot.state, plan.state, WriteOp.Import).firstOrNull()
                    if (violation != null) {
                        LedgerResult.Err(violation.error)
                    } else {
                        val batch = ImportBatch(id, ImportSource.OWN_NORMALIZED_CSV, analysis.fileName, context.now, plan.rowCount)
                        LedgerResult.Ok(StoreWrite(id, WritePlan(plan.changes, plan.snapshots), importBatches = listOf(batch)))
                    }
                }
            }
        }
        if (result is LedgerResult.Ok) sessions.remove(preview.id)
        return result
    }

    override fun observeImportBatches(): Flow<List<ImportBatchView>> = store.readSnapshot { snapshot ->
        snapshot.importBatches.sortedByDescending { it.importedAt }
            .map { ImportBatchView(it.id, it.fileName, it.importedAt, it.rowCount, it.undoneAt) }
    }

    /** Best-effort (spec §5.4). An already undone batch does nothing. Errors: `NotFound`. */
    override suspend fun undoImport(id: ImportBatchId): LedgerResult<UndoImportResult> = store.writeWith { snapshot, context ->
        val batch = snapshot.importBatches.firstOrNull { it.id == id } ?: return@writeWith LedgerResult.Err(LedgerError.NotFound(id.value))
        val undo = ImportUndo.plan(snapshot.state, snapshot.revisions, batch, context.now)
        val undone = if (batch.undoneAt == null) listOf(batch.copy(undoneAt = context.now)) else emptyList()
        LedgerResult.Ok(StoreWrite(UndoImportResult(undo.skipped), WritePlan(undo.changes), importBatches = undone))
    }

    private fun pending(id: String, session: Session, snapshot: StoreSnapshot, sourceMe: PersonId) = ImportPreview(
        id = id, fileName = session.fileName, generation = snapshot.generation, ledgerSeq = snapshot.ledgerSeq,
        identity = ImportIdentity.NeedsConfirmation(sourceMe), counts = ImportCounts(0, 0, 0, 0),
        rows = emptyList(), invalidRows = emptyList(), balanceChanges = emptyList(),
    )

    /** Analyses the session against [snapshot]; with [previous], rows that are new or whose diff changed are flagged. */
    private fun build(id: String, session: Session, snapshot: StoreSnapshot, identity: ImportIdentity, previous: ImportPreview?): ImportPreview {
        val analysis = ImportAnalysis.build(snapshot.state, session.fileName, session.decoded, if (session.mapped) session.sourceMe else null)
        session.analysis = analysis
        val take = session.choices.takeIncoming
        val before = previous?.rows?.associateBy { it.key }
        val rows = analysis.previewRows(take).map { row: ImportRow ->
            row.copy(changedSinceLastPreview = before != null && before[row.key]?.changes != row.changes)
        }
        return ImportPreview(
            id = id, fileName = session.fileName, generation = snapshot.generation, ledgerSeq = snapshot.ledgerSeq,
            identity = identity, counts = analysis.counts, rows = rows, invalidRows = analysis.invalid,
            balanceChanges = analysis.balanceChanges(take),
        )
    }

    /**
     * The document's file name, from the last path segment of its URI (SAF URIs encode the path). The
     * charset-name overload: the `Charset` one needs API 33 (minSdk is 30).
     */
    private fun fileName(ref: DocumentRef): String =
        URLDecoder.decode(ref.uri.substringAfterLast('/'), "UTF-8").substringAfterLast('/').substringAfterLast(':')

    /** Runs a document read or write; a missing document or a revoked permission becomes `FileAccessFailed`. */
    private inline fun <T> access(ref: DocumentRef, block: () -> T): LedgerResult<T> = try {
        LedgerResult.Ok(block())
    } catch (e: IOException) {
        LedgerResult.Err(LedgerError.FileAccessFailed("${ref.uri}: ${e.message}"))
    } catch (e: SecurityException) {
        LedgerResult.Err(LedgerError.FileAccessFailed("${ref.uri}: ${e.message}"))
    }
}

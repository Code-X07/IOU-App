# M1 Part 2: Room Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** Persist the ledger in Room: one table per record type, revision snapshots as versioned JSON, and a `RoomJournal` that writes each store commit in one transaction. `LedgerLoader` reads a whole database back into a `LedgerContent`.

**Architecture:** `data` holds plain Room rows (`*Row`, text and integer columns only). The rows are also the JSON shape of revision snapshots (and, in Part 5, of backups), so one mapping (`RowMapping.kt`) serves all three. `SnapshotCodec` wraps a row in `{ "schema": 1, … }` and has an upcaster hook for later row changes (spec §5.5). `RoomJournal.append` runs `RoomJournal.write` inside `useWriterConnection { immediateTransaction { } }`; the store (Part 1) publishes only after it returns. Tests run Room on the plain JVM with the bundled SQLite driver.

**Tech Stack:** Room 2.8.1 (KSP, driver API), androidx.sqlite 2.6.1 (`sqlite-framework` on the device, `sqlite-bundled-jvm` in tests), kotlinx.serialization 1.9.0, JUnit 5, Kotest.

## Global Constraints

- Room entities and DAOs live in `data`. Only `data` uses `LedgerDao`, so every ledger write goes through the journal (spec §2.2); `DataAccessTest` checks this.
- No `Double`/`Float` in `data` (`DomainPurityTest`). Money is stored as `Long` minor units plus an ISO 4217 code; rates as decimal strings (spec §3.1, §3.2).
- The mapping is lossless: instants keep their nanoseconds (ISO-8601 text), dates are ISO `yyyy-MM-dd`, enums are stored by name (AC M1-7 needs identical round trips).
- `EntryRevision` is append-only: inserted, never updated (spec §3.2). FX snapshots are immutable: a second insert of the same ID fails (spec §3.2).
- Each `snapshotJson` carries `schema: Int`; stored snapshots are never rewritten (spec §5.5).
- One store write = one Room transaction: a failure part-way leaves no row and no revision (spec §5.1, §11).
- Room schema exports are tracked in `android/app/schemas/` (root `CLAUDE.md`).

## Decisions this part makes

- **Rows double as JSON.** Every `*Row` is `@Entity` and `@Serializable`. A revision snapshot is the entity's row (an expense also carries its share rows). Part 5's backup is the list of rows per table. A column change therefore bumps `SnapshotCodec.CURRENT_SCHEMA` and adds an upcaster in the same commit as the Room migration.
- **Ordered reads.** The store keeps revisions and import batches in append order. The loader reads both `ORDER BY rowid`. Share order is kept in `ShareRow.position`.
- **`REPLACE`, not `@Upsert`.** Writes replace whole rows (`@Insert(onConflict = REPLACE)`). On the plain JVM, Room's `@Upsert` inspects the message of an Android-stub `SQLException`, which is always null there. There are no foreign keys, so a replace has no cascade side effects. A replaced import batch moves to the end of the `rowid` order, as the store moves it.
- **Journal mode WAL.** Room keeps separate reader and writer connections. In a rollback-journal mode, an earlier read blocks the next write on a file database (found while building Part 3). In WAL, readers never block the writer. Closing the last connection checkpoints the WAL into the database file and deletes `-wal` and `-shm`, so a closed database is exactly one file again, which Part 5's restore relies on. A `.lck` lock file may stay next to it and is harmless.
- **The schema has every M1/M2 table from version 1**, including groups, memberships and the FX rate cache (Part 4). Version 1 ships only with M1's release, so no migration is needed before then.
- **Ledger settings and `ledgerSeq`** are rows of `app_setting` (`homeCurrency`, `backupEncryptionDefault`, `ledgerSeq`), rewritten by every journal entry.

import io.github.codex07.iou.ledger.model.Transfer
import java.time.Instant
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.decodeFromJsonElement
import kotlinx.serialization.json.int
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/**
 * The JSON of `EntryRevision.snapshotJson` (spec §3.2, §5.5): the entity's row, an expense with its share
 * rows, plus a `schema` number. Stored snapshots are never rewritten. When a migration changes a row,
 * [CURRENT_SCHEMA] goes up and an entry in [upcasters] turns the previous schema's JSON into the next one's
 * when it is read.
 */
object SnapshotCodec {
    const val CURRENT_SCHEMA = 1

    /** Schema n → n + 1, applied in order to older snapshots. Empty until the first row change. */
    private val upcasters: Map<Int, (JsonObject) -> JsonObject> = emptyMap()

    internal val json = Json {
        encodeDefaults = true
        explicitNulls = true
        ignoreUnknownKeys = false
    }

    @Serializable
    private data class Snapshot(
        val schema: Int,
        val person: PersonRow? = null,
        val handle: HandleRow? = null,
        val group: GroupRow? = null,
        val member: MemberRow? = null,
        val transfer: TransferRow? = null,
        val expense: ExpenseRow? = null,
        val shares: List<ShareRow>? = null,
    )

    fun encode(entity: LedgerEntity): String = json.encodeToString(
        Snapshot.serializer(),
        when (entity) {
            is Person -> Snapshot(CURRENT_SCHEMA, person = entity.toRow())
            is PaymentHandle -> Snapshot(CURRENT_SCHEMA, handle = entity.toRow())
            is Group -> Snapshot(CURRENT_SCHEMA, group = entity.toRow())
            is GroupMember -> Snapshot(CURRENT_SCHEMA, member = entity.toRow())
            is Transfer -> Snapshot(CURRENT_SCHEMA, transfer = entity.toRow())
            is Expense -> Snapshot(CURRENT_SCHEMA, expense = entity.toRow(), shares = entity.shareRows())
        },
    )

    /** Throws [IllegalArgumentException] for a snapshot from a newer schema or one that names no entity. */
    fun decode(text: String): LedgerEntity {
        var obj = json.parseToJsonElement(text).jsonObject
        var schema = obj.getValue("schema").jsonPrimitive.int
        require(schema <= CURRENT_SCHEMA) { "Snapshot schema $schema is newer than $CURRENT_SCHEMA" }
        while (schema < CURRENT_SCHEMA) {
            obj = upcasters.getValue(schema)(obj)
            schema += 1
        }
        val snapshot = json.decodeFromJsonElement<Snapshot>(obj)
        return snapshot.person?.toPerson()
            ?: snapshot.handle?.toHandle()
            ?: snapshot.group?.toGroup()
            ?: snapshot.member?.toMember()
            ?: snapshot.transfer?.toTransfer()
            ?: snapshot.expense?.toExpense(snapshot.shares.orEmpty())
            ?: throw IllegalArgumentException("Snapshot names no entity")
    }
}

fun EntryRevision.toRow() = RevisionRow(
    id = id.value, entityType = entityType.name, entityId = entityId, version = version, action = action.name,
    authorId = authorId.value, deviceId = deviceId.value, at = at.toString(), reason = reason,
    importBatchId = importBatchId?.value, snapshotJson = SnapshotCodec.encode(snapshot),
)

fun RevisionRow.toRevision() = EntryRevision(
    id = RevisionId(id), entityType = EntityType.valueOf(entityType), entityId = entityId, version = version,
    action = RevisionAction.valueOf(action), authorId = PersonId(authorId), deviceId = DeviceId(deviceId),
    at = Instant.parse(at), reason = reason, importBatchId = importBatchId?.let(::ImportBatchId),
    snapshot = SnapshotCodec.decode(snapshotJson),
)

package io.github.codex07.iou.data

import android.content.Context
import androidx.room.Dao
import androidx.room.Database
import androidx.room.Insert
import androidx.room.OnConflictStrategy
import androidx.room.Query
import androidx.room.Room
import androidx.room.RoomDatabase
import androidx.sqlite.SQLiteDriver
import kotlinx.coroutines.Dispatchers

/**
 * Every ledger table (spec §3). Only [RoomJournal] and the backup restore write it; nothing outside `data`
 * may touch [LedgerDao] (checked by `DataAccessTest`). Rows are replaced whole (`REPLACE`; there are no
 * foreign keys); a replaced import batch moves to the end of the `rowid` order, as it does in the store.
 */
@Dao
interface LedgerDao {
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertPeople(rows: List<PersonRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertHandles(rows: List<HandleRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertGroups(rows: List<GroupRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertMembers(rows: List<MemberRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertTransfers(rows: List<TransferRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertExpenses(rows: List<ExpenseRow>)
    @Query("DELETE FROM expense_share WHERE expenseId = :expenseId") suspend fun deleteShares(expenseId: String)
    @Insert suspend fun insertShares(rows: List<ShareRow>)

    /** Snapshots are immutable (spec §3.2): a second insert of the same ID fails the transaction. */
    @Insert suspend fun insertFxSnapshots(rows: List<FxSnapshotRow>)
    @Insert suspend fun insertRevisions(rows: List<RevisionRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertImportBatches(rows: List<ImportBatchRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertSettings(rows: List<AppSettingRow>)
    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertRates(rows: List<FxRateRow>)

    @Query("SELECT * FROM person") suspend fun people(): List<PersonRow>
    @Query("SELECT * FROM payment_handle") suspend fun handles(): List<HandleRow>
    @Query("SELECT * FROM ledger_group") suspend fun groups(): List<GroupRow>
    @Query("SELECT * FROM group_member") suspend fun members(): List<MemberRow>
    @Query("SELECT * FROM transfer") suspend fun transfers(): List<TransferRow>
    @Query("SELECT * FROM expense") suspend fun expenses(): List<ExpenseRow>
    @Query("SELECT * FROM expense_share ORDER BY expenseId, position") suspend fun shares(): List<ShareRow>
    @Query("SELECT * FROM fx_snapshot") suspend fun fxSnapshots(): List<FxSnapshotRow>
    @Query("SELECT * FROM entry_revision ORDER BY rowid") suspend fun revisions(): List<RevisionRow>
    @Query("SELECT * FROM import_batch ORDER BY rowid") suspend fun importBatches(): List<ImportBatchRow>
    @Query("SELECT * FROM app_setting") suspend fun settings(): List<AppSettingRow>
    @Query("SELECT * FROM fx_rate_cache") suspend fun rates(): List<FxRateRow>
}

@Database(
    entities = [
        PersonRow::class, HandleRow::class, GroupRow::class, MemberRow::class, TransferRow::class, ExpenseRow::class,
        ShareRow::class, FxSnapshotRow::class, RevisionRow::class, ImportBatchRow::class, AppSettingRow::class, FxRateRow::class,
    ],
    version = 1,
    exportSchema = true,
)
abstract class IouDatabase : RoomDatabase() {
    abstract fun ledgerDao(): LedgerDao

    companion object {
        /**
         * Opens the database at the absolute path [file], or an in-memory one when [file] is null. In WAL mode
         * readers never block the writer, and closing the last connection checkpoints the WAL into the database
         * file and deletes it, so a closed database is a single file; the restore's file swap relies on that
         * (spec §7.1).
         */
        fun open(context: Context, driver: SQLiteDriver, file: String?): IouDatabase {
            val builder = if (file == null) {
                Room.inMemoryDatabaseBuilder(context, IouDatabase::class.java)
            } else {
                Room.databaseBuilder(context, IouDatabase::class.java, file)
            }
            return builder
                .setDriver(driver)
                .setJournalMode(JournalMode.WRITE_AHEAD_LOGGING)
                .setQueryCoroutineContext(Dispatchers.IO)
                .build()
        }
    }
}

/** Where [RoomJournal] finds the live database; Part 3's holder swaps it on restore. */
fun interface DatabaseProvider {
    fun database(): IouDatabase
}

/** The real flavor's journal (spec §5.1 `LedgerWriter`): one Room transaction per store write. */
class RoomJournal(private val databases: DatabaseProvider) : LedgerJournal {

    override suspend fun append(entry: JournalEntry) {
        val db = databases.database()
        db.useWriterConnection { connection ->
            connection.immediateTransaction { write(db.ledgerDao(), entry) }
        }
    }

    companion object {
        /** Writes [entry] through [dao]; the caller provides the transaction. Also used by the backup restore. */
        suspend fun write(dao: LedgerDao, entry: JournalEntry) {
            val entities = entry.changes.map { it.entity }
            dao.insertFxSnapshots(entry.snapshots.map { it.toRow() })
            dao.upsertPeople(entities.filterIsInstance<Person>().map { it.toRow() })
            dao.upsertHandles(entities.filterIsInstance<PaymentHandle>().map { it.toRow() })
            dao.upsertGroups(entities.filterIsInstance<Group>().map { it.toRow() })
            dao.upsertMembers(entities.filterIsInstance<GroupMember>().map { it.toRow() })
            dao.upsertTransfers(entities.filterIsInstance<Transfer>().map { it.toRow() })
            val expenses = entities.filterIsInstance<Expense>()
            dao.upsertExpenses(expenses.map { it.toRow() })
            for (expense in expenses) {
                dao.deleteShares(expense.id.value)
                dao.insertShares(expense.shareRows())
            }
            dao.insertRevisions(entry.revisions.map { it.toRow() })
            dao.upsertImportBatches(entry.importBatches.map { it.toRow() })
            dao.upsertSettings(settingRows(entry.settings, entry.ledgerSeq))
        }

        fun settingRows(settings: LedgerSettings, ledgerSeq: Long) = listOf(
            AppSettingRow(SettingKeys.HOME_CURRENCY, settings.homeCurrency.code),
            AppSettingRow(SettingKeys.BACKUP_ENCRYPTION_DEFAULT, settings.backupEncryptionDefault.toString()),
            AppSettingRow(SettingKeys.LEDGER_SEQ, ledgerSeq.toString()),
        )
    }
}

/** Reads a whole ledger database into memory (ADR-0010). An empty database gives an empty ledger with defaults. */
object LedgerLoader {

    suspend fun load(db: IouDatabase): LedgerContent {
        val dao = db.ledgerDao()
        val shares = dao.shares().groupBy { it.expenseId }
        val state = LedgerState(
            people = dao.people().associate { PersonId(it.id) to it.toPerson() },
            handles = dao.handles().associate { HandleId(it.id) to it.toHandle() },
            groups = dao.groups().associate { GroupId(it.id) to it.toGroup() },
            members = dao.members().associate { MembershipId(it.id) to it.toMember() },
            transfers = dao.transfers().associate { EntryId(it.id) to it.toTransfer() },
            expenses = dao.expenses().associate { EntryId(it.id) to it.toExpense(shares[it.id].orEmpty()) },
            fxSnapshots = dao.fxSnapshots().associate { FxSnapshotId(it.id) to it.toSnapshot() },
        )
        val settings = dao.settings().associate { it.key to it.value }
        val defaults = LedgerSettings()
        return LedgerContent(
            state = state,
            revisions = dao.revisions().map { it.toRevision() },
            importBatches = dao.importBatches().map { it.toBatch() },
            ledgerSeq = settings[SettingKeys.LEDGER_SEQ]?.toLong() ?: 0,
            settings = LedgerSettings(
                homeCurrency = settings[SettingKeys.HOME_CURRENCY]?.let(::CurrencyCode) ?: defaults.homeCurrency,
                backupEncryptionDefault = settings[SettingKeys.BACKUP_ENCRYPTION_DEFAULT]?.toBooleanStrict() ?: defaults.backupEncryptionDefault,
            ),
        )
    }
}

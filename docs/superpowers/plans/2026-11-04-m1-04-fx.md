# M1 Part 4: FX Rates, Rate Cache and Daily Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** The `real` flavor quotes exchange rates through the spec §4.5 lookup chain (cache, Frankfurter, latest cached as stale, user-entered). Fetched rates are cached in `fx_rate_cache`, the overview's approximate home-currency totals use the latest cached rates, and a daily WorkManager job refreshes them. The FX contract suite passes against the real backend.

**Architecture:** A new Android-free package `fx` holds three pieces. `FrankfurterClient` (Ktor) fetches EUR rates. `RateTable` keeps cached rates in memory and inverts or crosses them. `FxService` runs the lookup chain over a `RateCache` port and publishes a `RateLookup` for the store's views. `data.RoomRateCache` is that port on the live database. Both flavors share one `FxApi`, `store.StoreFxApi`, on a `QuoteSource`: the fake's demo table or `FxService`. In the `real` source set, `RateRefreshWorker` calls `RealBackend.refreshRates()` once a day.

**Tech Stack:** Ktor 3.2.3 (OkHttp engine; `MockEngine` in tests), kotlinx.serialization JSON (tree API), Room 2.8.1, WorkManager 2.10.3, Hilt entry points, JUnit 5, Kotest.

## Global Constraints

- **Lookup chain** `rateFor(occurredOn, from, to)` (spec §4.5):
  1. the cached historical rate for that date;
  2. the Frankfurter historical endpoint (`https://api.frankfurter.dev/v1/{date}`);
  3. the most recent cached rate, with the snapshot flagged `isStale = true`;
  4. no rate available, or a currency outside the ECB set: the user enters a rate manually (`USER_ENTERED`).
- **Rate semantics:** `rate` is major units of `quoteCurrency` per one major unit of `baseCurrency`. An inverted or cross rate is computed once with `MathContext.DECIMAL128` and stored as the snapshot's rate string (spec §4.5).
- **Valid rates:** a rate parses as `BigDecimal`, is > 0 and has at most 34 significant digits; otherwise `InvalidRate`. This applies to fetched, cached and user-entered rates alike (spec §4.5).
- **Refresh:** a daily WorkManager job (network required) caches the latest rates for the home currency and the currencies in use. Historical rates are cached forever (spec §4.5).
- **FX failures never block entry.** Network failure or an unsupported currency falls through the chain; at worst the user enters a rate. The refresh worker uses WorkManager's exponential backoff and stays silent (spec §8).
- **Rate cache table:** `FxRateCache(base, quote, rateDate, rate, fetchedAt)` (spec §3.3; Part 2's `FxRateRow`).
- **No floating point** in money paths (spec §11, `DomainPurityTest`). Fetched rates are read from the JSON text, never as `Double`.

## Decisions this part makes

- **Frankfurter is always asked for EUR rates**, the rates the ECB publishes. Other pairs are inverted or crossed locally (`RateTable`). For a non-EUR base, Frankfurter rounds the cross rate to 5 significant digits (on 2026-11-04, `base=SEK` gave `"EUR":0.091312`). Crossing locally keeps one cache format and makes the precision ours (`DECIMAL128`).
- **A fetched quote carries the date Frankfurter answered for**, and the rate is cached under that date. For a weekend, a holiday or a date before that day's publication, Frankfurter answers with the previous working day. Live check on 2026-11-04: `/v1/2026-11-01` (a Sunday) answered `"date":"2026-10-30"`. Step 1 matches exact dates only, so such a date asks Frankfurter again while online.
- **The stale fallback** (step 3) is the newest cached date that can answer the pair: directly, inverted or crossed through EUR.
- **Unavailable means any failure:** no network, a timeout (5 s connect, 10 s request), a status other than 200, or an unreadable answer. Live behaviour on 2026-11-04 was 404 for an unknown currency or a future date, 422 for a bad pair, and 522 earlier that day while the origin was down. Invalid fetched rates are dropped.
- **The cache is not ledger data.** It lives in the live database's `fx_rate_cache` table (Part 2), and `RoomRateCache` writes it directly; the journal never does. `FxService` holds it in memory after `load()`, which `RealBackend` runs at start-up before publishing the ledger. Part 5 runs `fx.load()` again after it swaps databases.
- **One `FxApi` for both flavors:** `store.StoreFxApi(QuoteSource)`. It handles typed rates (`userRate`) and bank-actual rates (`rateFromCharged`) itself, and asks its source only for lookups. The fake's source is `FakeRates.quote`; `FakeFxApi` keeps its name and now delegates to `StoreFxApi`.
- **The worker reaches the backend through a Hilt entry point**, not `HiltWorkerFactory`. It needs no `androidx.hilt:hilt-work`, no `Configuration.Provider` and no change to WorkManager's default initializer. The worker and WorkManager exist only in the `real` source set (`realImplementation`).
- **Scheduling:** Hilt's `RealBackend` provider schedules unique periodic work `fx-rate-refresh`: daily, network required, exponential backoff from 30 minutes, `KEEP`. A periodic request's first run is due at once.
- **Currencies in use** are the paid and effect currencies of all entries, deleted ones included, and the groups' default currencies. The refresh asks for these plus the home currency. Each non-EUR currency is requested separately, preserving each publication date, so an unsupported currency cannot block supported ones. Refresh succeeds when at least one requested rate is usable; with only EUR or an empty set there is nothing to ask and it succeeds without a request.
- **`INTERNET` is declared only by the `real` flavor** (`src/real/AndroidManifest.xml`). WorkManager adds `WAKE_LOCK`, `ACCESS_NETWORK_STATE`, `RECEIVE_BOOT_COMPLETED` and `FOREGROUND_SERVICE` to the real merged manifest; Part 8's manifest review covers them.
- **Package `fx`** is Android-free and floating-point-free (`DomainPurityTest`). Dependency direction: `store` ← `fx` ← `data`.

```kotlin
package io.github.codex07.iou.testutil

import io.github.codex07.iou.fx.FrankfurterClient
import io.ktor.client.HttpClient
import io.ktor.client.engine.mock.MockEngine
import io.ktor.client.engine.mock.respond
import io.ktor.http.HttpHeaders
import io.ktor.http.HttpStatusCode
import io.ktor.http.Url
import io.ktor.http.headersOf
import java.io.IOException
import java.time.LocalDate
import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.CopyOnWriteArrayList

/**
 * Frankfurter on Ktor's `MockEngine`, answering like the live v1 API: EUR rates as JSON numbers, a missing
 * date answered from the latest earlier one, 404 for an unknown currency or when no date fits, 422 for a base
 * other than EUR. With [online] false every request fails with an `IOException`.
 */
class FakeFrankfurter {
    /** EUR rates (JSON number text) by date. */
    val published: MutableMap<LocalDate, Map<String, String>> = ConcurrentHashMap()
    @Volatile var online = true
    val requests: MutableList<Url> = CopyOnWriteArrayList()

    fun publish(date: LocalDate, vararg perEur: Pair<String, String>) {
        published[date] = perEur.toMap()
    }

    fun client(): FrankfurterClient = FrankfurterClient(
        HttpClient(
            MockEngine { request ->
                requests += request.url
                if (!online) throw IOException("offline")
                val (status, body) = answer(request.url)
                respond(body, status, headersOf(HttpHeaders.ContentType, "application/json"))
            },
        ),
    )

    private fun answer(url: Url): Pair<HttpStatusCode, String> {
        if (url.parameters["base"] != "EUR") return HttpStatusCode.UnprocessableEntity to """{"message":"bad currency pair"}"""
        val asked = url.segments.last().let { if (it == "latest") LocalDate.MAX else LocalDate.parse(it) }
        val symbols = url.parameters["symbols"].orEmpty().split(',')
        val day = published.keys.filter { it <= asked }.maxOrNull()
        val rates = day?.let { published.getValue(it) }
        if (rates == null || symbols.any { it !in rates }) return HttpStatusCode.NotFound to """{"message":"not found"}"""
        val json = symbols.joinToString(",") { "\"$it\":${rates.getValue(it)}" }
        return HttpStatusCode.OK to """{"amount":1.0,"base":"EUR","date":"$day","rates":{$json}}"""
    }
}
```

```kotlin
package io.github.codex07.iou.fx

import io.github.codex07.iou.ledger.engine.FxConverter
import io.github.codex07.iou.money.CurrencyCode
import java.time.Instant
import java.time.LocalDate

/** A cached rate (spec §3.3): [rate] units of [quote] per one [base] on [rateDate]. */
data class CachedRate(
    val base: CurrencyCode,
    val quote: CurrencyCode,
    val rateDate: LocalDate,
    val rate: String,
    val fetchedAt: Instant,
)

/** A rate and the date it applies to. */
data class DatedRate(val rate: String, val date: LocalDate)

/**
 * Cached rates in memory. A pair that isn't cached directly is answered from its inverse or crossed through a
 * shared base on the same date, computed with `DECIMAL128` (spec §4.5). Rates must be valid
 * ([FxConverter.validateRate]); the cache only ever holds validated ones.
 */
class RateTable(rates: Collection<CachedRate> = emptyList()) {

    private data class Key(val base: CurrencyCode, val quote: CurrencyCode, val date: LocalDate)

    private val byKey: Map<Key, CachedRate> = rates.associateBy { Key(it.base, it.quote, it.rateDate) }
    private val byDate: Map<LocalDate, List<CachedRate>> = byKey.values.groupBy { it.rateDate }
    private val datesNewestFirst: List<LocalDate> = byDate.keys.sortedDescending()

    val rates: Collection<CachedRate> get() = byKey.values

    /** This table with [more] added; a rate for the same pair and date replaces the old one. */
    operator fun plus(more: Collection<CachedRate>): RateTable = RateTable(byKey.values + more)

    /** Units of [to] per one [from] on exactly [date], or null. The same currency is always "1". */
    fun on(date: LocalDate, from: CurrencyCode, to: CurrencyCode): String? {
        if (from == to) return "1"
        val day = byDate[date] ?: return null
        byKey[Key(from, to, date)]?.let { return it.rate }
        byKey[Key(to, from, date)]?.let { return FxConverter.invert(it.rate) }
        for (toRate in day.filter { it.quote == to }) {
            val fromRate = byKey[Key(toRate.base, from, date)] ?: continue
            return FxConverter.cross(homeToBase = fromRate.rate, homeToQuote = toRate.rate)
        }
        return null
    }

    /** The rate from the most recent date that has one, or null. */
    fun latest(from: CurrencyCode, to: CurrencyCode): DatedRate? =
        datesNewestFirst.firstNotNullOfOrNull { date -> on(date, from, to)?.let { DatedRate(it, date) } }
}
```

```kotlin
package io.github.codex07.iou.fx

import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.ledger.engine.FxConverter
import io.github.codex07.iou.money.CurrencyCode
import io.ktor.client.HttpClient
import io.ktor.client.engine.okhttp.OkHttp
import io.ktor.client.plugins.HttpTimeout
import io.ktor.client.request.get
import io.ktor.client.request.parameter
import io.ktor.client.statement.bodyAsText
import io.ktor.http.HttpStatusCode
import java.time.LocalDate
import kotlin.coroutines.cancellation.CancellationException
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/** Rates the ECB published for [date]: units of each currency per one EUR. */
data class PublishedRates(val date: LocalDate, val perEur: Map<CurrencyCode, String>)

/**
 * ECB reference rates from Frankfurter (spec §4.5). It always asks for EUR rates, which are the ones the
 * ECB publishes; other pairs are inverted or crossed locally ([RateTable]), so their precision doesn't
 * depend on Frankfurter's rounding of non-EUR bases. Rates are read from the JSON text, never as floating
 * point.
 */
class FrankfurterClient(private val http: HttpClient, private val baseUrl: String = BASE_URL) : AutoCloseable {

    /**
     * EUR rates for [currencies] on [date], or the latest when [date] is null. For a weekend, a holiday or a
     * date before today's publication, Frankfurter answers with the previous working day, so the result's
     * date can be earlier than [date]. Null when there is nothing to ask for or the rates are unavailable for
     * any reason: no network, a timeout, a status other than 200 (an unknown currency or a future date gives
     * 404), or an unreadable answer. Invalid rates are left out.
     */
    suspend fun eurRates(date: LocalDate?, currencies: Set<CurrencyCode>): PublishedRates? {
        val symbols = currencies.filter { it != EUR }.map { it.code }.sorted()
        if (symbols.isEmpty()) return null
        return try {
            val response = http.get("$baseUrl/${date ?: "latest"}") {
                parameter("base", EUR.code)
                parameter("symbols", symbols.joinToString(","))
            }
            if (response.status == HttpStatusCode.OK) parse(response.bodyAsText()) else null
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            null
        }
    }

    override fun close() = http.close()

    private fun parse(text: String): PublishedRates {
        val body = Json.parseToJsonElement(text).jsonObject
        val rates = body.getValue("rates").jsonObject.mapNotNull { (code, value) ->
            val currency = CurrencyCode.parse(code) ?: return@mapNotNull null
            val rate = FxConverter.validateRate(value.jsonPrimitive.content) as? LedgerResult.Ok ?: return@mapNotNull null
            currency to rate.value.stripTrailingZeros().toPlainString()
        }
        return PublishedRates(LocalDate.parse(body.getValue("date").jsonPrimitive.content), rates.toMap())
    }

    companion object {
        const val BASE_URL = "https://api.frankfurter.dev/v1"
        val EUR = CurrencyCode("EUR")

        /** The app's client: OkHttp with short timeouts, so a slow network never holds up an entry for long. */
        fun create(): FrankfurterClient = FrankfurterClient(
            HttpClient(OkHttp) {
                install(HttpTimeout) {
                    connectTimeoutMillis = 5_000
                    requestTimeoutMillis = 10_000
                }
```

```kotlin
package io.github.codex07.iou.fx

import io.github.codex07.iou.api.FxQuote
import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.ledger.model.FxSource
import io.github.codex07.iou.money.CurrencyCode
import io.github.codex07.iou.store.QuoteSource
import io.github.codex07.iou.store.RateLookup
import java.time.Clock
import java.time.LocalDate
import kotlin.coroutines.cancellation.CancellationException
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.filterNotNull
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock

/** Where fetched rates are kept: the `fx_rate_cache` table in the real flavor. */
interface RateCache {
    suspend fun load(): List<CachedRate>
    suspend fun save(rates: List<CachedRate>)
}

/**
 * The rate lookup chain (spec §4.5) and the rates behind approximate totals. The cache is held in memory
 * after [load], which must run before [quote] returns; quotes wait for it.
 */
class FxService(
    private val cache: RateCache,
    private val frankfurter: FrankfurterClient,
    private val clock: Clock,
) : QuoteSource {

    private val mutex = Mutex()
    private val table = MutableStateFlow<RateTable?>(null)
    private val latestRates = MutableStateFlow(RateLookup.None)

    /** The latest cached rate for each pair, for approximate home-currency totals (spec §4.3). */
    val lookup: StateFlow<RateLookup> = latestRates.asStateFlow()

    /** Reads the cache into memory. Also run after the database is replaced (Part 5). */
    suspend fun load() = mutex.withLock { publish(RateTable(cache.load())) }

    /**
     * 1. The cached rate for [date]. 2. Frankfurter for [date]; its answer is cached and may be for the
     * previous working day, which is the date the quote carries. 3. The most recent cached rate, flagged
     * stale. 4. `RateRequired`: the user enters a rate.
     */
    override suspend fun quote(date: LocalDate, from: CurrencyCode, to: CurrencyCode): LedgerResult<FxQuote> {
        val cached = table.filterNotNull().first()
        cached.on(date, from, to)?.let { return ok(from, to, DatedRate(it, date), stale = false) }
        val fetched = frankfurter.eurRates(date, setOf(from, to))?.let { published ->
            val rows = rows(published)
            val updated = try {
                add(rows)
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                cached + rows
            }
            updated.on(published.date, from, to)?.let { return ok(from, to, DatedRate(it, published.date), stale = false) }
            updated
        }
        (fetched ?: cached).latest(from, to)?.let { return ok(from, to, it, stale = true) }
        return LedgerResult.Err(LedgerError.RateRequired(from, to))
    }

    /**
     * Caches the latest EUR rates for [currencies] (the daily refresh), requesting each currency separately.
     * True when at least one rate was fetched or there is nothing to fetch; false when none was available.
     */
    suspend fun refresh(currencies: Set<CurrencyCode>): Boolean {
        val requested = currencies - FrankfurterClient.EUR
        if (requested.isEmpty()) return true
        var fetched = false
        for (currency in requested) {
            val published = frankfurter.eurRates(null, setOf(currency)) ?: continue
            if (currency !in published.perEur) continue
            add(rows(published))
            fetched = true
        }
        return fetched
    }

    private fun rows(published: PublishedRates): List<CachedRate> {
        val now = clock.instant()
        return published.perEur.map { (currency, rate) -> CachedRate(FrankfurterClient.EUR, currency, published.date, rate, now) }
    }

    private suspend fun add(rows: List<CachedRate>): RateTable = mutex.withLock {
        cache.save(rows)
        (checkNotNull(table.value) + rows).also(::publish)
    }
    private fun publish(rates: RateTable) {
        table.value = rates
        publishLookup(rates)
    }

    private fun publishLookup(rates: RateTable) {
```

```kotlin
/**
 * The real flavor's backend (ADR-0010): the shared store with a Room journal, the rate cache and Frankfurter,
 * the device settings file and the device ID file. Construction returns at once; [start] runs recovery, opens
 * the database the pointer names, loads the rate cache and publishes the ledger, and reads and writes wait

 *
 * Backup and import/export are still the simulations from `fake`; Parts 5 and 7 replace them.

class RealBackend(
    databaseDir: File,
    deviceIdFile: File,
    settingsFile: File,
    openDatabase: (File) -> IouDatabase,
    private val frankfurter: FrankfurterClient,
    clock: Clock,
    ids: IdGenerator,
    private val scope: CoroutineScope,
) {
    val files = DbFiles(databaseDir)
    val databases = LedgerDatabases(files, openDatabase, ids)
    val device = FileDeviceSettings(settingsFile)
    val fx = FxService(RoomRateCache(databases), frankfurter, clock)
    val store = LedgerStore(clock, ids, DeviceIdFile.read(deviceIdFile, ids), RoomJournal(databases), fx.lookup)

    /** Set once [start] has run recovery. */
    @Volatile var recovery: RestoreRecovery.Result? = null
        private set

    val apis = Apis(
        setup = StoreSetupApi(store),
        people = StorePeopleApi(store),
        groups = StoreGroupsApi(store),
        ledger = StoreLedgerApi(store),
        fx = StoreFxApi(fx),
        backup = FakeBackupApi(store, device),
        importExport = FakeImportExportApi(store),
        settings = StoreSettingsApi(store, device, SimpleLockGate()),
    )

    private val started: Job = scope.launch { start() }

    private suspend fun start() = store.exclusive { _, publish ->
        recovery = RestoreRecovery.run(files)
        val generation = databases.openCurrent()
        fx.load()
        publish(LedgerLoader.load(databases.database()), generation)
    }

    /**
     * The daily refresh (spec §4.5): caches the latest rates for the home currency and the currencies in use.
     * False when Frankfurter was unavailable.

        val snapshot = store.loaded()
        return fx.refresh(currenciesInUse(snapshot.state) + snapshot.settings.homeCurrency)
    }

    /** Stops background work and closes the database; the backend is unusable afterwards. */
    suspend fun close() {
        started.join()
        scope.coroutineContext.job.cancelAndJoin()
        databases.close()
        frankfurter.close()
    }

    companion object {
        /** Paid and effect currencies of all entries, and the groups' default currencies. */
        fun currenciesInUse(state: LedgerState): Set<CurrencyCode> =
            state.transfers.values.flatMap { listOf(it.amount.currency, it.effectAmount.currency) }.toSet() +
                state.expenses.values.flatMap { listOf(it.total.currency, it.effectTotal.currency) } +
                state.groups.values.map { it.defaultCurrency }

                clock = Clock.systemUTC(),
                ids = IdGenerator.Random,
                scope = CoroutineScope(SupervisorJob() + Dispatchers.IO),
            )
        }
    }
}
```

```kotlin
package io.github.codex07.iou.data

import android.content.Context
import androidx.work.BackoffPolicy
import androidx.work.Constraints
import androidx.work.CoroutineWorker
import androidx.work.ExistingPeriodicWorkPolicy
import androidx.work.NetworkType
import androidx.work.PeriodicWorkRequestBuilder
import androidx.work.WorkManager
import androidx.work.WorkerParameters
import dagger.hilt.EntryPoint
import dagger.hilt.InstallIn
import dagger.hilt.android.EntryPointAccessors
import dagger.hilt.components.SingletonComponent
import java.util.concurrent.TimeUnit

/**
 * The daily rate refresh (spec §4.5, §8): needs a network, retries with exponential backoff, never reports
 * anything. It reaches the app's single [RealBackend] through a Hilt entry point.
 */
class RateRefreshWorker(context: Context, params: WorkerParameters) : CoroutineWorker(context, params) {

    @EntryPoint
    @InstallIn(SingletonComponent::class)
    interface Backend {
        fun backend(): RealBackend
    }

    override suspend fun doWork(): Result {
        val backend = EntryPointAccessors.fromApplication(applicationContext, Backend::class.java).backend()
        return if (backend.refreshRates()) Result.success() else Result.retry()
    }

    companion object {
        const val NAME = "fx-rate-refresh"

        /** Schedules the refresh once; an existing schedule is kept, so app starts don't reset its timing. */
        fun schedule(context: Context) {
            val request = PeriodicWorkRequestBuilder<RateRefreshWorker>(1, TimeUnit.DAYS)
                .setConstraints(Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build())
                .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.MINUTES)
                .build()
            WorkManager.getInstance(context).enqueueUniquePeriodicWork(NAME, ExistingPeriodicWorkPolicy.KEEP, request)
        }
    }
}
```

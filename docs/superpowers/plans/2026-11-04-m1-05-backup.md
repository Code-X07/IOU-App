# M1 Part 5: Encrypted Backup, Restore and Undo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/superpowers/plans/2026-11-04-m1-00-index.md` first: its locked decisions and type inventory apply here.

**Goal:** The `real` flavor writes JSON backups of the whole database, encrypted by default, and restores them all or nothing through the database pointer. "Undo last restore" works, a restore or undo killed at any step leaves the complete old or the complete new ledger, and the backup reminder and the interrupted-restore notice reach the UI. The backup contract suite passes against the real backend (AC M1-7, 8, 12, 13, 15).

**Architecture:** `LedgerRows` holds every table as rows. `LedgerLoader` reads it from a database, and a backup is the same rows as JSON (`BackupDocument`). `BackupCipher` wraps that JSON in the spec's `IOUB` format: Argon2id over the passphrase, then AES-256-GCM over the gzipped JSON. `BackupFormat` writes files and reads them back: it decrypts, parses and validates before anything touches disk. `RestoreProcedure` runs the spec §7.1 steps under the store's write lock: mark, build, close the live database, commit the pointer, clean up. A `RestoreHook` after each step lets tests inject failures or stand in for process death. `RealBackupApi` ties these to picked documents through the `DocumentStore` port.

**Tech Stack:** BouncyCastle `bcprov-jdk18on` 1.81 (Argon2id, lightweight API only), JCE AES/GCM, `java.util.zip`, kotlinx.serialization, Room 2.8.1, JUnit 5 parameterized tests, Kotest.

## Global Constraints

- **Content:** all Room tables, including `EntryRevision`, `FxSnapshot`, `FxRateCache`, `ImportBatch` and `AppSetting`, plus `schemaVersion`, app version and timestamp. Device-local settings and the device ID are not included (spec §7.1).
- **Encrypted format** (default): header = magic `IOUB`, format version, Argon2id parameters (memory 64 MiB, iterations 3, parallelism 1), 16-byte salt, 12-byte nonce. Body = AES-256-GCM over the gzipped JSON. The passphrase is entered for every backup and restore and never stored (spec §7.1).
- **Passphrase** at least 8 characters (spec §9). **Unencrypted format:** plain `.json` (spec §7.1).
- **Backup reminder:** when `lastManualBackupAt` is older than 30 days (or no backup was ever made), `BackupApi` reports a non-blocking reminder. There are no scheduled automatic backups (spec §7.1).
- **Restore procedure** (spec §7.1):
  1. Decrypt, parse and validate the entire file before touching the live database. A newer `schemaVersion` is rejected.
  2. Mark: write `restore-marker.json` and fsync it.
  3. Build `iou-<new>.db`, run the §4.7 invariant checks, and close it with a full WAL checkpoint.
  4. Commit: under the write lock, close the live database, then replace the pointer with `{ current: new, previous: old current, generation: fresh UUID }`. The atomic rename is the commit point. Reopen, release the lock and emit the new generation.
  5. Clean up: delete the database that was `previous` before the commit, then the marker.
  6. On any failure before the commit point, the pointer write included, delete the new database and the marker and reopen the live one: "Restore failed, nothing changed". After it the operation is complete and is never rolled back (spec §7.1, §8).
- **Undo last restore** writes a marker with `op = "undo"` and `target` = the current `previous`. It then commits a pointer with `current` and `previous` swapped and a fresh `generation`, so an undo can itself be undone. A token from before the restore stays invalid after the undo (spec §7.1, AC M1-15).
- **The me identity comes from the backup; the device ID stays the installation's own** (spec §7.1, AC M1-7).
- **Process death** at each step leaves the complete old database or the complete new one, never a mix. A kill before the commit point is reported once; a kill after it reports nothing (AC M1-12).

## Decisions this part makes

- **A backup holds the database's rows** (`LedgerRows`), the same shape the tables, the revision snapshots and the loader use (index, locked decision 5), and the rate cache travels with them (spec §7.1).
  - The document is `{ format: "iou-backup", schemaVersion, appVersion, createdAt, rows }`. `schemaVersion` is the Room schema version, 1. No older version exists yet, so there is nothing to migrate.
  - A backup is written from the store's current snapshot, which is exactly what the database holds (ADR-0010), so creating one doesn't read the database.
- **The header layout** is `IOUB` | version byte `1` | memory KiB | iterations | parallelism (4-byte big-endian each) | 16-byte salt | 12-byte nonce, 45 bytes in all.
  - The header is GCM's associated data, so a changed header fails like a changed body: `WrongPassphraseOrDamagedFile`.
  - A newer version byte gives `SchemaTooNew`. A truncated file or Argon2 parameters above 256 MiB, 10 iterations or 4 lanes give `CorruptFile`, before any key is derived, so a crafted file can't make the app allocate gigabytes.
- **Unencrypted backups are plain JSON.** The magic decides which format a file is. An encrypted file restored without a passphrase gives `WrongPassphraseOrDamagedFile`.
- **Limits:** a backup file over 64 MiB, or JSON over 256 MiB after decompression, gives `LimitsExceeded`.
- **Step 1 validation** maps every row (bad enums, dates or snapshots give `CorruptFile`), the rate cache included: each cached rate needs a date, supported currencies and a valid rate, because `fx.load()` reads them once the restore has committed. It then runs the single validator over the whole state as for an import (`WriteOp.Import`: field rules on live rows plus every state invariant). A violation gives `CorruptFile("Backup breaks rule N: …")`. An empty, never-set-up ledger is a valid backup.
- **The whole restore holds the store's write lock,** from the marker to the clean-up. The spec takes the lock at step 4. Taking it earlier only makes writes wait for the build too, and nothing can change under the restore.
- **After the commit, the ledger is loaded from the new database** and only then published, so memory always equals disk. The rate cache is reloaded too (`fx.load()`).
  - If opening or loading fails, the commit stands: nothing is rolled back and no pointer is written again (every pointer replacement needs a fresh generation, and a rollback would be a second transition after the commit point). The database is closed and the exception propagates, the same end as process death after the commit point. The store still shows the earlier ledger, but no write lands, as no database is open. The next start opens the committed database under the committed generation and reports nothing, because the marker names the database the pointer does. Until that restart, restore and undo throw an `IllegalStateException` (`RESTART_NEEDED`) before touching anything: a retry that failed before its own commit point would otherwise reopen the committed database while the store still holds the earlier ledger and generation, and writes would land there again.
  - The pointer write is inside the failure handling: full storage while writing it abandons the restore like any earlier step.
  - Restore and undo run under `NonCancellable`. A caller cancelled half-way would otherwise leave the database closed or the pointer switched.
- **New errors** (spec §6.4 change; tell the friend):
  - `RestoreFailed(detail)`: a failure before the commit point, shown as "Restore failed, nothing changed".
  - `FileAccessFailed(detail)`: a picked document can't be opened, read or written. The fake returns it for an unknown backup too.
- **New `BackupApi` members** (tell the friend): `observeRestoreInterrupted(): Flow<Boolean>` and `dismissRestoreInterrupted()`. They carry start-up recovery's "The last restore was interrupted, nothing changed" until the UI dismisses it. The fake's restores can't be interrupted, so it always reports false.
- **Both flavors check the passphrase** (`BackupRules.checkPassphrase`: `InvalidField("passphrase")` under 8 characters) and share the reminder (`BackupRules.reminder`).
- **Documents** go through the `store.DocumentStore` port. On the device it is `data.ContentDocuments` (SAF `content://` URIs, written with mode `wt`); in tests, `testutil.FileDocuments`. Parts 6 and 7 reuse the port.
- **A rate fetched during a restore is not saved** when the database is being swapped (`RoomRateCache.save` ignores `IllegalStateException`); it stays in memory.
- **Argon2 cost is a constructor parameter** (`BackupFormat(kdf)`). Tests use `RealHarness.FAST_KDF` (1 MiB, 1 iteration); one test runs the spec's parameters. Timing on the device is Part 8 (spec §14 item 3).
- **BouncyCastle is used only through its lightweight API** (`Argon2BytesGenerator`). No JCE provider is registered, so it can't clash with Android's built-in one.
- **Process death in tests** is an `Error` thrown by the restore hook. The procedure cleans up only after an `Exception`, so an `Error` leaves the files as a killed process would. The test then stops the backend and starts a new one on the same files.

```kotlin
package io.github.codex07.iou.data

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.kotest.matchers.shouldBe
import io.kotest.matchers.shouldNotBe
import java.nio.ByteBuffer
import org.junit.jupiter.api.Test

class BackupCipherTest {

    private val fast = KdfParams(memoryKiB = 1_024, iterations = 1, parallelism = 1)
    private val plain = """{"format":"iou-backup","note":"Café ☕"}""".repeat(50).toByteArray()
    private val passphrase = "correct horse".toCharArray()

    private fun LedgerResult<ByteArray>.text() = (this as LedgerResult.Ok).value.toString(Charsets.UTF_8)

    @Test
    fun `a file round-trips and every encryption uses a fresh salt and nonce`() {
        val file = BackupCipher.encrypt(plain, passphrase, fast)
        file.copyOfRange(0, 4).toString(Charsets.US_ASCII) shouldBe "IOUB"
        BackupCipher.isEncrypted(file) shouldBe true
        BackupCipher.isEncrypted(plain) shouldBe false
        BackupCipher.decrypt(file, passphrase, 1_000_000).text() shouldBe plain.toString(Charsets.UTF_8)
        BackupCipher.encrypt(plain, passphrase, fast).contentEquals(file) shouldBe false
    }

    @Test
    fun `a wrong passphrase or any changed byte fails the tag`() {
        val file = BackupCipher.encrypt(plain, passphrase, fast)
        BackupCipher.decrypt(file, "wrong horse".toCharArray(), 1_000_000) shouldBe LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
        for (index in listOf(20, file.size / 2, file.size - 1)) {
            val damaged = file.copyOf().also { it[index] = (it[index] + 1).toByte() }
            BackupCipher.decrypt(damaged, passphrase, 1_000_000) shouldBe LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
        }
    }

    @Test
    fun `malformed headers are rejected before any key is derived`() {
        val file = BackupCipher.encrypt(plain, passphrase, fast)
        (BackupCipher.decrypt(file.copyOf(40), passphrase, 1_000_000) as LedgerResult.Err).error::class shouldBe LedgerError.CorruptFile::class
        val newer = file.copyOf().also { it[4] = 2 }
        BackupCipher.decrypt(newer, passphrase, 1_000_000) shouldBe LedgerResult.Err(LedgerError.SchemaTooNew(2, 1))
        val unsignedVersion = file.copyOf().also { it[4] = 0xFF.toByte() }
        BackupCipher.decrypt(unsignedVersion, passphrase, 1_000_000) shouldBe LedgerResult.Err(LedgerError.SchemaTooNew(255, 1))
        val greedy = file.copyOf().also { ByteBuffer.wrap(it).putInt(5, 4 * 1024 * 1024) }
        BackupCipher.decrypt(greedy, passphrase, 1_000_000) shouldBe LedgerResult.Err(LedgerError.CorruptFile("Unsupported key derivation parameters"))
    }

    @Test
    fun `the decompressed size is limited`() {
        val file = BackupCipher.encrypt(plain, passphrase, fast)
        (BackupCipher.decrypt(file, passphrase, plain.size - 1L) as LedgerResult.Err).error::class shouldBe LedgerError.LimitsExceeded::class
    }

    @Test
    fun `the default parameters work`() {
        val file = BackupCipher.encrypt(plain, passphrase, KdfParams.DEFAULT)
        ByteBuffer.wrap(file, 5, 12).let { KdfParams(it.getInt(), it.getInt(), it.getInt()) } shouldBe KdfParams(65_536, 3, 1)
        BackupCipher.decrypt(file, passphrase, 1_000_000) shouldNotBe LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
    }
}
```

```kotlin
import io.github.codex07.iou.testutil.T0
import io.kotest.matchers.shouldBe
import io.kotest.matchers.string.shouldContain
import io.kotest.matchers.string.shouldStartWith
import java.time.Clock
import java.time.ZoneOffset
import kotlinx.coroutines.runBlocking
import org.junit.jupiter.api.Test

class BackupFormatTest {

    private val format = BackupFormat(KdfParams(memoryKiB = 1_024, iterations = 1, parallelism = 1))
    private val content = FakeApis.store(Clock.fixed(T0, ZoneOffset.UTC), SequentialIds("seed"))
        .also { runBlocking { SeedData.populate(it) } }
        .let { runBlocking { it.loaded().content } }
    private val rows = LedgerRows.of(content, listOf(CachedRate(EUR, SEK, D0, "10.978", T0)))
    private val passphrase = "pass-12345".toCharArray()

    fun `the seeded ledger round-trips encrypted and plain`() {
        for (secret in listOf(passphrase, null)) {
            val backup = (format.read(format.write(rows, "0.1.0", T0, secret), secret) as LedgerResult.Ok).value
            backup.rows shouldBe rows
            backup.content shouldBe content
        }
    }

    @Test
    fun `an empty ledger round-trips too`() {
        val empty = LedgerRows.of(LedgerContent(), emptyList())
        (format.read(format.write(empty, "0.1.0", T0, null), null) as LedgerResult.Ok).value.content shouldBe LedgerContent()
    }

    @Test
    fun `a plain backup is JSON with its schema, app version and time`() {
        val text = format.write(rows, "0.1.0", T0, null).toString(Charsets.UTF_8)
        text shouldStartWith """{"format":"iou-backup","schemaVersion":1,"appVersion":"0.1.0","createdAt":"2026-01-01T00:00:00Z","rows":{"""
    }

    @Test
    fun `files that aren't readable backups are rejected`() {
        val plain = format.write(rows, "0.1.0", T0, null)
        val text = plain.toString(Charsets.UTF_8)
        format.read(format.write(rows, "0.1.0", T0, passphrase), null).error() shouldBe LedgerError.WrongPassphraseOrDamagedFile
        format.read("""{"hello":1}""".toByteArray(), null).error() shouldBe LedgerError.CorruptFile("Not an IOU backup")
        format.read("PK\u0003\u0004 not json".toByteArray(), null).error()::class shouldBe LedgerError.CorruptFile::class
        format.read(text.replace("\"schemaVersion\":1", "\"schemaVersion\":2").toByteArray(), null).error() shouldBe
            LedgerError.SchemaTooNew(2, 1)
        format.read(text.replace("\"schemaVersion\":1,", "").toByteArray(), null).error()::class shouldBe
            LedgerError.CorruptFile::class
        format.read(text.replace("\"people\":[", "\"people\":7,\"x\":[").toByteArray(), null).error()::class shouldBe
            LedgerError.CorruptFile::class
        BackupFormat(maxFileBytes = plain.size - 1L).read(plain, null).error()::class shouldBe LedgerError.LimitsExceeded::class
    }

    @Test
    fun `rows that don't map or break a ledger rule are rejected`() {
        val badKind = rows.copy(transfers = rows.transfers.map { it.copy(kind = "BOGUS") })
        format.read(format.write(badKind, "0.1.0", T0, null), null).error()::class shouldBe LedgerError.CorruptFile::class

        val twoMes = rows.copy(people = rows.people.map { it.copy(isMe = true) })
        (format.read(format.write(twoMes, "0.1.0", T0, null), null).error() as LedgerError.CorruptFile).detail shouldContain "rule 15"
    }

    @Test
    fun `cached rates that don't map or aren't valid are rejected`() {
        val rate = rows.rates.single()
        for (bad in listOf(rate.copy(rateDate = "not a date"), rate.copy(base = "ZZZ"), rate.copy(rate = "0"))) {
            val backup = format.write(rows.copy(rates = listOf(bad)), "0.1.0", T0, null)
            format.read(backup, null).error()::class shouldBe LedgerError.CorruptFile::class
        }
    }
}
```

```kotlin
package io.github.codex07.iou.data

import io.github.codex07.iou.fx.CachedRate
import io.github.codex07.iou.ledger.model.EntryId
import io.github.codex07.iou.ledger.model.FxSnapshotId
import io.github.codex07.iou.ledger.model.GroupId
import io.github.codex07.iou.ledger.model.HandleId
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.model.MembershipId
import io.github.codex07.iou.ledger.model.PersonId
import io.github.codex07.iou.money.CurrencyCode
import io.github.codex07.iou.store.LedgerContent
import io.github.codex07.iou.store.LedgerSettings
import kotlinx.serialization.Serializable

/**
 * Every table of a ledger database as rows, in `rowid` order where that order matters (revisions, import
 * batches). It is what [LedgerLoader] reads and the body of a backup (spec §7.1), so a backup holds exactly
 * what the database holds, the rate cache included.
 */
@Serializable
data class LedgerRows(
    val people: List<PersonRow> = emptyList(),
    val handles: List<HandleRow> = emptyList(),
    val groups: List<GroupRow> = emptyList(),
    val members: List<MemberRow> = emptyList(),
    val transfers: List<TransferRow> = emptyList(),
    val expenses: List<ExpenseRow> = emptyList(),
    val shares: List<ShareRow> = emptyList(),
    val fxSnapshots: List<FxSnapshotRow> = emptyList(),
    val revisions: List<RevisionRow> = emptyList(),
    val importBatches: List<ImportBatchRow> = emptyList(),
    val settings: List<AppSettingRow> = emptyList(),
    val rates: List<FxRateRow> = emptyList(),
) {
    /** The ledger these rows hold; defaults for missing settings. Throws for rows that don't map (bad enums, dates, snapshots). */
    fun toContent(): LedgerContent {
        val sharesByExpense = shares.groupBy { it.expenseId }
        val state = LedgerState(
            people = people.associate { PersonId(it.id) to it.toPerson() },
            handles = handles.associate { HandleId(it.id) to it.toHandle() },
            groups = groups.associate { GroupId(it.id) to it.toGroup() },
            members = members.associate { MembershipId(it.id) to it.toMember() },
            transfers = transfers.associate { EntryId(it.id) to it.toTransfer() },
            expenses = expenses.associate { EntryId(it.id) to it.toExpense(sharesByExpense[it.id].orEmpty()) },
            fxSnapshots = fxSnapshots.associate { FxSnapshotId(it.id) to it.toSnapshot() },
        )
        val values = settings.associate { it.key to it.value }
        val defaults = LedgerSettings()
        return LedgerContent(
            state = state,
            revisions = revisions.map { it.toRevision() },
            importBatches = importBatches.map { it.toBatch() },
            ledgerSeq = values[SettingKeys.LEDGER_SEQ]?.toLong() ?: 0,
            settings = LedgerSettings(
                homeCurrency = values[SettingKeys.HOME_CURRENCY]?.let(::CurrencyCode) ?: defaults.homeCurrency,
                backupEncryptionDefault = values[SettingKeys.BACKUP_ENCRYPTION_DEFAULT]?.toBooleanStrict() ?: defaults.backupEncryptionDefault,
            ),
        )
    }

    /** Inserts every row through [dao], in order; the caller provides the transaction. */
    suspend fun writeTo(dao: LedgerDao) {
        dao.upsertPeople(people)
        dao.upsertHandles(handles)
```

```kotlin
package io.github.codex07.iou.data

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import java.io.ByteArrayInputStream
import java.io.ByteArrayOutputStream
import java.io.IOException
import java.io.InputStream
import java.nio.ByteBuffer
import java.security.SecureRandom
import java.util.zip.GZIPInputStream
import java.util.zip.GZIPOutputStream
import javax.crypto.AEADBadTagException
import javax.crypto.Cipher
import javax.crypto.spec.GCMParameterSpec
import javax.crypto.spec.SecretKeySpec
import org.bouncycastle.crypto.generators.Argon2BytesGenerator
import org.bouncycastle.crypto.params.Argon2Parameters

/** Argon2id cost: memory in KiB, iterations, lanes (spec §7.1). */
data class KdfParams(val memoryKiB: Int, val iterations: Int, val parallelism: Int) {
    companion object {
        /** Spec §7.1: 64 MiB, 3 iterations, 1 lane. */
        val DEFAULT = KdfParams(memoryKiB = 65_536, iterations = 3, parallelism = 1)

        /** Upper bounds a file may ask for, so a crafted header can't make a restore allocate gigabytes. */
        val MAX = KdfParams(memoryKiB = 262_144, iterations = 10, parallelism = 4)
    }
}

/**
 * The encrypted backup format (spec §7.1). Header: magic `IOUB`, format version (1 byte), Argon2id memory,
 * iterations and parallelism (4-byte big-endian integers), a 16-byte salt and a 12-byte nonce. Body:
 * AES-256-GCM over the gzipped JSON, with the header as associated data, so a changed header fails like a
 * changed body.
 */
object BackupCipher {
    const val VERSION: Byte = 1
    private val MAGIC = "IOUB".toByteArray(Charsets.US_ASCII)
    private const val SALT_BYTES = 16
    private const val NONCE_BYTES = 12
    private const val TAG_BITS = 128
    private const val HEADER_BYTES = 4 + 1 + 3 * 4 + SALT_BYTES + NONCE_BYTES

    fun isEncrypted(file: ByteArray): Boolean = file.size >= MAGIC.size && file.copyOfRange(0, MAGIC.size).contentEquals(MAGIC)

    fun encrypt(plain: ByteArray, passphrase: CharArray, params: KdfParams, random: SecureRandom = SecureRandom()): ByteArray {
        val salt = ByteArray(SALT_BYTES).also(random::nextBytes)
        val nonce = ByteArray(NONCE_BYTES).also(random::nextBytes)
        val header = ByteBuffer.allocate(HEADER_BYTES)
            .put(MAGIC).put(VERSION)
            .putInt(params.memoryKiB).putInt(params.iterations).putInt(params.parallelism)
            .put(salt).put(nonce)
            .array()
        val body = cipher(Cipher.ENCRYPT_MODE, derive(passphrase, salt, params), nonce, header).doFinal(gzip(plain))
        return header + body
    }

    /**
     * The JSON inside [file]. Errors: `CorruptFile` for a truncated or malformed header, `SchemaTooNew` for a
     * newer format version, `WrongPassphraseOrDamagedFile` when the GCM tag doesn't verify, `LimitsExceeded`
     * when the JSON would be larger than [maxPlainBytes].
     */
    fun decrypt(file: ByteArray, passphrase: CharArray, maxPlainBytes: Long): LedgerResult<ByteArray> {
        if (!isEncrypted(file) || file.size < HEADER_BYTES + TAG_BITS / 8) return LedgerResult.Err(LedgerError.CorruptFile("Truncated encrypted backup"))
        val buffer = ByteBuffer.wrap(file, MAGIC.size, HEADER_BYTES - MAGIC.size)
        val version = buffer.get()
        if (version != VERSION) return LedgerResult.Err(LedgerError.SchemaTooNew(version.toInt() and 0xFF, VERSION.toInt()))
        val params = KdfParams(buffer.getInt(), buffer.getInt(), buffer.getInt())
        val max = KdfParams.MAX
        if (params.memoryKiB !in 8..max.memoryKiB || params.iterations !in 1..max.iterations || params.parallelism !in 1..max.parallelism) {
            return LedgerResult.Err(LedgerError.CorruptFile("Unsupported key derivation parameters"))
        }
        val salt = ByteArray(SALT_BYTES).also(buffer::get)
        val nonce = ByteArray(NONCE_BYTES).also(buffer::get)
        val header = file.copyOfRange(0, HEADER_BYTES)
        val compressed = try {
            cipher(Cipher.DECRYPT_MODE, derive(passphrase, salt, params), nonce, header).doFinal(file, HEADER_BYTES, file.size - HEADER_BYTES)
        } catch (_: AEADBadTagException) {
            return LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
        }
        return gunzip(compressed, maxPlainBytes)
    }

    private fun derive(passphrase: CharArray, salt: ByteArray, params: KdfParams): ByteArray {
        val generator = Argon2BytesGenerator()
        generator.init(
            Argon2Parameters.Builder(Argon2Parameters.ARGON2_id)
                .withVersion(Argon2Parameters.ARGON2_VERSION_13)
                .withSalt(salt)
                .withMemoryAsKB(params.memoryKiB)
                .withIterations(params.iterations)
                .withParallelism(params.parallelism)
                .build(),
        )
        return ByteArray(32).also { generator.generateBytes(passphrase, it) }
    }

    private fun cipher(mode: Int, key: ByteArray, nonce: ByteArray, header: ByteArray): Cipher =
        Cipher.getInstance("AES/GCM/NoPadding").apply {
            init(mode, SecretKeySpec(key, "AES"), GCMParameterSpec(TAG_BITS, nonce))
            updateAAD(header)
        }

    private fun gzip(plain: ByteArray): ByteArray =
        ByteArrayOutputStream().also { out -> GZIPOutputStream(out).use { it.write(plain) } }.toByteArray()

    private fun gunzip(compressed: ByteArray, maxPlainBytes: Long): LedgerResult<ByteArray> = try {
        val plain = GZIPInputStream(ByteArrayInputStream(compressed)).use { it.readAtMost(maxPlainBytes) }
        if (plain == null) LedgerResult.Err(LedgerError.LimitsExceeded("Backup larger than $maxPlainBytes bytes")) else LedgerResult.Ok(plain)
    } catch (_: IOException) {
        LedgerResult.Err(LedgerError.CorruptFile("Damaged compressed backup"))
    }
}

/** Reads the whole stream, or returns null once it holds more than [max] bytes. */
fun InputStream.readAtMost(max: Long): ByteArray? {
    val out = ByteArrayOutputStream()
    val chunk = ByteArray(64 * 1024)
    var total = 0L
    while (true) {
        val read = read(chunk)
        if (read < 0) return out.toByteArray()
        total += read
        if (total > max) return null
        out.write(chunk, 0, read)
    }
}
```

```kotlin
package io.github.codex07.iou.data

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.ledger.engine.FxConverter
import io.github.codex07.iou.ledger.model.LedgerState
import io.github.codex07.iou.ledger.rules.LedgerValidator
import io.github.codex07.iou.ledger.rules.WriteOp
import io.github.codex07.iou.store.LedgerContent
import java.time.Instant
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.int
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/** A backup file's JSON (spec §7.1): every table as rows, plus the schema version, app version and time. */
@Serializable
data class BackupDocument(
    val format: String,
    val schemaVersion: Int,
    val appVersion: String,
    val createdAt: String,
    val rows: LedgerRows,
)

/** A backup that passed step 1 of the restore: its rows, and the ledger they hold. */
data class ValidBackup(val rows: LedgerRows, val content: LedgerContent)

/**
 * Writes and reads backup files (spec §7.1): encrypted with [BackupCipher] when a passphrase is given,
 * plain JSON otherwise. Reading decrypts, parses and validates the whole file before anything is written.
 */
class BackupFormat(
    private val kdf: KdfParams = KdfParams.DEFAULT,
    val maxFileBytes: Long = MAX_FILE_BYTES,
    private val maxJsonBytes: Long = MAX_JSON_BYTES,
) {

    fun write(rows: LedgerRows, appVersion: String, createdAt: Instant, passphrase: CharArray?): ByteArray {
        val document = BackupDocument(FORMAT, SCHEMA_VERSION, appVersion, createdAt.toString(), rows)
        val text = json.encodeToString(BackupDocument.serializer(), document).toByteArray(Charsets.UTF_8)
        return if (passphrase == null) text else BackupCipher.encrypt(text, passphrase, kdf)
    }

    /**
     * Step 1 of the restore. Errors:
     * - `WrongPassphraseOrDamagedFile` (also for an encrypted file without a passphrase);
     * - `CorruptFile` (not a backup, malformed, rows that don't map, a cached rate that isn't valid, a ledger that
     *   breaks a §3.4 rule);
     * - `SchemaTooNew`;
     * - `LimitsExceeded`.
     */
    fun read(file: ByteArray, passphrase: CharArray?): LedgerResult<ValidBackup> {
        if (file.size > maxFileBytes) return LedgerResult.Err(LedgerError.LimitsExceeded("Backup larger than $maxFileBytes bytes"))
        val text = when {
            !BackupCipher.isEncrypted(file) ->
                if (file.size > maxJsonBytes) return LedgerResult.Err(LedgerError.LimitsExceeded("Backup larger than $maxJsonBytes bytes")) else file
            passphrase == null -> return LedgerResult.Err(LedgerError.WrongPassphraseOrDamagedFile)
            else -> when (val plain = BackupCipher.decrypt(file, passphrase, maxJsonBytes)) {
                is LedgerResult.Err -> return plain
                is LedgerResult.Ok -> plain.value
            }
        }.toString(Charsets.UTF_8)
        val document = try {
            val header = json.parseToJsonElement(text).jsonObject
            if (header["format"]?.jsonPrimitive?.content != FORMAT) return LedgerResult.Err(LedgerError.CorruptFile("Not an IOU backup"))
            val schema = requireNotNull(header["schemaVersion"]) { "Missing schemaVersion" }.jsonPrimitive.int
            if (schema > SCHEMA_VERSION) return LedgerResult.Err(LedgerError.SchemaTooNew(schema, SCHEMA_VERSION))
            json.decodeFromString(BackupDocument.serializer(), text)
        } catch (e: IllegalArgumentException) {
            // kotlinx.serialization's exceptions are IllegalArgumentExceptions.
            return LedgerResult.Err(LedgerError.CorruptFile("Malformed backup: ${e.message}"))
        }
        val content = try {
            // The rate cache isn't ledger data, but `FxService.load` reads it once the restore has committed.
            for (rate in document.rows.rates.map { it.toCachedRate().rate }) {
                require(FxConverter.validateRate(rate) is LedgerResult.Ok) { "Invalid cached rate $rate" }
            }
            document.rows.toContent()
        } catch (e: RuntimeException) {
            return LedgerResult.Err(LedgerError.CorruptFile("Unreadable rows: ${e.message}"))
        }
        if (content.state != LedgerState()) {
            val violation = LedgerValidator.validate(LedgerState(), content.state, WriteOp.Import).firstOrNull()
            if (violation != null) return LedgerResult.Err(LedgerError.CorruptFile("Backup breaks rule ${violation.rule}: ${violation.error}"))
        }
        return LedgerResult.Ok(ValidBackup(document.rows, content))
    }

    companion object {
        const val FORMAT = "iou-backup"

        /** The Room schema version (`IouDatabase`); older backups are migrated when it grows. */
        const val SCHEMA_VERSION = 1
        const val MAX_FILE_BYTES = 64L * 1024 * 1024
        const val MAX_JSON_BYTES = 256L * 1024 * 1024

        private val json = Json {
            encodeDefaults = true
            explicitNulls = true
        }
    }
}
```

```kotlin
interface DocumentStore {
    /** Throws `IOException` when [ref] can't be opened. */
    fun openRead(ref: DocumentRef): InputStream

    /** Replaces [ref]'s content. Throws `IOException` when it can't be opened. */

/** Backup rules both flavors share (spec §7.1, §9). */
object BackupRules {
    const val MIN_PASSPHRASE = 8
    val REMINDER_AFTER: Duration = Duration.ofDays(30)

    /** `InvalidField("passphrase")` for a passphrase shorter than [MIN_PASSPHRASE]; null means none (unencrypted). */
    fun checkPassphrase(passphrase: CharArray?): LedgerError? =

    fun reminder(device: DeviceSettingsStore, now: () -> Instant): Flow<BackupReminder> = device.settings.map { settings ->
        val last = settings.lastManualBackupAt
        BackupReminder(due = last == null || Duration.between(last, now()) > REMINDER_AFTER, lastBackupAt = last)
    }.distinctUntilChanged()
}
```

```kotlin
/** The steps of a restore and of an undo (spec §7.1), in order. An undo has no [BUILT] step. */
enum class RestoreStep { MARKED, BUILT, LIVE_CLOSED, COMMITTED, CLEANED }

/**
 * Called after each step. Tests use it to inject a failure (throw an `Exception`) or to stand in for process
 * death (throw an `Error`, which skips all clean-up, as a killed process would).
 */
fun interface RestoreHook {
    fun reached(step: RestoreStep)

    companion object {
        val None = RestoreHook { }
    }
}

/**
 * Restore and undo through the database pointer (spec §7.1, ADR-0007). Both hold the store's write lock
 * throughout, so writes in flight finish first, new ones wait, and those that waited then meet the new
 * generation (`LedgerReplaced`). Committing the pointer is the commit point. A failure before it, the commit
 * itself included, deletes what the attempt created and reopens the live database; nothing changed. After it,
 * the operation is complete and is never rolled back (spec §7.1, §8): the new ledger is opened, loaded and
 * published, and a failure there ends like process death after the commit point (see [switchTo]); until a
 * restart, every later restore and undo is then refused. Neither runs cancellably: a caller cancelled
 * half-way would leave the database closed or the pointer switched.
 */
class RestoreProcedure(
    private val store: LedgerStore,
    private val files: DbFiles,
    private val databases: LedgerDatabases,
    private val fx: FxService,
    private val ids: IdGenerator,
    private val hook: RestoreHook,
) {
    private val undo = MutableStateFlow(false)

    /** Set once a switch past the commit point failed: the store no longer matches the pointer until a restart. */
    @Volatile private var stale = false

    /** Whether the pointer names a pre-restore copy. */
    val undoAvailable: StateFlow<Boolean> = undo.asStateFlow()

    /** Reads the pointer again; the backend calls it at start-up. */
    fun refresh() {
        undo.value = files.readPointer()?.previous != null
    }

    /** Steps 2–6 for a backup that passed step 1. */
    suspend fun restore(backup: ValidBackup): LedgerResult<Unit> = store.exclusive { _, publish ->
        withContext(NonCancellable) {
            check(!stale) { RESTART_NEEDED }
            val pointer = checkNotNull(files.readPointer())
            val target = files.newDatabaseName(ids.next())
            val next = DbPointer(current = target, previous = pointer.current, generation = ids.next())
            try {
                files.writeMarker(RestoreMarker(RESTORE, target))
                hook.reached(RestoreStep.MARKED)
                databases.build(target) { dao -> backup.rows.writeTo(dao) }
                hook.reached(RestoreStep.BUILT)
                databases.close()
                hook.reached(RestoreStep.LIVE_CLOSED)
                files.commitPointer(next)
            } catch (e: Exception) {
                files.deleteDatabase(target)
                return@withContext abandon(e)
            }
            switchTo(next, publish)
            pointer.previous?.let(files::deleteDatabase)
            finish()
        }
    }

    /** Swaps `current` and `previous`, so an undo can itself be undone. `NotFound("restore")` without a copy. */
    suspend fun undo(): LedgerResult<Unit> = store.exclusive { _, publish ->
        withContext(NonCancellable) {
            check(!stale) { RESTART_NEEDED }
            val pointer = checkNotNull(files.readPointer())
            val previous = pointer.previous ?: return@withContext LedgerResult.Err(LedgerError.NotFound("restore"))
            val next = DbPointer(current = previous, previous = pointer.current, generation = ids.next())
            try {
                files.writeMarker(RestoreMarker(UNDO, previous))
                hook.reached(RestoreStep.MARKED)
                databases.close()
                hook.reached(RestoreStep.LIVE_CLOSED)
                files.commitPointer(next)
            } catch (e: Exception) {
                return@withContext abandon(e)
            }
            switchTo(next, publish)
            finish()
        }
    }

    /**
     * After the commit point: opens the database [next] names, loads it, and only then publishes it. The commit
     * stands whatever happens here. If any of it fails, the database is closed and the exception propagates, as
     * process death after the commit point would end it: the store still holds the earlier ledger but no write
     * lands (none has a database), and the next start opens the committed database under the committed pointer's
     * generation and reports nothing, since the marker names the database the pointer does. Until then the
     * procedure is stale: a retried restore or undo throws [RESTART_NEEDED] before touching anything, because
     * one that failed before its own commit point would reopen the committed database ([abandon]) under a store
     * still holding the earlier ledger and generation, and writes would land there again.
     */
    private suspend fun switchTo(next: DbPointer, publish: (LedgerContent, LedgerGeneration) -> Unit) {
        try {
            hook.reached(RestoreStep.COMMITTED)
            val generation = databases.openCurrent()
            val content = LedgerLoader.load(databases.database())
            fx.load()
            publish(content, generation)
            undo.value = next.previous != null
        } catch (e: Exception) {
            stale = true
            databases.close()
            throw e
        }
    }

    private fun finish(): LedgerResult<Unit> {
        files.deleteMarker()
        hook.reached(RestoreStep.CLEANED)
        return LedgerResult.Ok(Unit)
    }

    private fun abandon(failure: Exception): LedgerResult<Unit> {
        files.deleteTempPointer()
        files.deleteMarker()
        if (!databases.isOpen) databases.openCurrent()
        return LedgerResult.Err(LedgerError.RestoreFailed(failure.message ?: failure.toString()))
    }

    companion object {
        const val RESTORE = "restore"
        const val UNDO = "undo"
        const val RESTART_NEEDED = "The ledger switched after a failed load; restart the app"
    }
}
```

```kotlin
/**
 * JSON backups of the whole database (spec §7.1). A backup is written from the store's current snapshot,
 * which is exactly what the database holds, plus the rate cache. A restore reads and validates the whole
 * file before [RestoreProcedure] touches any database file.
 */
class RealBackupApi(
    private val store: LedgerStore,
    private val device: DeviceSettingsStore,
    private val documents: DocumentStore,
    private val format: BackupFormat,
    private val fx: FxService,
    private val procedure: RestoreProcedure,
    private val interrupted: MutableStateFlow<Boolean>,
    private val appVersion: String,
) : BackupApi {

    override fun observeLedgerGeneration(): Flow<LedgerGeneration> = store.snapshot.map { it.generation }.distinctUntilChanged()

    override fun observeBackupReminder(): Flow<BackupReminder> = BackupRules.reminder(device, store::now)

    override suspend fun createBackup(target: DocumentRef, passphrase: CharArray?): LedgerResult<BackupInfo> {
        BackupRules.checkPassphrase(passphrase)?.let { return LedgerResult.Err(it) }
        val now = store.now()
        val rows = LedgerRows.of(store.loaded().content, fx.cachedRates())
        val written = withContext(Dispatchers.IO) {
            val file = format.write(rows, appVersion, now, passphrase)
            access(target) { documents.openWrite(target).use { it.write(file) } }
        }
        if (written is LedgerResult.Err) return written
        device.update { it.copy(lastManualBackupAt = now) }
        return LedgerResult.Ok(BackupInfo(encrypted = passphrase != null, createdAt = now))
    }

    override suspend fun restoreBackup(source: DocumentRef, passphrase: CharArray?): LedgerResult<Unit> = withContext(Dispatchers.IO) {
        val file = when (val read = access(source) { documents.openRead(source).use { it.readAtMost(format.maxFileBytes) } }) {
            is LedgerResult.Err -> return@withContext read
            is LedgerResult.Ok -> read.value
                ?: return@withContext LedgerResult.Err(LedgerError.LimitsExceeded("Backup larger than ${format.maxFileBytes} bytes"))
        }
        when (val backup = format.read(file, passphrase)) {
            is LedgerResult.Err -> backup
            is LedgerResult.Ok -> procedure.restore(backup.value)
        }
    }

    override fun observeUndoRestoreAvailable(): Flow<Boolean> = procedure.undoAvailable

    override suspend fun undoLastRestore(): LedgerResult<Unit> = withContext(Dispatchers.IO) { procedure.undo() }

    override fun observeRestoreInterrupted(): Flow<Boolean> = interrupted

    override suspend fun dismissRestoreInterrupted() {
        interrupted.value = false
    }

    /** Runs a document read or write; a missing document or a revoked permission becomes `FileAccessFailed`. */
    private inline fun <T> access(ref: DocumentRef, block: () -> T): LedgerResult<T> = try {
        LedgerResult.Ok(block())
    } catch (e: IOException) {
        LedgerResult.Err(LedgerError.FileAccessFailed("${ref.uri}: ${e.message}"))
    } catch (e: SecurityException) {
        LedgerResult.Err(LedgerError.FileAccessFailed("${ref.uri}: ${e.message}"))
    }
}
```

```kotlin
/**
 * The real flavor's backend (ADR-0010): the shared store with a Room journal, the rate cache and Frankfurter,
 * backups through the database pointer, the device settings file and the device ID file. Construction
 * returns at once; [start] runs recovery, opens the database the pointer names, loads the rate cache and
 * publishes the ledger, and reads and writes wait for that.
 *
 * Import/export is still the simulation from `fake`; Parts 6 and 7 replace it.
 */
class RealBackend(
    databaseDir: File,
    deviceIdFile: File,
    settingsFile: File,
    openDatabase: (File) -> IouDatabase,
    private val frankfurter: FrankfurterClient,
    documents: DocumentStore,
    clock: Clock,
    ids: IdGenerator,
    private val scope: CoroutineScope,
    backupFormat: BackupFormat = BackupFormat(),
    appVersion: String = "",
    restoreHook: RestoreHook = RestoreHook.None,
) {
    val files = DbFiles(databaseDir)
    val databases = LedgerDatabases(files, openDatabase, ids)
    val device = FileDeviceSettings(settingsFile)
    val fx = FxService(RoomRateCache(databases), frankfurter, clock)
    val store = LedgerStore(clock, ids, DeviceIdFile.read(deviceIdFile, ids), RoomJournal(databases), fx.lookup)
    val restores = RestoreProcedure(store, files, databases, fx, ids, restoreHook)

    /** Set once [start] has run recovery. */
    @Volatile var recovery: RestoreRecovery.Result? = null
        private set

    private val interrupted = MutableStateFlow(false)

    val apis = Apis(
        setup = StoreSetupApi(store),
        people = StorePeopleApi(store),
        groups = StoreGroupsApi(store),
        ledger = StoreLedgerApi(store),
        fx = StoreFxApi(fx),
        backup = RealBackupApi(store, device, documents, backupFormat, fx, restores, interrupted, appVersion),
        importExport = FakeImportExportApi(store),
        settings = StoreSettingsApi(store, device, SimpleLockGate()),
    )

    private val started: Job = scope.launch { start() }

    private suspend fun start() = store.exclusive { _, publish ->
        val result = RestoreRecovery.run(files)
        recovery = result
        interrupted.value = result.interrupted
        val generation = databases.openCurrent()
        restores.refresh()
        fx.load()
        publish(LedgerLoader.load(databases.database()), generation)
    }

    /**
     * The daily refresh (spec §4.5): caches the latest rates for the home currency and the currencies in use.
     * False when Frankfurter was unavailable.
     */
    suspend fun refreshRates(): Boolean {
        val snapshot = store.loaded()
        return fx.refresh(currenciesInUse(snapshot.state) + snapshot.settings.homeCurrency)
    }

    /** Stops background work and closes the database; the backend is unusable afterwards. */
    suspend fun close() {
        started.join()
        scope.coroutineContext.job.cancelAndJoin()
        databases.close()
        frankfurter.close()
    }

    companion object {
        /** Paid and effect currencies of all entries, and the groups' default currencies. */
        fun currenciesInUse(state: LedgerState): Set<CurrencyCode> =
            state.transfers.values.flatMap { listOf(it.amount.currency, it.effectAmount.currency) }.toSet() +
                state.expenses.values.flatMap { listOf(it.total.currency, it.effectTotal.currency) } +
                state.groups.values.map { it.defaultCurrency }

        /** The app's backend: files in the app's private storage, the framework SQLite driver, SAF documents. */
        fun android(context: Context): RealBackend {
            val app = context.applicationContext
            return RealBackend(
                databaseDir = checkNotNull(app.getDatabasePath(DbFiles.POINTER).parentFile),
                deviceIdFile = File(app.noBackupFilesDir, "device-id"),
                settingsFile = File(app.noBackupFilesDir, "device-settings.json"),
                openDatabase = { IouDatabase.open(app, AndroidSQLiteDriver(), it.absolutePath) },
                frankfurter = FrankfurterClient.create(),
                documents = ContentDocuments(app.contentResolver),
                clock = Clock.systemUTC(),
                ids = IdGenerator.Random,
                scope = CoroutineScope(SupervisorJob() + Dispatchers.IO),
                appVersion = BuildConfig.VERSION_NAME,
            )
        }
    }
}
```

```kotlin
 * the complete old database or the complete new one. A kill before the commit point is reported once; a kill
 * after it is not reported. The restore hook stands in for the kill by throwing an `Error`, which skips every

    /** A ledger with one person, backed up, and then a second person; returns (backed up, live). */
    private suspend fun RealBackend.backupThenChange(): Pair<LedgerContent, LedgerContent> {
        apis.setup.completeSetup("Me", EUR).orFail()
        apis.people.createPerson(PersonDraft("In the backup"), apis.backup.observeLedgerGeneration().first()).orFail()
        apis.backup.createBackup(file, "pass-12345".toCharArray()).orFail()
        val backedUp = store.loaded().content
        apis.people.createPerson(PersonDraft("Only live"), apis.backup.observeLedgerGeneration().first()).orFail()

        harness.onStep = { if (it == step) throw Killed() }

        harness.onStep = {}
        harness.stop()
        val restarted = harness.start()
        restarted.store.loaded().content shouldBe expected
        restarted.recovery shouldBe RestoreRecovery.Result(interrupted = reported)
        restarted.apis.backup.observeRestoreInterrupted().first() shouldBe reported
        restarted.apis.backup.dismissRestoreInterrupted()

        harness.ledgerFileNames() shouldBe setOfNotNull(DbFiles.POINTER, pointer.current, pointer.previous)
        harness.stop()
        val again = harness.start()
        again.store.loaded().content shouldBe expected
        again.recovery shouldBe RestoreRecovery.Result(interrupted = false)
```

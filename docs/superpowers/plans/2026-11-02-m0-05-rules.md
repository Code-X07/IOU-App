**Goal:** One validator that every write path calls: field validity, the state invariants [S] over the complete state a write would produce, and the edit rules [E] over the entities an `api` write changes (spec §3.4).

**Architecture:** `LedgerValidator.validate(before, after, op)` returns every violation as `RuleViolation(rule, error)`: field checks first, then edit rules, then state invariants, each by rule number (so the cause, e.g. `MemberRemoved`, is reported before its consequence, e.g. `MemberHasBalance`). Structural problems (rule 15) short-circuit, because the other checks assume every reference resolves. Balances are computed once (`LedgerEngine.compute(after)`); an overflow becomes `AmountTooLarge`. `WriteOp.Edit(changes)` turns the edit rules on; `WriteOp.Import`/`UndoImport` check state invariants only.

**Tech Stack:** Kotlin, JUnit 5, Kotest assertions.

## Global Constraints

- Two kinds of rules (spec §3.4): **state invariants [S]** are checked against the complete state a write would produce, on every write path; **edit rules [E]** apply only to the entities a write creates or changes, plus the operation's own preconditions, never to untouched historical entries. Import and undo import are checked against the state invariants only.
- Business invariants constrain non-deleted rows only; rule 15 (structure) covers every row, deleted ones included (spec §3.4).
- A write that violates any applicable rule is rejected in full with a typed `LedgerError` (spec §3.4).
- Rule texts and errors are those of spec §3.4, rules 1–17 (quoted in each task below).
- An overflow while computing the balances of the produced state → `AmountTooLarge` (spec §3.1).
- IBAN: uppercase without spaces, mod-97 validated; Revtag without `@`; phone E.164 (spec §3.2).

## Deviations and interpretations (deliberate)

- **Rule 0 = field validity** (not numbered in the spec): blank names/labels/descriptions → `InvalidField`; amounts must be `0 < x ≤ MAX_MINOR` (`InvalidAmount` / `AmountTooLarge`); expense shares must be non-empty, distinct, non-negative and sum to the effect total (`CorruptData`, only reachable through import since ops compute shares); handle values valid for their type. Checked on changed rows for edits and on every non-deleted row for import.
- **Rule 8 error:** the spec names none; a CONVERT entry in the wrong effect currency reports `FxSnapshotMismatch(entryId)`.
- **Rule 2 [S] error:** a non-deleted group without me as an active member reports `CannotModifyMe`.
- **Rule 10 [E]:** "referenced" counts every entry and every membership row, soft-deleted ones included (they could be restored). A person's own handles and a group's own memberships don't block, because the cascade deletes them in the same write.
- **Rule 13 [E]:** applies to transfers whose revision action is `CREATED` or `UPDATED`; deleting or restoring a transfer that became a self-transfer through a merge stays allowed.
- Merging me, or merging into me, reports `CannotModifyMe` (rule 9) rather than `InvalidMerge`.

package io.github.codex07.iou.ledger.rules

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.LedgerResult
import io.github.codex07.iou.api.RuleViolation
import io.github.codex07.iou.ledger.model.Expense
import io.github.codex07.iou.ledger.model.Group
import io.github.codex07.iou.ledger.model.GroupMember
import io.github.codex07.iou.ledger.model.HandleType
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.PaymentHandle
import io.github.codex07.iou.ledger.model.Person
import io.github.codex07.iou.ledger.model.Transfer
import io.github.codex07.iou.money.MAX_MINOR
import io.github.codex07.iou.money.Money
import java.math.BigInteger

/** Rule 0: field validity, and normalization of payment handle values (spec §3.2). */
object FieldRules {

    private val ibanShape = Regex("^[A-Z]{2}[0-9]{2}[A-Z0-9]{11,30}$")
    private val revtagShape = Regex("^[A-Za-z0-9._-]{1,64}$")
    private val e164Shape = Regex("^\\+[1-9][0-9]{7,14}$")
    private val ninetySeven = BigInteger.valueOf(97)

    fun normalizeHandleValue(type: HandleType, raw: String): LedgerResult<String> {
        val normalized = when (type) {
            HandleType.IBAN -> raw.filterNot { it.isWhitespace() }.uppercase()
            HandleType.REVTAG -> raw.trim().removePrefix("@")
            HandleType.PHONE -> raw.filterNot { it.isWhitespace() || it == '-' }
            HandleType.OTHER -> raw.trim()
        }
        return when {
            type == HandleType.IBAN && !isValidIban(normalized) -> LedgerResult.Err(LedgerError.InvalidIban(raw))
            !hasValidShape(type, normalized) -> LedgerResult.Err(LedgerError.InvalidField("value"))
            else -> LedgerResult.Ok(normalized)
        }
    }

    /** Shape plus ISO 13616 mod-97 check of an already normalized IBAN. */
    fun isValidIban(normalized: String): Boolean {
        if (!ibanShape.matches(normalized)) return false
        val rearranged = normalized.substring(4) + normalized.substring(0, 4)
        val digits = rearranged.map { if (it.isDigit()) it.toString() else (it - 'A' + 10).toString() }.joinToString("")
        return BigInteger(digits).mod(ninetySeven) == BigInteger.ONE
    }

    fun check(entities: List<LedgerEntity>): List<RuleViolation> = entities.flatMap { entity ->
        when (entity) {
            is Person -> listOfNotNull(blank(entity.displayName, "displayName"))
            is PaymentHandle -> listOfNotNull(blank(entity.label, "label"), handleValue(entity))
            is Group -> listOfNotNull(blank(entity.name, "name"))
            is GroupMember -> emptyList()
            is Transfer -> listOfNotNull(amount(entity.amount), amount(entity.effectAmount))
            is Expense -> listOfNotNull(
                blank(entity.description, "description"),
                amount(entity.total),
                amount(entity.effectTotal),
            ) + shares(entity)
        }.map { RuleViolation(0, it) }
    }

    private fun hasValidShape(type: HandleType, value: String): Boolean = when (type) {
        HandleType.IBAN -> true
        HandleType.REVTAG -> revtagShape.matches(value)
        HandleType.PHONE -> e164Shape.matches(value)
        HandleType.OTHER -> value.isNotBlank()
    }

    private fun blank(value: String, field: String): LedgerError? =
        if (value.isBlank()) LedgerError.InvalidField(field) else null

    private fun handleValue(handle: PaymentHandle): LedgerError? = when (val result = normalizeHandleValue(handle.type, handle.value)) {
        is LedgerResult.Err -> result.error
        is LedgerResult.Ok -> if (result.value != handle.value) {
            if (handle.type == HandleType.IBAN) LedgerError.InvalidIban(handle.value) else LedgerError.InvalidField("value")
        } else {
            null
        }
    }

    private fun amount(money: Money): LedgerError? = when {
        money.amountMinor <= 0 -> LedgerError.InvalidAmount
        money.amountMinor > MAX_MINOR -> LedgerError.AmountTooLarge
        else -> null
    }

    private fun shares(expense: Expense): List<LedgerError> {
        if (expense.shares.isEmpty()) return listOf(LedgerError.NoParticipants)
        expense.shares.groupBy { it.personId }.entries.firstOrNull { it.value.size > 1 }
            ?.let { return listOf(LedgerError.DuplicateParticipant(it.key)) }
        expense.shares.firstOrNull { it.shareMinor < 0 }?.let { return listOf(LedgerError.NegativeInput(it.personId)) }
        var sum = 0L
        for (share in expense.shares) {
            // Shares are non-negative here; stopping above MAX_MINOR keeps a corrupt import from overflowing.
            if (share.shareMinor > MAX_MINOR - sum) {
                return listOf(LedgerError.CorruptData("shares of ${expense.id} sum to more than $MAX_MINOR"))
            }
            sum += share.shareMinor
        }
        return if (sum == expense.effectTotal.amountMinor) {
            emptyList()
        } else {
            listOf(LedgerError.CorruptData("shares of ${expense.id} sum to $sum, not ${expense.effectTotal.amountMinor}"))
        }
    }
}

Rule texts (spec §3.4) this task implements:

14. [S] An entry has an `fxSnapshotId` exactly when its effect currency differs from its paid currency, and that snapshot has base = paid currency and quote = effect currency → `FxSnapshotMismatch`.
15. [S, all rows] Every ID reference points to an existing row; the `mergedIntoId` graph has no cycles; exactly one person has `isMe` → `CorruptData`.
16. [S] An entry that references a `BANK_ACTUAL` snapshot has paid amount = `paidMinor` and effect amount = `chargedMinor` → `FxSnapshotMismatch`.
17. [S] An entry without a snapshot has effect = paid; an entry with a rate-based snapshot has exactly the effect the §4.5 conversion gives → `FxSnapshotMismatch`.

/** The [S] rules of spec §3.4. */
internal object StateInvariants {

    /** Rule 15, over every row including deleted ones. */
    fun structure(state: LedgerState): List<RuleViolation> {
        val problems = mutableListOf<String>()
        val meCount = state.people.values.count { it.isMe }
        if (meCount != 1) problems += "expected exactly one me, found $meCount"

        fun person(id: PersonId, owner: String) {
            if (id !in state.people) problems += "$owner references missing person $id"
        }
        fun group(id: GroupId?, owner: String) {
            if (id != null && id !in state.groups) problems += "$owner references missing group $id"
        }
        fun snapshot(id: FxSnapshotId?, owner: String) {
            if (id != null && id !in state.fxSnapshots) problems += "$owner references missing FX snapshot $id"
        }

        state.people.values.forEach { p -> p.mergedIntoId?.let { person(it, p.id.value) } }
        state.handles.values.forEach { person(it.personId, it.id.value) }
        state.members.values.forEach {
            person(it.personId, it.id.value)
            group(it.groupId, it.id.value)
        }
        state.transfers.values.forEach {
            person(it.fromPersonId, it.id.value)
            person(it.toPersonId, it.id.value)
            group(it.groupId, it.id.value)
            snapshot(it.fxSnapshotId, it.id.value)
        }
        state.expenses.values.forEach { e ->
            person(e.payerPersonId, e.id.value)
            e.shares.forEach { person(it.personId, e.id.value) }
            group(e.groupId, e.id.value)
            snapshot(e.fxSnapshotId, e.id.value)
        }
        IdentityResolver(state).brokenChains.sortedBy { it.value }.forEach {
            problems += "merge chain of $it loops or ends at a missing person"
        }
        return problems.map { RuleViolation(15, LedgerError.CorruptData(it)) }
    }

    /** Every other [S] rule. Assumes [structure] passed. [balances] is null when they overflowed. */
    fun check(state: LedgerState, resolver: IdentityResolver, balances: Balances?): List<RuleViolation> {
        val out = mutableListOf<RuleViolation>()
        fun add(rule: Int, error: LedgerError) { out += RuleViolation(rule, error) }

        val me = state.me
        val liveEntries = state.entries.filter { !it.isDeleted }
        val liveGroups = state.groups.values.filter { !it.isDeleted }

        // Rule 1
        for (entry in liveEntries.filter { it.groupId == null }) {
            val people = entry.personIds.map(resolver::canonical).toSet()
            val ok = when (entry) {
                is Transfer -> me.id in people
                is Expense -> people.size == 2 && me.id in people
            }
            if (!ok) add(1, LedgerError.NeedsGroup(people))
        }

        // Rule 2
        for (group in liveGroups) {
            if (!resolver.isActiveMember(group.id, me.id)) add(2, LedgerError.CannotModifyMe)
        }

        // Rule 3
        for (entry in liveEntries) {
            val groupId = entry.groupId ?: continue
            val missing = entry.personIds.map(resolver::canonical).filterNot { resolver.hasMembership(groupId, it) }.toSet()
            if (missing.isNotEmpty()) add(3, LedgerError.NotGroupMember(groupId, missing))
        }

        // Rule 4
        if (balances != null) {
            for (group in liveGroups) {
                for (person in resolver.canonicalMembers(group.id).sortedBy { it.value }) {
                    if (resolver.isActiveMember(group.id, person)) continue
                    val nets = balances.groupNet(group.id, person)
                    if (nets.isNotEmpty()) add(4, LedgerError.MemberHasBalance(group.id, person, nets))
                }
            }
        }

        // Rule 8
        for (entry in liveEntries) {
            val group = entry.groupId?.let { state.groups[it] } ?: continue
            if (group.fxMode == FxMode.CONVERT && entry.effect.currency != group.defaultCurrency) {
                add(8, LedgerError.FxSnapshotMismatch(entry.id))
            }
        }

        // Rule 9
        if (me.isDeleted || me.mergedIntoId != null) add(9, LedgerError.CannotModifyMe)

        // Rule 10
        for (handle in state.handles.values.filter { !it.isDeleted }) {
            if (state.people.getValue(handle.personId).isDeleted) {
                add(10, LedgerError.DeletedReference(setOf(handle.id.value, handle.personId.value)))
            }
        }
        for (member in state.members.values.filter { !it.isDeleted }) {
            val dead = listOfNotNull(
                member.personId.value.takeIf { state.people.getValue(member.personId).isDeleted },
                member.groupId.value.takeIf { state.groups.getValue(member.groupId).isDeleted },
            )
            if (dead.isNotEmpty()) add(10, LedgerError.DeletedReference(setOf(member.id.value) + dead))
        }
        for (entry in liveEntries) {
            val dead = entry.personIds.filter { state.people.getValue(it).isDeleted }.map { it.value } +
                listOfNotNull(entry.groupId?.takeIf { state.groups.getValue(it).isDeleted }?.value)
            if (dead.isNotEmpty()) add(10, LedgerError.DeletedReference(setOf(entry.id.value) + dead))
        }

        // Rule 11
        for (person in state.people.values.filter { !it.isDeleted && it.mergedIntoId != null }) {
            val canonical = resolver.canonical(person.id)
            if (state.people.getValue(canonical).isDeleted) {
                add(11, LedgerError.DeletedReference(setOf(person.id.value, canonical.value)))
            }
        }

        // Rules 14, 16, 17
        for (entry in liveEntries) fxRule(state, entry)?.let { (rule, error) -> add(rule, error) }

        return out
    }

    private fun fxRule(state: LedgerState, entry: Entry): Pair<Int, LedgerError>? {
        val mismatch = LedgerError.FxSnapshotMismatch(entry.id)
        val converted = entry.effect.currency != entry.paid.currency
        val snapshotId = entry.fxSnapshotId
        if (snapshotId == null) {
            if (converted) return 14 to mismatch
            return if (entry.effect != entry.paid) 17 to mismatch else null
        }
        if (!converted) return 14 to mismatch
        val snapshot = state.fxSnapshots.getValue(snapshotId)
        if (snapshot.baseCurrency != entry.paid.currency || snapshot.quoteCurrency != entry.effect.currency) {
            return 14 to mismatch
        }
        return when (snapshot.source) {
            FxSource.BANK_ACTUAL ->
                if (snapshot.paidMinor == entry.paid.amountMinor && snapshot.chargedMinor == entry.effect.amountMinor) null
                else 16 to mismatch
            FxSource.ECB_FRANKFURTER, FxSource.USER_ENTERED -> {
                val expected = FxConverter.convert(entry.paid, entry.effect.currency, snapshot.rate)
                if (expected == LedgerResult.Ok(entry.effect)) null else 17 to mismatch
            }
        }
    }
}

package io.github.codex07.iou.ledger.rules

import io.github.codex07.iou.api.LedgerError
import io.github.codex07.iou.api.RuleViolation
import io.github.codex07.iou.ledger.engine.Balances
import io.github.codex07.iou.ledger.engine.IdentityResolver
import io.github.codex07.iou.ledger.engine.LedgerEngine
import io.github.codex07.iou.ledger.model.LedgerEntity
import io.github.codex07.iou.ledger.model.LedgerState

/**
 * The single validator every write path runs (spec §3.4): field validity, state invariants over the
 * complete state [after], and, for api writes, the edit rules over the changed entities.
 */
object LedgerValidator {

    fun validate(before: LedgerState, after: LedgerState, op: WriteOp): List<RuleViolation> {
        val structure = StateInvariants.structure(after)
        if (structure.isNotEmpty()) return structure

        val resolver = IdentityResolver(after)
        val balances: Balances? = try {
            LedgerEngine.compute(after)
        } catch (overflow: ArithmeticException) {
            null
        }

        // Order: field checks, then edit rules (what the user tried to do), then state invariants
        // (its consequences), each by rule number. Callers report the first one.
        val violations = buildList {
            if (balances == null) add(RuleViolation(0, LedgerError.AmountTooLarge))
            addAll(FieldRules.check(fieldTargets(after, op)))
            if (op is WriteOp.Edit) addAll(EditRules.check(before, after, op.changes).sortedBy { it.rule })
            addAll(StateInvariants.check(after, resolver, balances).sortedBy { it.rule })
        }
        return violations.distinct()
    }

    private fun fieldTargets(after: LedgerState, op: WriteOp): List<LedgerEntity> = when (op) {
        is WriteOp.Edit -> op.changes.map { it.entity }.filter { !it.isDeleted }
        WriteOp.Import, WriteOp.UndoImport ->
            (after.people.values + after.handles.values + after.groups.values + after.members.values + after.entries)
                .filter { !it.isDeleted }
    }
}

/** The [E] rules of spec §3.4: only the changed entities and the operation's preconditions. */
internal object EditRules {

    fun check(before: LedgerState, after: LedgerState, changes: List<Change>): List<RuleViolation> {
        val out = mutableListOf<RuleViolation>()
        fun add(rule: Int, error: LedgerError) { out += RuleViolation(rule, error) }

        val resolver = IdentityResolver(after)
        val me = after.me.id

        for (change in changes) {
            val new = change.entity
            val old = before.entity(new.entityType, new.entityId)
            when (new) {
                is GroupMember -> {
                    val wasActive = (old as GroupMember?)?.removedAt == null && old != null
                    if (wasActive && new.removedAt != null && resolver.canonical(new.personId) == me) {
                        add(2, LedgerError.CannotModifyMe)
                    }
                }

                is Entry -> {
                    for (version in listOfNotNull(old as Entry?, new)) {
                        val groupId = version.groupId ?: continue
                        val removed = version.personIds.map(resolver::canonical)
                            .filter { resolver.hasMembership(groupId, it) && !resolver.isActiveMember(groupId, it) }
                            .toSet()
                        if (removed.isNotEmpty()) add(5, LedgerError.MemberRemoved(groupId, removed))
                    }
                    if (new is Transfer &&
                        (change.action == RevisionAction.CREATED || change.action == RevisionAction.UPDATED) &&
                        resolver.canonical(new.fromPersonId) == resolver.canonical(new.toPersonId)
                    ) {
                        add(13, LedgerError.SelfTransfer)
                    }
                }

                is Group -> {
                    val previous = old as Group?
                    if (previous != null && before.entries.any { it.groupId == new.id }) {
                        if (previous.fxMode != new.fxMode) add(6, LedgerError.GroupSettingsLocked(new.id))
                        if (previous.fxMode == FxMode.CONVERT && previous.defaultCurrency != new.defaultCurrency) {
                            add(7, LedgerError.GroupSettingsLocked(new.id))
                        }
                    }
                    if (previous != null && !previous.isDeleted && new.isDeleted && after.entries.any { it.groupId == new.id }) {
                        add(10, LedgerError.StillReferenced(new.id.value))
                    }
                }

                is Person -> checkPerson(before, after, old as Person?, new, ::add)

                is PaymentHandle -> Unit
            }
        }
        return out
    }

    private fun checkPerson(
        before: LedgerState,
        after: LedgerState,
        old: Person?,
        new: Person,
        add: (Int, LedgerError) -> Unit,
    ) {
        val newlyDeleted = old != null && !old.isDeleted && new.isDeleted

        // Rule 9
        if (new.isMe) {
            val archived = old?.archivedAt == null && new.archivedAt != null
            if (newlyDeleted || archived || new.mergedIntoId != null) add(9, LedgerError.CannotModifyMe)
        }
        val target = new.mergedIntoId?.let { before.people[it] }
        if (old?.mergedIntoId != new.mergedIntoId && target?.isMe == true) add(9, LedgerError.CannotModifyMe)

        // Rule 10
        if (newlyDeleted) {
            val referenced = after.entries.any { new.id in it.personIds } ||
                after.members.values.any { it.personId == new.id }
            if (referenced) add(10, LedgerError.StillReferenced(new.id.value))
        }

        // Rule 11 (merge preconditions; merging me is rule 9)
        val targetId = new.mergedIntoId
        if (old != null && targetId != null && old.mergedIntoId != targetId && !new.isMe && target?.isMe != true) {
            when {
                targetId == new.id -> add(11, LedgerError.InvalidMerge(MergeProblem.SAME_PERSON))
                old.mergedIntoId != null -> add(11, LedgerError.InvalidMerge(MergeProblem.NOT_CANONICAL))
                target == null -> Unit // reported by rule 15
                old.isDeleted || target.isDeleted -> add(11, LedgerError.InvalidMerge(MergeProblem.DELETED))
                target.mergedIntoId != null -> add(11, LedgerError.InvalidMerge(MergeProblem.NOT_CANONICAL))
            }
        }
    }
}
